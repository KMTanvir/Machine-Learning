Measuring Quality: Mean Squared Error

For regression problems with continuous \(Y\), the most common quality measure is the Mean Squared Error (MSE). Given training data \(\{(x_i, y_i)\}_{i=1}^n\) and a fitted model \(\hat{f}\):

Training MSE
\[ \text{MSE}_{\text{train}} = \frac{1}{n}\sum_{i=1}^{n}\bigl(y_i - \hat{f}(x_i)\bigr)^2 \]
Test MSE (goal)
\[ \text{MSE}_{\text{test}} = E\bigl[(y_0 - \hat{f}(x_0))^2\bigr] \]
Critical Distinction

Training MSE is computed on the same data used to fit \(\hat{f}\). Test MSE is computed on new observations \((x_0, y_0)\) not used in training. We almost always care about test MSE, but we can only directly observe training MSE.

Rule

A method that minimises training MSE does NOT necessarily minimise test MSE. This is the central challenge of statistical machine learning.

The Training Error vs Test Error Curve

As model flexibility (degrees of freedom) increases, the training error always decreases. But the test error follows a U-shape: it falls, reaches a minimum, then rises.

Low Flexibility
Underfitting
High train error, high test error
Optimal Flexibility
Just Right
Min test error, train < test but close
High Flexibility
Overfitting
Near-zero train error, high test error
Degrees of Freedom

Roughly the number of free parameters a model can use. Linear regression with \(p\) predictors has \(p+1\) degrees of freedom. A polynomial of degree \(d\) has \(d+1\). KNN with neighbourhood size \(K\) has effective df \(n/K\) (smaller \(K\) = more flexible).

Key Insight

We cannot observe the test error curve directly during training. We need held-out data or cross-validation to estimate where we are on the curve.

Overfitting and Underfitting

Underfitting

  • Model too simple to capture true \(f\)
  • High training error AND high test error
  • Caused by: too few predictors, linearity when truth is nonlinear
  • Fix: increase model complexity, add features, use polynomial or nonlinear terms

Overfitting

  • Model too flexible, memorises training data
  • Very low training error, high test error
  • Caused by: too many parameters, no regularisation
  • Fix: regularise (ridge, lasso), reduce complexity, get more data
Concrete Example: Polynomial Regression
  • Degree 1 (linear): may underfit if true \(f\) is curved
  • Degree 3 or 4: often near optimal
  • Degree 15: passes through almost every training point, test MSE explodes
How to detect

Large gap between training MSE and test MSE signals overfitting. If both are large, the model is underfitting.

Bias-Variance Decomposition

For any test point \(x_0\), the expected test MSE can be decomposed into three components:

The Bias-Variance Decomposition
\[ E\bigl[(y_0 - \hat{f}(x_0))^2\bigr] = \underbrace{\operatorname{Bias}(\hat{f}(x_0))^2}_{\text{Bias}^2} + \underbrace{\operatorname{Var}(\hat{f}(x_0))}_{\text{Variance}} + \underbrace{\operatorname{Var}(\varepsilon)}_{\text{Irreducible}} \]

Bias

  • Error from wrong model assumptions
  • \(= E[\hat{f}(x_0)] - f(x_0)\)
  • Simple models: HIGH bias
  • Complex models: LOW bias

Variance

  • Sensitivity to training data
  • Changes a lot if data changes
  • Simple models: LOW variance
  • Complex models: HIGH variance

Irreducible

  • Noise in the process
  • \(= \operatorname{Var}(\varepsilon)\)
  • Cannot be reduced
  • Lower bound on test MSE
Slide 6 of 16
Bias-Variance Tradeoff

As model flexibility increases, bias falls monotonically but variance rises. Test MSE = Bias\(^2\) + Variance + Const. The minimum of test MSE occurs where the marginal decrease in bias\(^2\) equals the marginal increase in variance.

Model TypeBiasVarianceTest MSE
Constant (predict mean)Very HighVery LowHigh
Linear regression (low dim)ModerateLowModerate
Polynomial degree 3-4LowModerateLow (often best)
KNN with K=1~0Very HighHigh
Deep neural networkVery LowHigh (unless regularised)Depends on regularisation
Practical Message

The best model balances bias and variance. Regularisation methods (ridge, lasso, dropout) reduce variance while accepting a small increase in bias, often reducing overall test MSE.

The Validation Set Approach

We need to estimate test error without fitting a new model on test data. The simplest approach: split data into two parts before fitting.

1
Randomly split \(n\) observations into a training set (typically 60-80% of data) and a validation set (the rest).
2
Fit the model (or multiple competing models) on the training set only.
3
Evaluate each fitted model on the validation set. Compute validation MSE or error rate.
4
Select the model with the lowest validation error. Then (optionally) refit on all data before final deployment.

Advantages

  • Simple to implement
  • Fast: fits model only once
  • No assumptions needed

Disadvantages

  • High variance: result depends on the random split
  • Uses less data for training
  • Validation MSE overestimates true test MSE
Slide 9 of 16
Leave-One-Out Cross-Validation (LOOCV)
LOOCV Estimate
\[ \text{CV}_{(n)} = \frac{1}{n}\sum_{i=1}^{n}\bigl(y_i - \hat{f}^{(-i)}(x_i)\bigr)^2 \]

where \(\hat{f}^{(-i)}\) is the model fitted on all \(n-1\) observations excluding \((x_i, y_i)\).

Advantages

  • Uses almost all data for each fit
  • Low bias in error estimate
  • Deterministic: no randomness
  • For OLS: computed in one fit using the hat matrix

Disadvantages

  • Fits \(n\) models: expensive for large \(n\)
  • High variance: each fold's training sets are almost identical, so errors are correlated
Shortcut for Linear Models

For ordinary least squares: \[ \text{CV}_{(n)} = \frac{1}{n}\sum_{i=1}^n \left(\frac{y_i - \hat{y}_i}{1 - h_{ii}}\right)^2 \] where \(h_{ii}\) is the \(i\)th diagonal of the hat matrix \(\mathbf{H} = \mathbf{X}(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\). Only one model fit needed.

Slide 10 of 16
K-Fold Cross-Validation
K-Fold CV Estimate
\[ \text{CV}_{(K)} = \frac{1}{K}\sum_{k=1}^{K}\text{MSE}_k \quad \text{where} \quad \text{MSE}_k = \frac{1}{n_k}\sum_{i \in C_k}(y_i - \hat{f}^{(-k)}(x_i))^2 \]
1
Randomly divide the \(n\) observations into \(K\) roughly equal folds.
2
For fold \(k = 1,\ldots,K\): fit the model on all folds except \(k\), then compute \(\text{MSE}_k\) on fold \(k\).
3
Average the \(K\) errors: \(\text{CV}_{(K)} = \frac{1}{K}\sum_k \text{MSE}_k\).
Choosing K

K = 5 or K = 10 is standard. K = 10 gives a good bias-variance balance: lower bias than K = 5, manageable variance, and feasible computation. LOOCV is K = n and has high variance. Stratified K-fold is preferred for classification to maintain class proportions in each fold.

Why K-Fold beats Validation Set

Averaging over \(K\) folds reduces the variance of the error estimate substantially compared to a single train/validation split.

The 1-Standard-Error Rule

CV gives not just a mean error but also a standard error for each model. For each complexity level \(d\) (e.g., polynomial degree or number of features):

Standard Error of CV Estimate
\[ \widehat{SE}\bigl(\text{CV}_{(K)}^{(d)}\bigr) = \sqrt{\frac{1}{K}\sum_{k=1}^K \frac{(\text{MSE}_k^{(d)} - \overline{\text{MSE}}^{(d)})^2}{K-1}} \]
The 1-SE Rule

Choose the simplest model whose CV error is within one standard error of the minimum CV error. That is, find \(d^* = \arg\min_d \text{CV}^{(d)}\), then choose the simplest \(d\) such that \(\text{CV}^{(d)} \leq \text{CV}^{(d^*)} + \widehat{SE}^{(d^*)}\).

Why prefer a simpler model?
  • Lower variance in predictions
  • More interpretable (useful for inference)
  • Difference in test error is within statistical noise
  • More stable under slight data changes

Classification: Error Rate and Bayes Classifier

For classification, \(Y\) is categorical. The natural quality measure is the error rate (fraction of misclassified observations).

Training Error Rate
\[ \frac{1}{n}\sum_{i=1}^{n}\mathbf{1}(y_i \neq \hat{y}_i) \]
Test Error Rate
\[ E\bigl[\mathbf{1}(y_0 \neq \hat{y}_0)\bigr] \]
Bayes Classifier (Optimal Decision Rule)

Assign observation \(x_0\) to class \(j\) that maximises \(P(Y = j \mid X = x_0)\). The Bayes error rate is \(1 - E[\max_j P(Y=j \mid X)]\), which is the irreducible error for classification. No classifier can do better in expectation.

Why not just minimise training error rate?

A 1-nearest-neighbour classifier achieves 0% training error: every training point is its own nearest neighbour and is classified correctly. But its test error is often much higher than simpler classifiers because of very high variance.

In-Class Exercise
Scenario 1
A company has 500 customer records and wants to pick between linear discriminant analysis, logistic regression, and KNN (K = 1, 5, 10, 15). They want a reliable error estimate. Design the full evaluation pipeline: type of CV, value of K, and metric.
CV type: Stratified 10-fold CV. With n = 500 stratified folds preserve class balance in each fold. 10 folds give good bias-variance balance.

Pipeline: (1) For each candidate model (LDA, logistic, KNN with K = 1, 5, 10, 15): run 10-fold CV and record mean CV error rate and SE. (2) Select the model with lowest mean CV error, or apply the 1-SE rule to prefer a simpler model within one SE of the minimum. (3) Refit the chosen model on all 500 records before deployment.

Metric: Error rate (fraction misclassified). If classes are imbalanced, also report AUC or F1.
Scenario 2
A research team computes 5-fold CV for polynomial regression of degrees 1 to 8. Minimum CV error is 12.4 at degree 5, SE = 1.3. Degrees 3 and 4 have CV errors 13.2 and 12.9. Which degree does the 1-SE rule select? Justify.
Threshold = 12.4 + 1.3 = 13.7.

Check each degree in increasing order of simplicity: degree 3 has CV = 13.2 \(\leq\) 13.7. Degree 4 has CV = 12.9 \(\leq\) 13.7. Both qualify. The 1-SE rule picks the simplest qualifying model.

Answer: degree 3. It is within one SE of the minimum, and it is simpler and more interpretable than degrees 4 or 5. The difference in CV error (13.2 vs 12.4) is within statistical noise.
Scenario 3
True or false: "If a model has lower training error than another model, it will always have lower test error." Explain.
False. Lower training error often means higher flexibility. A very flexible model can memorise the training data (training error near 0) while performing poorly on new data because of high variance. For example, a degree-15 polynomial may have lower training error than a degree-3 polynomial yet much higher test error. What matters for deployment is test error, not training error.
Scenario 4
A model has training MSE = 4 and test MSE = 40. What does this gap tell you? What would you check or change?
Diagnosis: The 10-fold gap between training and test MSE is a classic overfitting signature. The model memorised the training data (near-zero error there) but does not generalise, indicating very high variance.

What to check and change:
(1) Regularise: add ridge or lasso penalty, or dropout for neural networks, to reduce variance.
(2) Reduce complexity: lower polynomial degree, prune a decision tree, or reduce the number of hidden units.
(3) Get more training data: variance typically falls as n grows.
(4) Use cross-validation to select the regularisation strength or model complexity objectively.

Practice Problems
Problem 1
Model A: training MSE = 2, test MSE = 45. Model B: training MSE = 18, test MSE = 22.
(a) Which model has a larger bias-variance gap? What does this suggest?
(b) Which model would you choose for deployment and why?
(c) Name two concrete actions to reduce the test MSE of Model A.
(a) Model A gap = 43, Model B gap = 4. Model A is severely overfitting: it memorised training data but does not generalise. Model B underfits slightly but generalises consistently.

(b) Model B. What matters in deployment is test MSE (22 vs 45). The lower training MSE of Model A is irrelevant once deployed.

(c) (i) Regularise Model A (ridge, lasso, or dropout) to reduce variance. (ii) Reduce complexity (fewer parameters, lower polynomial degree, or tree pruning).
Problem 2
Write out the complete 5-fold CV algorithm for selecting polynomial degree on n = 100 observations. Be specific: what is fitted on each fold, what is computed, and what is the final selection criterion?
Step 1. Randomly partition 100 observations into 5 folds \(C_1,\ldots,C_5\), each of size 20.

Step 2. For each degree \(d\) and fold \(k\): fit polynomial of degree \(d\) on 80 training points, compute \(\text{MSE}_k^{(d)} = \frac{1}{20}\sum_{i\in C_k}(y_i - \hat{f}^{(-k)}(x_i))^2\).

Step 3. Average: \(\text{CV}_{(5)}^{(d)} = \frac{1}{5}\sum_k \text{MSE}_k^{(d)}\).

Step 4. Select \(d^* = \arg\min_d \text{CV}_{(5)}^{(d)}\), or apply 1-SE rule. Optionally refit on all 100 observations at \(d^*\).
Problem 3
The bias-variance decomposition: \(E[(y_0-\hat{f}(x_0))^2]=\text{Bias}^2+\text{Var}+\sigma^2\).
(a) Bias\(^2\)=16, Var=9, \(\sigma^2\)=4. Compute expected test MSE.
(b) Bias\(^2\) drops to 4 but Var rises to 20. Is this an improvement?
(c) Can we ever achieve \(E[(y_0-\hat{f}(x_0))^2]=0\)? Explain.
(a) Test MSE = 16+9+4 = 29.

(b) New Test MSE = 4+20+4 = 28. Marginally better, but barely. The large variance increase almost cancels the bias reduction.

(c) No. The irreducible error \(\sigma^2=\operatorname{Var}(\varepsilon)>0\) remains even if \(\hat{f}=f\). No model can achieve expected squared error below \(\sigma^2\).
Problem 4
10-fold CV for KNN (K=3,5,7,9,11) on n=200 gives CV errors: 22.1%, 18.4%, 16.2%, 15.8%, 16.9% with SEs: 2.2, 2.0, 1.8, 1.7, 1.6.
(a) Which K minimises CV error?
(b) Apply the 1-SE rule. What is the threshold? Which K do you choose?
(c) Why does the 1-SE rule prefer a larger K?
(a) K=9 with CV error 15.8%.

(b) Threshold = 15.8+1.7 = 17.5%. Largest K with CV \(\leq\) 17.5%: K=11 gives 16.9%. Choose K=11 by the 1-SE rule.

(c) Larger K averages over more neighbours, producing a smoother, lower-variance decision boundary. The accuracy sacrifice (16.9% vs 15.8%) is within statistical noise, while K=11 is more stable.

Key Takeaways
Training vs Test ErrorTraining MSE always decreases with flexibility. Test MSE follows a U-shape. Never evaluate a model on training data alone.
Bias-Variance DecompositionTest MSE = Bias\(^2\) + Variance + Irreducible. As flexibility rises, bias falls and variance rises.
OverfittingLow training error with high test error. Caused by too much flexibility relative to data size.
UnderfittingBoth training and test error are high. Model is too simple to capture the true pattern.
K-Fold CVK = 10 is the standard choice. Fits \(K\) models, averages errors. Better than a single validation split.
1-SE RulePick the simplest model within one SE of the minimum CV error. Favours interpretability without meaningfully worse accuracy.
ClassificationError rate replaces MSE. Bayes classifier is optimal. 1-NN achieves 0% training error but often overfits badly.
