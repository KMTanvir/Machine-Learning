What is Statistical Machine Learning?

We observe inputs \(\mathbf{X} = (X_1, X_2, \ldots, X_p)\) and an output \(Y\). We assume a relationship:

The Core Model
\[ Y = f(\mathbf{X}) + \varepsilon \]
What each symbol means
  • \(Y\): the response variable we want to understand or predict
  • \(\mathbf{X} = (X_1, \ldots, X_p)\): the \(p\) input features (predictors)
  • \(f(\mathbf{X})\): the unknown true function linking inputs to output
  • \(\varepsilon\): random error term, independent of \(\mathbf{X}\), with \(E[\varepsilon]=0\)
The Problem

We never observe \(f\) directly. From training data \(\{(x_i,y_i)\}_{i=1}^{n}\) we estimate \(f\) with \(\hat{f}\), then predict \(\hat{Y} = \hat{f}(\mathbf{X})\).

Slide 3 of 14
Reducible vs Irreducible Error
Error Decomposition
\[ E\!\left[(Y - \hat{Y})^2\right] = \underbrace{\!\left[f(\mathbf{X}) - \hat{f}(\mathbf{X})\right]^2}_{\text{Reducible}} + \underbrace{\,\operatorname{Var}(\varepsilon)\,}_{\text{Irreducible}} \]

Reducible Error

  • Because \(\hat{f} \neq f\) in general
  • Reduced by better methods or more data
  • This is what we try to minimise

Irreducible Error

  • Due to noise \(\varepsilon\) in the process
  • Cannot be reduced even if \(\hat{f} = f\)
  • Sets a lower bound on prediction error
Key Insight

Zero training error does not mean a good model. Even a perfect model makes errors because of \(\varepsilon\). Zero training error usually means the model memorised the training data.

Goal 1: Prediction
We want to predict Y accurately for new observations

Treat \(\hat{f}\) as a black box. The exact form of \(\hat{f}\) does not matter, only accuracy matters.

Examples
  • Medical: Given blood tests \(\mathbf{X}\), predict whether patient has cancer \(Y\). We need accuracy, not which test matters most.
  • Finance: Predict tomorrow's stock price from today's market data.
  • Security: Predict if a transaction is fraudulent \((Y \in \{0,1\})\).
AspectPrediction setting
Model formDoesn't matter, black box is fine
Key metricTest MSE (regression) or test error rate (classification)
InterpretabilityNot required

Goal 2: Inference
We want to understand HOW inputs X affect output Y

The exact form of \(\hat{f}\) matters. We must interpret coefficients and test hypotheses.

Inference Questions
  • Which \(X_j\) matter? Variable selection
  • Direction and size: Does increasing \(X_j\) raise or lower \(Y\)? By how much?
  • Functional form: Is the \(X_j \to Y\) relationship linear or nonlinear?
Examples
  • Marketing: How do TV, radio, newspaper budgets each affect sales? Which gives best return?
  • Public health: Which risk factors are most strongly linked to heart disease?
  • Economics: How does education affect wages, controlling for experience?

For inference we prefer simple, interpretable models (e.g., linear regression) even if a black box would be more accurate.

Parametric vs Nonparametric

Parametric

  • Assume a form: \(f(\mathbf{X}) = \beta_0 + \beta_1 X_1 + \cdots\)
  • Estimate finite set of parameters
  • Simple, interpretable, needs less data
  • Risk: wrong assumed form
  • Examples: Linear regression, logistic regression

Nonparametric

  • No assumed form for \(f\)
  • Data determines the shape
  • Fits complex patterns
  • Needs much more data, may overfit
  • Examples: KNN, decision trees, random forests
The Flexibility, Interpretability Tradeoff

More flexible models fit complex patterns but are harder to interpret and more prone to overfitting. This tradeoff runs through the entire course.

Supervised vs Unsupervised

Supervised

  • Observe both \(\mathbf{X}\) and \(Y\)
  • Training data: \(\{(x_i, y_i)\}_{i=1}^n\)
  • Goal: learn \(f: \mathbf{X} \to Y\)
  • \(Y\) supervises the learning
  • Examples: Regression, classification

Unsupervised

  • Observe only \(\mathbf{X}\), no \(Y\)
  • Training data: \(\{x_i\}_{i=1}^n\)
  • Goal: find hidden structure in \(\mathbf{X}\)
  • No correct answer to guide learning
  • Examples: K-means, PCA, clustering
SupervisedUnsupervised
Labels needed?Yes, \(Y\) requiredNo, only \(\mathbf{X}\)
GoalPredict or explain \(Y\)Discover structure in \(\mathbf{X}\)
EvaluationCompare \(\hat{Y}\) to true \(Y\)Harder, no ground truth

Regression vs Classification

Regression

  • \(Y\) is quantitative (continuous)
  • Output is a real number
  • Examples: salary, temperature, price
  • Ask: "How much?" or "How many?"
  • Metrics: MSE, RMSE, R\(^2\)

Classification

  • \(Y\) is qualitative (categorical)
  • Output is a class label
  • Examples: spam or not-spam, disease type
  • Ask: "Which category?"
  • Metrics: Accuracy, F1, ROC-AUC
Rule

Always look at \(Y\). If it is continuous, use regression. If it is categorical, use classification. Logistic regression predicts a probability but classifies into a category, so it is a classification method.

Worked Example 2: Same Data, Different Goals
Advertising data: TV, radio, newspaper spend vs sales, n = 200 weeks
Setting

\(X_1\) = TV spend, \(X_2\) = Radio spend, \(X_3\) = Newspaper spend (in $000s), \(Y\) = Sales (units). Three different questions from the same dataset:

Q1
Forecast next week's sales to order enough stock.
PREDICTION. Need accurate \(\hat{Y}\). Black box (XGBoost, random forest) is fine.
Q2
Which channel gives the best return on investment?
INFERENCE. Need to read \(\hat{\beta}_1, \hat{\beta}_2, \hat{\beta}_3\). Interpretable linear model required.
Q3
Does TV advertising work better when radio spend is also high?
INFERENCE. Must test interaction term \(\beta_{12} X_1 X_2\). Black-box models cannot answer this.
Key Takeaway

The same dataset can address prediction and inference questions. The goal determines the model choice.

In-Class Exercise
For each scenario: (a) supervised or unsupervised, (b) regression or classification if supervised, (c) prediction or inference, (d) parametric or nonparametric
Scenario 1
A university predicts whether an applicant will enrol (Yes or No) from test score, GPA, and family income.
(a) Supervised: we have labelled outcomes (enrolled or not). (b) Classification: Y is binary (Yes/No). (c) Prediction: the university wants accurate forecasts for future applicants. (d) Either parametric (logistic regression) or nonparametric (KNN, decision tree) is fine since the goal is prediction, not explanation.
Scenario 2
A music service groups 10 million songs into thematic clusters to improve recommendations. No genre labels exist.
(a) Unsupervised: no label Y, only audio features X. (b) Not applicable: regression/classification require a Y. The task is clustering. (c) Not applicable: prediction/inference also require Y. The goal is to discover hidden structure. (d) Nonparametric: K-means or hierarchical clustering make no parametric assumption about f.
Scenario 3
An economist measures the causal effect of a minimum wage increase on unemployment, controlling for other factors.
(a) Supervised: Y = unemployment rate (or change in unemployment), X includes minimum wage and controls. (b) Regression: Y is continuous. (c) Inference: the economist wants to quantify the specific effect of minimum wage, not just predict Y for new values. (d) Parametric: a linear or log-linear regression model is required to read and interpret the coefficient on minimum wage directly.
Scenario 4
A hospital predicts the number of days a patient will stay after surgery, from age, diagnosis code, and surgical complexity.
(a) Supervised: Y = length of stay (a number), X = patient and surgery features. (b) Regression: Y is a count/continuous quantity. (c) Prediction: the hospital wants accurate forecasts to allocate beds and staff. (d) Either works: parametric (linear regression, Poisson regression) or nonparametric (random forest, gradient boosting). Since the goal is prediction accuracy, a flexible nonparametric method is often preferred.

Practice Problems
Problem 1
For each scenario, state (i) supervised or unsupervised, (ii) regression or classification if supervised, (iii) prediction or inference.
  1. Predicting a student's final exam score from attendance, assignment marks, and mid-term score.
  2. Grouping news articles by topic with no predefined categories.
  3. Detecting fraudulent bank transactions (fraud = yes or no).
  4. Estimating the market value of houses from size, location, and age.
  1. Supervised, Regression, Prediction. Y = exam score (continuous). Goal: accurate prediction for future students.
  2. Unsupervised. No label Y. Goal: find groups in X alone. Regression/classification and prediction/inference do not apply.
  3. Supervised, Classification, Prediction. Y ∈ {fraud, not-fraud} (categorical). Goal: accurate labelling of new transactions.
  4. Supervised, Regression, Prediction. Y = house value (continuous). If the goal were "which features drive price?" it would be inference instead.
Problem 2
Model: Crop Yield = \(f\)(Rainfall, Temperature, Fertiliser) + \(\varepsilon\).
(a) What does \(f\) represent in words?
(b) Give two reasons why \(\varepsilon \neq 0\) even with perfect \(f\).
(c) A farmer says doubling fertiliser doubles yield. When is this approximately true? When is it wrong?
(a) \(f\) is the systematic, non-random part: the expected crop yield given fixed values of rainfall, temperature, and fertiliser. It captures the true underlying relationship.

(b) (i) Random within-season weather fluctuations not captured by average temperature or rainfall. (ii) Unmeasured variables such as soil quality, pest pressure, and seed variety that affect yield but are absent from the model.

(c) Approximately true if \(f\) is linear in fertiliser over the relevant range. Wrong when fertiliser is at saturation (diminishing returns), or excess fertiliser damages the crop (non-monotone relationship).
Problem 3
A data scientist says: "I achieved 100% accuracy on my training data, so my model is perfect." Identify two statistical problems and explain how you would address each.
Problem 1: Overfitting. A flexible model can memorise training data and achieve perfect training accuracy while performing poorly on new data. Fix: evaluate on a held-out test set or use cross-validation.

Problem 2: Class imbalance. If only 1% of observations are in the positive class, a model that always predicts "negative" achieves 99% training accuracy without learning anything useful. Fix: report precision, recall, F1, or ROC-AUC instead of raw accuracy.
Problem 4
(a) Why might a doctor prefer a simpler interpretable model over a more accurate black-box model?
(b) What is the difference between \(f(\mathbf{X})\) and \(\hat{f}(\mathbf{X})\)? Which do we actually use?
(c) If \(\operatorname{Var}(\varepsilon) = 25\), what is the lowest possible expected squared prediction error?
(a) Doctors need to explain diagnoses to patients, verify alignment with medical knowledge, and ensure legal and ethical accountability. A black-box model provides no justification.

(b) \(f(\mathbf{X})\) is the unknown true function that exists in nature but cannot be observed. \(\hat{f}(\mathbf{X})\) is our estimate learned from training data. We use \(\hat{f}\) in practice.

(c) Minimum \(E[(Y-\hat{Y})^2] = \operatorname{Var}(\varepsilon) = 25\). Even with a perfect \(\hat{f} = f\), the irreducible error remains. No model achieves expected squared error below 25.

Key Takeaways
The Statistical Model\(Y = f(\mathbf{X}) + \varepsilon\). Error = reducible + irreducible. Irreducible error is unavoidable.
Prediction vs InferencePrediction: maximise accuracy of \(\hat{Y}\). Inference: understand \(X_j \to Y\). Same data, different model choices.
Parametric vs NonparametricParametric: assume form, estimate parameters, interpretable. Nonparametric: no form assumed, flexible, risk of overfitting.
Supervised vs UnsupervisedSupervised: labels \(Y\) exist. Unsupervised: only \(\mathbf{X}\), find hidden structure.
Regression vs Classification\(Y\) continuous: regression. \(Y\) categorical: classification.
