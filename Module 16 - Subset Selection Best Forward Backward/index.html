Module 16: Subset Selection

Module 16

Subset Selection: Best, Forward, Backward

When $p$ predictors are available, which ones should enter the model? Subset selection methods search the space of possible models to find the subset of predictors that best explains the response, while penalising complexity to avoid overfitting.

The model selection problem With $p$ predictors there are $2^p$ possible linear regression models (each predictor included or not). For $p = 40$ that is over a trillion models. We need principled strategies to search this space and criteria to compare models of different sizes.

Learning Objectives

  • Implement best subset, forward stepwise, and backward stepwise selection
  • Understand the bias in training $R^2$, RSS, and MSE as model selection criteria
  • Apply Mallows' $C_p$, AIC, BIC, and adjusted $R^2$ for model comparison
  • Use cross-validation to select the optimal model size
  • Compare the computational and statistical properties of each method
Reference: ISLR Chapter 6.1; Module 06 (adjusted R², F-test, AIC)
Best Subset

Best Subset Selection

Best Subset Selection Algorithm
  1. Let $\mathcal{M}_0$ be the null model (intercept only).
  2. For $k = 1, 2, \ldots, p$: fit all $\binom{p}{k}$ models with exactly $k$ predictors. Let $\mathcal{M}_k$ be the best (lowest RSS) among them.
  3. Select the single best model from $\mathcal{M}_0, \mathcal{M}_1, \ldots, \mathcal{M}_p$ using a model selection criterion (not training RSS).

Why not choose the model with highest training $R^2$? Training $R^2$ increases monotonically with $k$: the model with all $p$ predictors always wins. We must penalise for model size to estimate test performance.
Forward Stepwise

Forward Stepwise Selection

Forward Stepwise Algorithm
  1. Start with $\mathcal{M}_0$ (intercept only).
  2. For $k = 0, 1, \ldots, p-1$: consider all $p-k$ models formed by adding one predictor to $\mathcal{M}_k$. Let $\mathcal{M}_{k+1}$ be the best (lowest RSS or highest $R^2$) among them.
  3. Select the best model from $\mathcal{M}_0, \mathcal{M}_1, \ldots, \mathcal{M}_p$ using a selection criterion.
Computational cost: fits $1 + p + (p-1) + \cdots + 1 = 1 + p(p+1)/2$ models. For $p=40$: 821 models vs. $10^{12}$ for best subset.
Limitation: forward stepwise is greedy: once a predictor is added it cannot be removed. It is not guaranteed to find the best subset of any given size. For example, the best 2-predictor model may not contain the predictor in the best 1-predictor model.
When to use Forward stepwise is the method of choice when $p$ is large ($p > 40$), when $n < p$ (where best subset is infeasible), or in any setting requiring a fast approximation to best subset selection.
Backward Stepwise

Backward Stepwise Selection

Backward Stepwise Algorithm
  1. Start with $\mathcal{M}_p$ (all $p$ predictors).
  2. For $k = p, p-1, \ldots, 1$: consider all $k$ models formed by removing one predictor from $\mathcal{M}_k$. Let $\mathcal{M}_{k-1}$ be the best (lowest RSS) among them.
  3. Select the best model from $\mathcal{M}_0, \mathcal{M}_1, \ldots, \mathcal{M}_p$ using a selection criterion.
Requirement Backward stepwise requires $n > p$: the full model must be estimable. It cannot be used when $p \geq n$.
Greedy limitation Like forward stepwise, backward selection is greedy: once a predictor is removed it cannot return. The models $\mathcal{M}_{k-1}$ through $\mathcal{M}_0$ need not contain the globally best subsets of those sizes.

Hybrid Approaches

Hybrid (bidirectional) stepwise combines forward and backward steps: at each stage add the best available predictor, then consider dropping any existing predictor that no longer improves the criterion. More thorough than either pure method but still not guaranteed to find the global optimum.

Selection Criteria

Choosing Among Models of Different Sizes

After obtaining $\mathcal{M}_0, \ldots, \mathcal{M}_p$, we need a criterion to pick the best model that is not simply training RSS.

Mallows' $C_p$ $$C_p = \frac{1}{n}\bigl(\mathrm{RSS} + 2k\hat\sigma^2\bigr)$$ where $k$ is the number of predictors in the model and $\hat\sigma^2$ is estimated from the full $p$-predictor model. Selects the model with minimum $C_p$.
AIC (Akaike Information Criterion) $$\mathrm{AIC} = -2\log L + 2k$$ For OLS regression with normal errors, $\mathrm{AIC} \propto C_p$. Selects minimum AIC.
BIC (Bayesian Information Criterion) $$\mathrm{BIC} = -2\log L + k\log n = \frac{1}{n}(\mathrm{RSS} + k\hat\sigma^2\log n)$$ BIC penalises model size more heavily than AIC for $n > e^2 \approx 7.4$. BIC is more consistent: it selects the true model as $n\to\infty$; AIC tends to overfit asymptotically.
Adjusted $R^2$ $$\bar{R}^2 = 1 - \frac{\mathrm{RSS}/(n-k-1)}{\mathrm{TSS}/(n-1)}$$ Maximise adjusted $R^2$. Adding a useless predictor decreases $\bar R^2$.

One-standard-error rule for CV After computing CV error across model sizes, choose the smallest model whose CV error is within one SE of the minimum. This guards against selecting an unnecessarily complex model.
CV for Model Selection

Cross-Validation for Subset Selection

Correct procedure The entire subset selection procedure must be performed within each fold. That is:
  1. Split data into $k$ folds.
  2. For each fold $j$: run the full subset/stepwise selection on the other $k-1$ folds; evaluate the resulting models on fold $j$.
  3. Aggregate: for each model size, average the CV errors across all $k$ folds.
  4. Select the model size with lowest (or one-SE) CV error; refit that size on all data.
Common mistake: selection before CV Running subset selection on the full dataset first, then using CV only to evaluate the pre-selected model, leads to optimistic bias. Predictor selection on the full data has already peeked at the test folds.
This correct procedure is expensive: $k$ subset-selection runs instead of one. For large $p$, best subset selection within each fold may be infeasible. Forward stepwise within each fold is the practical compromise.

High-dimensional Issues

When $p$ is Large: Challenges and Alternatives

Multiple-testing inflation Best subset with $p = 20$ predictors tests over 1 million models. Even with a stringent selection criterion, the selected model is likely to contain spurious predictors. The effective number of tests inflates the false discovery rate.
$p \geq n$ regime When $p \geq n$, OLS is not unique (infinitely many solutions), so best subset and backward stepwise are infeasible. Forward stepwise stops when $k = n$ (saturated model). Regularisation methods (Module 17) are the appropriate tool for this regime.
Practical guidance
  • $p \leq 30$, prediction focus: best subset with CV
  • $p \leq 100$: forward or backward stepwise with BIC
  • $p > 100$ or $p \geq n$: ridge regression or lasso (Module 17)
In-Class Exercise

In-Class Exercise

A housing price dataset has $n = 100$ observations and $p = 4$ candidate predictors: area ($X_1$), bedrooms ($X_2$), distance to city ($X_3$), age ($X_4$). Forward stepwise produces the following sequence:

  • Step 1: Add $X_1$ (RSS drops from 8500 to 4200)
  • Step 2: Add $X_3$ (RSS drops to 3100)
  • Step 3: Add $X_4$ (RSS drops to 3010)
  • Step 4: Add $X_2$ (RSS drops to 2990)

$\hat\sigma^2 = 31.0$ from the full 4-predictor model.

  1. Compute $C_p$ for each model size $k = 0, 1, 2, 3, 4$. Use TSS $= 8500$ for the null model.
  2. Which model does $C_p$ select?
  3. Would backward stepwise have been feasible here? Would it guarantee the same result as forward stepwise?

1. $C_p = \frac{1}{n}(\mathrm{RSS} + 2k\hat\sigma^2)$ with $n=100$, $\hat\sigma^2=31.0$:
$k=0$: $(8500 + 0)/100 = 85.0$
$k=1$: $(4200 + 62)/100 = 42.62$
$k=2$: $(3100 + 124)/100 = 32.24$
$k=3$: $(3010 + 186)/100 = 31.96$
$k=4$: $(2990 + 248)/100 = 32.38$

2. $C_p$ is minimised at $k=3$ (value 31.96). Select the model with $X_1, X_3, X_4$.

3. Backward stepwise requires $n > p$: here $n=100 > p=4$, so yes, it is feasible. However, backward stepwise is not guaranteed to produce the same sequence as forward stepwise. In this small-$p$ case, running best subset selection (only $2^4 = 16$ models) would be computationally trivial and would guarantee finding the true best subset of each size.

Practice Problems

Practice Problems

Problem 1: Conceptual
  1. Explain why training RSS always decreases (never increases) as more predictors are added in best subset selection.
  2. A researcher reports: "I ran forward stepwise and found a 3-predictor model with the lowest BIC. I then confirmed this was the best 3-predictor model." Is the second claim necessarily true? Explain.
  3. True or False: BIC always selects a model with fewer predictors than AIC on the same data.

a. OLS minimises RSS over the coefficient vector. When a predictor is added, the model has strictly more parameters, so the minimiser of RSS over the expanded set can always achieve at least as low a value as before (it can always set the new coefficient to zero). Hence RSS is non-increasing, and for continuous predictors not perfectly collinear with the response, it strictly decreases.

b. No. Forward stepwise does not search all $\binom{4}{3}$ possible 3-predictor subsets (in this case 4 subsets). It is greedy: the three predictors in the forward stepwise 3-predictor model are determined by the sequence of previous additions, not by comparing all 3-predictor models. The best 3-predictor model (in terms of RSS) may use a different set of predictors.

c. False. BIC penalties are heavier than AIC for $n > e^2 \approx 7$, so BIC tends to select smaller models. But this is a tendency, not a guarantee: it is possible for BIC and AIC to select the same model, and on a particular dataset BIC could select a model of the same or (extremely rarely) larger size than AIC.

Problem 2: Calculation

$n = 40$, $p = 3$. Best subset selection gives the following models:

$k$PredictorsRSS
0(none)560
1$X_2$320
2$X_1, X_2$260
3$X_1, X_2, X_3$248

The full 3-predictor model has $\hat\sigma^2 = 248/(40-4) = 6.889$.

  1. Compute $C_p$ for $k = 0, 1, 2, 3$.
  2. Compute BIC for $k = 0, 1, 2, 3$ using $\mathrm{BIC} = \frac{1}{n}(\mathrm{RSS} + k\hat\sigma^2\log n)$.
  3. Which model does each criterion select?

a. $C_p = \frac{1}{40}(\mathrm{RSS} + 2k \times 6.889)$, penalty per predictor $= 2 \times 6.889 = 13.778$:
$k=0$: $(560+0)/40 = 14.00$
$k=1$: $(320+13.78)/40 = 333.78/40 = 8.34$
$k=2$: $(260+27.56)/40 = 287.56/40 = 7.19$
$k=3$: $(248+41.33)/40 = 289.33/40 = 7.23$

b. $\log(40) \approx 3.689$, BIC penalty per predictor $= 6.889 \times 3.689 = 25.42$:
$k=0$: $(560+0)/40 = 14.00$
$k=1$: $(320+25.42)/40 = 8.64$
$k=2$: $(260+50.83)/40 = 7.77$
$k=3$: $(248+76.25)/40 = 8.11$

c. $C_p$ selects $k=2$ (value 7.19). BIC also selects $k=2$ (value 7.77). Both agree: the 2-predictor model $\{X_1, X_2\}$ is optimal. Adding $X_3$ does not reduce RSS enough to justify the extra penalty.

Problem 3: Conceptual
  1. Why must the subset selection procedure be repeated within each cross-validation fold, rather than selecting predictors on the full data and then applying CV?
  2. A dataset has $n = 30$ observations and $p = 35$ predictors. Which subset selection method(s) can be applied? Justify.

a. If selection is done on the full data first, the chosen predictors have already been informed by the validation observations in each fold. The CV error estimate will be optimistically biased because the model has implicitly "seen" the validation data during predictor selection. To get an honest estimate, selection must happen independently within each fold's training set.

b. Best subset is infeasible: $2^{35} \approx 3.4 \times 10^{10}$ models. Backward stepwise requires $n > p$: here $n=30 < p=35$, so the full model is not estimable; backward stepwise cannot start. Forward stepwise can be applied: start with the null model and add predictors one at a time (stopping before the model becomes saturated at $k=n=30$). However, regularisation methods (ridge, lasso) are more appropriate when $p > n$.
