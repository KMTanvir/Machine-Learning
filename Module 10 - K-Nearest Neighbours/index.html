Module 10: K-Nearest Neighbours

Module 10

K-Nearest Neighbours (KNN)

KNN is the simplest non-parametric classifier. It makes no assumptions about the form of the decision boundary and requires no model fitting: classification is entirely based on the training data.

KNN Classifier To classify a new point $\mathbf{x}_0$: find the $K$ training observations closest to $\mathbf{x}_0$ (the neighbourhood $\mathcal{N}_0$), then assign $\mathbf{x}_0$ to the most common class among its $K$ neighbours: $$P(Y = j \mid \mathbf{X} = \mathbf{x}_0) = \frac{1}{K}\sum_{i \in \mathcal{N}_0} \mathbf{1}(y_i = j)$$ Predict class $\hat y_0 = \arg\max_j P(Y = j \mid \mathbf{X} = \mathbf{x}_0)$.

Learning Objectives

  • Apply the KNN decision rule
  • Understand the effect of $K$ on bias, variance, and the decision boundary
  • Recognise the curse of dimensionality
  • Compare KNN with parametric classifiers
  • Apply KNN to regression problems
Algorithm

The KNN Algorithm

KNN Classification Algorithm
  1. Choose $K$ (the number of neighbours)
  2. For a new point $\mathbf{x}_0$, compute the distance to every training point
  3. Identify $\mathcal{N}_0$: the $K$ training points closest to $\mathbf{x}_0$
  4. Estimate $P(Y = j \mid \mathbf{x}_0) = \frac{|\{i \in \mathcal{N}_0 : y_i = j\}|}{K}$ for each class $j$
  5. Assign $\mathbf{x}_0$ to the class with the highest estimated probability
Most common distance metric: Euclidean distance $$d(\mathbf{x}, \mathbf{x}') = \|\mathbf{x} - \mathbf{x}'\|_2 = \sqrt{\sum_{j=1}^p (x_j - x_j')^2}$$ Other metrics: Manhattan, Minkowski, Mahalanobis (accounts for feature correlations).
Scale matters! Features with large ranges dominate Euclidean distance. Always standardise features (subtract mean, divide by SD) before applying KNN.
Effect of K

The Effect of K: Bias-Variance Tradeoff

Small $K$ (e.g., $K=1$):
  • Very flexible decision boundary
  • Low bias, high variance
  • Overfits: sensitive to noise
  • $K=1$: training error = 0 (always predicts its own label)
Large $K$ (e.g., $K=n$):
  • Very smooth decision boundary
  • High bias, low variance
  • Underfits: boundary approaches the majority class prediction
  • $K=n$: always predicts the most common class
Optimal $K$: Somewhere in between. As $K$ increases, boundary becomes smoother and less wiggly. Choose $K$ by cross-validation: minimise validation error over a grid of $K$ values.
The test error typically forms a U-shape as a function of $1/K$ (flexibility). The minimum gives the optimal $K$.

KNN Regression

KNN for Regression

KNN can also predict quantitative responses by averaging the $K$ nearest neighbours' values.

KNN Regression: $$\hat f(\mathbf{x}_0) = \frac{1}{K} \sum_{i \in \mathcal{N}_0} y_i$$
Advantages:
  • Flexible: can capture non-linear $f$
  • No assumptions about functional form
  • Simple to understand and implement
Disadvantages:
  • Slow at prediction time ($O(n)$ per query)
  • No interpretable model equation
  • Struggles in high dimensions (curse of dimensionality)
  • Sensitive to irrelevant features
KNN regression with $K=1$ interpolates the training data exactly. As $K$ increases, the fit smooths toward the overall mean.
Curse of Dimensionality

The Curse of Dimensionality

Problem: As the number of features $p$ increases, the $K$ nearest neighbours become increasingly far away from $\mathbf{x}_0$. The neighbourhood is no longer local, and the estimate $\hat f(\mathbf{x}_0)$ is based on points that are not actually near $\mathbf{x}_0$.
Illustration: Suppose features are uniform on $[0,1]^p$. To capture a fraction $r$ of the training data, you need a hypercube of side length $r^{1/p}$.
  • $p=1$, $r=0.1$: side $= 0.1$ (very local)
  • $p=2$, $r=0.1$: side $= 0.316$
  • $p=10$, $r=0.1$: side $= 0.794$ (80% of each axis!)
In high dimensions, "nearest" neighbours are not close at all.
This is why KNN works well with $p \leq 4$ predictors but degrades rapidly for larger $p$. In high dimensions, parametric models (which make strong assumptions to reduce variance) typically outperform KNN.

Choosing K

Choosing K by Cross-Validation

The key hyperparameter in KNN is $K$. Too small overfits; too large underfits.

Procedure:
  1. Choose a grid of $K$ values (e.g., $K = 1, 3, 5, 7, \ldots, 51$)
  2. For each $K$, estimate test error by $k$-fold cross-validation
  3. Select $K^*$ that minimises the CV error
  4. Refit on the full training data with $K^*$
It is conventional to use odd values of $K$ for binary classification to avoid ties. Also note: the $K$ in KNN is completely different from the $k$ in $k$-fold CV.
Do not use training error to choose $K$: $K=1$ always gives zero training error but is the worst choice for generalisation. Always use held-out validation or cross-validation.

Practice Problems

Practice Problems

Problem 1: KNN Regression

Training data: $(x_1,y_1)=(1,2)$, $(2,4)$, $(3,5)$, $(4,3)$, $(5,7)$.

  1. Predict $\hat f(3.5)$ using $K=1$, $K=2$, $K=3$.
  2. Which $K$ gives the smoothest estimate? Why?

a. Distances from 3.5: $|3{-}3.5|=0.5$, $|4{-}3.5|=0.5$, $|2{-}3.5|=1.5$, $|5{-}3.5|=1.5$, $|1{-}3.5|=2.5$.

$K{=}1$: nearest point is 3 or 4 (tie; take 3, $y{=}5$) $\Rightarrow\hat f=5$. $K{=}2$: points 3,4 ($y{=}5,3$) $\Rightarrow\hat f=4$. $K{=}3$: points 3,4,2 ($y{=}5,3,4$) $\Rightarrow\hat f=4$.

b. Larger $K$ smooths more; $K{=}3$ gives the smoothest estimate here.

Problem 2: Effect of K

A KNN classifier gives training error 0% and test error 35% with $K=1$. With $K=15$ it gives training error 12% and test error 18%.

  1. Which value of $K$ shows overfitting? Explain.
  2. Which value is likely better for a new dataset? Why?
  3. What would you expect if $K = n$ (all training points)?

a. $K{=}1$: zero training error is a hallmark of overfitting; test error 35% is very high.

b. $K{=}15$: lower test error (18%) indicates better generalisation; preferred.

c. $K{=}n$: the model predicts the same value (mean/majority class) for every point, equivalent to the null model. High bias, zero variance.

Problem 3: Curse of Dimensionality

Features are uniform on $[0,1]^p$. We want the nearest 10% of training data to be "close" to a query point (within a hypercube of side $l$).

  1. Find the required side length $l$ for $p = 1$, $p = 5$, and $p = 20$.
  2. Interpret what this means for KNN in high dimensions.

a. $l=0.1^{1/p}$. $p{=}1$: $l=0.10$. $p{=}5$: $l=0.1^{0.2}\approx0.631$. $p{=}20$: $l=0.1^{0.05}\approx0.891$.

b. In 20 dimensions we must span 89\% of each axis to capture only 10\% of the data. Neighbours are no longer "near": the curse of dimensionality makes KNN unreliable in high dimensions unless $n$ is very large.

Problem 4: True or False
  1. KNN with $K=1$ always achieves zero training error.
  2. Standardising features before KNN is optional.
  3. Larger $K$ always leads to better test performance.
  4. KNN can only be used for classification, not regression.

a. True: with $K{=}1$, each training point is its own nearest neighbour.

b. False: KNN is distance-based; unscaled features dominate, so standardisation is essential.

c. False: larger $K$ increases bias; the optimal $K$ is selected by cross-validation.

d. False: KNN regression (averaging neighbour responses) is widely used.
