Module 11

Regression Metrics: MSE, RMSE, MAE, R²

We now begin Part D: Performance Measures. A model is only as useful as our ability to measure how well it performs. This module covers the standard metrics for evaluating regression models.

Central Question Given a fitted model $\hat{f}$ and test data $(x_i, y_i)$, how do we summarise the gap between predictions $\hat{y}_i$ and true values $y_i$?

Learning Objectives

  • Define and compute MSE, RMSE, and MAE
  • Explain the properties and differences between these metrics
  • Interpret $R^2$ and adjusted $R^2$ correctly
  • Choose the appropriate metric for a given problem
Reference: ISLR Chapter 2.2, Chapter 3.5
Motivation

Why Metrics Matter

Every metric encodes a different loss function: a different answer to "what counts as a mistake and how much?"

Example: House price prediction
  • Predicting 400k when true value is 500k: error = 100k
  • Predicting 200k when true value is 500k: error = 300k
  • MSE penalises the second error 9× more than the first
  • MAE penalises it exactly 3× more
No universal best metric
  • MSE: penalises large errors heavily (outlier sensitive)
  • MAE: treats all errors proportionally (robust)
  • $R^2$: relative measure, scale-free
  • Choice depends on the cost structure of your application
Notation $n$ observations, true values $y_1,\ldots,y_n$, predictions $\hat{y}_1,\ldots,\hat{y}_n$, residuals $e_i = y_i - \hat{y}_i$.
MSE

Mean Squared Error

Mean Squared Error $$\mathrm{MSE} = \frac{1}{n}\sum_{i=1}^n (y_i - \hat{y}_i)^2 = \frac{1}{n}\sum_{i=1}^n e_i^2$$

Properties

  • Always non-negative; MSE $= 0$ only if all predictions are perfect
  • Units are squared (e.g., dollars² if $Y$ is in dollars): hard to interpret directly
  • Penalises large errors more than small ones (quadratic penalty)
  • Differentiable everywhere: convenient for optimisation (OLS minimises training MSE)
  • Sensitive to outliers: a single large error can dominate
Population vs Sample MSE
  • Training MSE: $\frac{1}{n}\sum_{i=1}^n(y_i - \hat{f}(x_i))^2$, always decreases as model complexity increases
  • Test MSE: $E[(y_0 - \hat{f}(x_0))^2]$ for new $(x_0,y_0)$: the quantity we actually care about
The bias-variance decomposition applies to test MSE: $\mathrm{Test\,MSE} = \mathrm{Bias}^2(\hat{f}) + \mathrm{Var}(\hat{f}) + \sigma^2$.
RMSE and MAE

RMSE and Mean Absolute Error

Root Mean Squared Error $$\mathrm{RMSE} = \sqrt{\mathrm{MSE}} = \sqrt{\frac{1}{n}\sum_{i=1}^n e_i^2}$$ Same units as $Y$. Directly comparable to $\bar{y}$.
Mean Absolute Error $$\mathrm{MAE} = \frac{1}{n}\sum_{i=1}^n |e_i|$$ Same units as $Y$. Median-optimal (minimised by the conditional median).

RMSE vs MAE

RMSE $\geq$ MAE always (Jensen's inequality). The ratio RMSE/MAE measures how much outliers inflate the error.
R-squared

R²: Coefficient of Determination

R² $$R^2 = 1 - \frac{\mathrm{RSS}}{\mathrm{TSS}} = 1 - \frac{\sum(y_i-\hat{y}_i)^2}{\sum(y_i-\bar{y})^2}$$ Proportion of variance in $Y$ explained by the model.
Interpretation
  • $R^2 = 1$: perfect predictions ($\hat{y}_i = y_i$ for all $i$)
  • $R^2 = 0$: model no better than predicting $\bar{y}$
  • $R^2 < 0$: model worse than the mean (possible on test data)
  • Scale-free: dimensionless and in $(-\infty, 1]$
Limitations
  • Always increases (or stays equal) as predictors are added
  • High $R^2$ does not mean good predictions out-of-sample
  • Sensitive to the range of $Y$ in the dataset
  • Does not detect non-linearity or heteroscedasticity
Adjusted R²

Adjusted R²

Adjusted R² $$\bar{R}^2 = 1 - \frac{\mathrm{RSS}/(n-p-1)}{\mathrm{TSS}/(n-1)} = 1 - (1-R^2)\frac{n-1}{n-p-1}$$ where $p$ is the number of predictors.

Adjusted $R^2$ penalises the addition of irrelevant predictors. Adding a predictor increases $\bar{R}^2$ only if the reduction in RSS more than offsets the loss of one degree of freedom.

$R^2$Adjusted $R^2$

Adjusted $R^2$ is one of several model-selection criteria. AIC and BIC (Module 05) are more principled alternatives because they are grounded in likelihood theory.
Metric Selection

Choosing the Right Metric

Variable number of predictorsAdjusted $R^2$, AIC, BICPenalises complexity
Mean Absolute Percentage Error (MAPE) $$\mathrm{MAPE} = \frac{100}{n}\sum_{i=1}^n \left|\frac{y_i - \hat{y}_i}{y_i}\right|$$ Useful when the scale of $Y$ varies widely. Undefined when $y_i = 0$.
Never use training error alone to select a model. Always evaluate on a held-out test set or via cross-validation (Module 14).
Bias-Variance

Metrics and the Bias-Variance Tradeoff

Decomposition of Expected Test MSE $$E\!\left[(y_0 - \hat{f}(x_0))^2\right] = \underbrace{\left[\mathrm{Bias}(\hat{f}(x_0))\right]^2}_{\text{reducible: bias}} + \underbrace{\mathrm{Var}(\hat{f}(x_0))}_{\text{reducible: variance}} + \underbrace{\sigma^2}_{\text{irreducible}}$$
  • Bias = error from wrong assumptions (underfitting)
  • Variance = sensitivity to training data fluctuations (overfitting)
  • Irreducible error $\sigma^2 = \mathrm{Var}(\varepsilon)$: a lower bound that no model can beat
Why test MSE is the right target: training MSE decreases monotonically as complexity increases. Test MSE forms a U-shape: it has a minimum at the optimal complexity. RMSE and $R^2$ on the test set share this property.
Overfitting signal: test MSE $\gg$ training MSE
Underfitting signal: both training and test MSE are high
RSE

Residual Standard Error

RSE (in regression context) $$\mathrm{RSE} = \sqrt{\frac{\mathrm{RSS}}{n - p - 1}} = \sqrt{\frac{\sum e_i^2}{n - p - 1}}$$ Estimates the standard deviation of the irreducible error $\sigma$.

RSE is the regression-specific version of RMSE, corrected for degrees of freedom. It has the same units as $Y$ and can be compared to $\bar{y}$ to assess relative model fit.

RSE vs RMSE
  • RMSE divides by $n$ (prediction error)
  • RSE divides by $n - p - 1$ (unbiased $\sigma$ estimate)
  • For large $n$ and small $p$, RSE $\approx$ RMSE
Interpretation example: If $\bar{y} = 14$ and RSE $= 3.26$, then the model has about $3.26/14 = 23\%$ relative error, a moderate fit.

In-Class Exercise

In-Class Exercise

A model predicts exam scores for $n = 4$ students:

Student$y_i$ (true)$\hat{y}_i$ (predicted)
17072

  1. Compute MSE, RMSE, and MAE.
  2. Compute $R^2$ (note: $\bar{y} = 75$, $\mathrm{TSS} = 500$).
  3. Student 4's prediction is the worst. By how much does removing this observation change MSE?
  4. If a second model has RMSE $= 4.2$ and MAE $= 3.1$, which model is better and why might the two models give different rankings?

1. Residuals: $-2, 5, 2, -10$. $\sum e_i^2 = 4+25+4+100 = 133$. MSE $= 133/4 = 33.25$. RMSE $= \sqrt{33.25} \approx 5.77$. MAE $= (2+5+2+10)/4 = 19/4 = 4.75$.

2. RSS $= 133$. $R^2 = 1 - 133/500 = 1 - 0.266 = 0.734$. The model explains 73.4% of variance in scores.

3. Without student 4: $\sum e_i^2 = 4+25+4 = 33$, MSE $= 33/3 = 11$. Change: $33.25 - 11 = 22.25$ reduction per observation (student 4 inflates MSE by the large squared error of 100).

4. Our model: RMSE $\approx 5.77 > 4.2$ : the second model is better by RMSE. But MAE: ours is $4.75 > 3.1$, also better for second model. The two rankings could differ when one model makes fewer but larger errors (higher RMSE/MAE ratio) while the other is more consistently wrong. Here both metrics agree.

Practice Problems

Practice Problems

Problem 1: Computing and comparing metrics

Test set with $n=5$: $y = (3, 7, 5, 9, 4)$, $\hat{y} = (4, 6, 6, 8, 5)$.

  1. Compute MSE, RMSE, and MAE.
  2. Compute $R^2$ (use $\bar{y} = 5.6$).
  3. A second model has RMSE $= 1.0$ and MAE $= 0.9$. Is model 2 strictly better? What does the RMSE/MAE ratio tell you?

a. $e_i=(-1,1,-1,1,-1)$. RSS$=5$. MSE$=1.0$, RMSE$=1.0$, MAE$=1.0$.

b. TSS$=(3{-}5.6)^2{+}(7{-}5.6)^2{+}(5{-}5.6)^2{+}(9{-}5.6)^2{+}(4{-}5.6)^2=23.2$. $R^2=1-5/23.2\approx0.784$: the model explains 78.4\% of variation.

c. Model 2 has the same RMSE$=1.0$ but lower MAE$=0.9$: not strictly better overall. RMSE/MAE$=1.0$ for model 1 (all errors equal); RMSE/MAE$\approx1.11$ for model 2, meaning some errors are larger than average, inflating RMSE relative to MAE.

Problem 2: R² properties

A model gives $R^2 = 0.85$ on training data. On test data, $\mathrm{TSS} = 2000$, $\mathrm{RSS} = 400$.

  1. Compute test $R^2$.
  2. Is the training $R^2$ higher or lower than test $R^2$? What does this indicate?
  3. Can test $R^2$ be negative? Give a concrete example.

a. Test $R^2=1-400/2000=0.80$.

b. Training $R^2=0.85>$ test $R^2=0.80$, as expected: the model is fitted to training data. The gap of 0.05 suggests mild overfitting.

c. Yes: test $R^2$ can be negative if the model performs worse than predicting $\bar y$. Example: a model always predicting 0 when $\bar y=10$ gives RSS$>$TSS.

Problem 3: Adjusted R²

$n = 50$, $p = 3$: $R^2 = 0.72$. A fourth predictor is added: new $R^2 = 0.73$.

  1. Compute adjusted $R^2$ before and after adding the predictor.
  2. Should the fourth predictor be retained? Justify using adjusted $R^2$.

a. Before: $\bar R^2=1-(1-0.72)(49/46)=1-0.298=0.702$. After: $\bar R^2=1-(1-0.73)(49/45)=1-0.294=0.706$. Slight increase.

b. The fourth predictor marginally improves adjusted $R^2$ and can be retained, though the gain is small and other criteria (AIC, BIC) should also be checked.

Problem 4: True or False
  1. RMSE is always greater than or equal to MAE for the same set of predictions.
  2. A model with higher $R^2$ always has lower RMSE.
  3. Adding any predictor to a regression model cannot decrease $R^2$.
  4. Test MSE can be lower than training MSE in practice.

a. True. MSE$=E[e^2]\geq(E|e|)^2=$MAE$^2$ by Jensen's inequality, so RMSE$\geq$MAE always.

b. False. $R^2$ depends on TSS, which varies by dataset. Higher $R^2$ does not imply lower RMSE.

c. True. OLS minimises RSS; adding a predictor cannot increase RSS (set its coefficient to 0), so $R^2$ cannot decrease.

d. True. If training data is noisy or the model underfits, test MSE can be lower than training MSE.
