Module 23

K-Means Clustering

Clustering seeks groups within the observations themselves, with no response variable to guide or judge the result. K-means is the most widely used method: it partitions the observations into a pre specified number of non overlapping groups by minimising the variation within each.

Learning Objectives
  • State the within cluster variation objective that K-means minimises
  • Execute the algorithm by hand and recognise when it has converged
  • Explain why the algorithm reaches a local, not global, optimum
  • Choose $K$ using the elbow method and the silhouette coefficient
  • Recognise the situations in which K-means gives misleading answers
Supervised and unsupervised contrasted Every method so far has had a response $Y$ against which predictions could be scored. Here there is no $Y$, so there is no test error and no cross validation in the usual sense. The result cannot be declared right or wrong, only more or less useful, which makes clustering exploratory by nature and places far more weight on judgement.
The Objective

What K-Means Minimises

The partition Divide the $n$ observations into $K$ sets $C_1,\ldots,C_K$ satisfying $$C_1 \cup C_2 \cup \cdots \cup C_K = \{1,\ldots,n\}, \qquad C_k \cap C_{k'} = \varnothing \text{ for } k \neq k'$$ Every observation belongs to exactly one cluster.
The criterion A good clustering has observations that lie close to the centre of their own cluster. The centre (centroid) of cluster $C_k$ is the mean $\bar{\mathbf{x}}_k$ of its members. K means chooses the clusters that minimise the total squared distance from each observation to its centroid: $$\min_{C_1,\ldots,C_K}\;\sum_{k=1}^{K}\sum_{i \in C_k}\|\mathbf{x}_i - \bar{\mathbf{x}}_k\|^2$$ This quantity is called the within cluster sum of squares. Small means tight, compact clusters.
Why an exact solution is impossible The number of ways to split $n$ observations into $K$ groups is roughly $K^n$. For $n = 100$ and $K = 3$ that is about $5 \times 10^{47}$ possibilities, too many to check. So the algorithm on the next slide settles for a good local solution rather than the global optimum.
Algorithm

The K-Means Algorithm

Lloyd's algorithm
  1. Choose $K$. Assign each observation at random to one of the $K$ clusters, or place $K$ initial centroids.
  2. Update step. Compute the centroid of each cluster, the vector of variable means for the observations currently assigned to it.
  3. Assignment step. Reassign each observation to the cluster whose centroid is nearest in Euclidean distance.
  4. Repeat steps 2 and 3 until no assignment changes.
What convergence does and does not guarantee Convergence is to a point where no single reassignment improves the objective, that is a local minimum. It carries no guarantee of being the global minimum, and different starting values will often lead to different answers.

Local Optima

Local Optima and Multiple Starts

The answer depends on where you start Because the algorithm only guarantees a local minimum, different random initialisations can produce genuinely different clusterings of the same data, with different values of the objective. Running K-means once and reporting the result is therefore unsafe.
The standard remedy Run the algorithm many times, typically $25$ to $50$, from different random starts, and keep the solution with the smallest total within cluster sum of squares. Because the objective is directly comparable across runs, choosing between them requires no judgement at all.

Better initialisation

Random starts can still place several initial centroids inside the same natural group. K means++ chooses the starting centroids more carefully so that they are spread apart. It is described on the next slide and is the default in most software.

Initialisation

K-Means++: Choosing Good Starting Centroids

The idea Poor starts happen when two initial centroids fall in the same group of points. K means++ avoids this by choosing each new centroid far from the centroids already chosen, but randomly rather than always taking the farthest point, so that a single outlier does not dominate.
The algorithm for $K$ clusters
  1. Choose the first centroid uniformly at random from the observations.
  2. For every observation $x$, compute $D(x)^2$, the squared distance to its nearest centroid chosen so far: $$D(x)^2 = \min_{c \in C}\|x - c\|^2$$
  3. Choose the next centroid from the observations at random, with probability $$P(x) = \frac{D(x)^2}{\sum_i D(x_i)^2}$$ so points far from every current centroid are more likely to be picked, and points already chosen have probability $0$.
  4. Repeat steps 2 and 3 until $K$ centroids have been chosen.
  5. Run ordinary K means from these starting centroids: assign each observation to its nearest centroid, recompute the cluster means, and repeat until the centroids stop changing.
Worked example: six points on a line, $K = 3$ Observations: $1,\ 2,\ 3,\ 9,\ 10,\ 20$. There are three natural groups, $\{1,2,3\}$, $\{9,10\}$ and $\{20\}$.

It is still random, so it is usually run several times, but it typically needs fewer iterations and reaches a lower objective than purely random starts.
Choosing K

Choosing the Number of Clusters

An important asymmetry The objective always improves as $K$ increases, reaching zero when $K = n$ and every observation forms its own cluster. So while the objective can be used to compare runs at the same $K$, it can never be used to choose $K$ itself. The two methods below are therefore needed.
The elbow method Plot the total within cluster sum of squares against $K$. The curve always decreases, but typically falls sharply while genuine structure is being separated and then flattens once clusters are merely being subdivided. The value of $K$ at the bend is taken as the choice.

Total within cluster sum of squares against $K$, with a clear bend at $K = 3$.

The silhouette coefficient For observation $i$, let $a(i)$ be the mean distance to the other members of its own cluster, and $b(i)$ the smallest mean distance to any other cluster. Then $$s(i) = \frac{b(i)-a(i)}{\max\{a(i),\,b(i)\}} \in [-1,\,1]$$ What the value means:
Score near +1Good
The observation is much closer to its own cluster than to other clusters. It is comfortably placed.
Score near 0Boundary
The observation is almost equally close to its own cluster and another cluster. It may lie near a cluster boundary.
Negative scorePoor
The observation is, on average, closer to another cluster than to its assigned cluster. It may be incorrectly assigned.
The mean of $s(i)$ over all observations summarises the clustering, and $K$ is chosen to maximise it.
Neither criterion is a test The elbow is frequently ambiguous or absent, and different criteria often disagree. Clustering has no ground truth, so these are diagnostics for judgement rather than decisions rules. Where a substantive reason exists to expect a particular number of groups, that reason should usually outweigh the plot.

Mean silhouette $$\bar s = \frac{0.7059+0.7333+0.2222+0.8421+0.8636}{5} = \mathbf{0.6734}$$ A value around $0.67$ indicates a reasonable structure. Values below about $0.25$ are usually taken to mean no substantial structure has been found.
Reading the individual values The point $C$ stands out with $s(C) = 0.2222$. Its mean distance within its own cluster, $3.5$, is barely less than its mean distance to the other cluster, $4.5$, so it sits almost equidistant between the two groups. The per observation silhouettes therefore reveal something the mean alone conceals: this clustering is clear for four of the five points and doubtful for one. That is exactly the kind of diagnostic detail worth reporting.
Limitations

Practical Issues and Limitations

Scaling is not optional Euclidean distance is dominated by whichever variable has the largest numerical spread. Income in taka and years of education cannot be combined meaningfully without standardisation, exactly as in Module 21. Standardise unless the variables are already in comparable units.
$K$ must be chosen in advance The method cannot tell you that the data contain no clusters. Given $K = 4$ it will return four clusters from perfectly homogeneous data, and they will look convincing when plotted.
Every observation must be assigned There is no concept of an outlier or of noise: an extreme observation is forced into some cluster and pulls that centroid towards itself, distorting the result.
In-Class Exercise

In-Class Exercise

Problem Four observations on one variable: $x = 1,\;2,\;6,\;7$. Apply K-means with $K = 2$ and initial centroids $c_1 = 1$ and $c_2 = 2$.
  1. Carry out the first assignment step and compute the updated centroids.
  2. Carry out the second iteration and state whether the algorithm has converged.
  3. Compute the final total within cluster sum of squares.
  4. Would the initial centroids $c_1 = 1$ and $c_2 = 7$ give the same answer?

1. Distances to $c_1=1$ are $0,1,5,6$; to $c_2=2$ they are $1,0,4,5$. So $x=1$ joins $C_1$ and $x=2,6,7$ join $C_2$. New centroids: $c_1 = 1$ and $c_2 = (2+6+7)/3 = 5$.

2. Distances to $c_1=1$: $0,1,5,6$; to $c_2=5$: $4,3,1,2$. Now $x=1$ and $x=2$ join $C_1$, while $x=6,7$ join $C_2$. New centroids: $c_1 = 1.5$ and $c_2 = 6.5$. The assignments changed, so a further iteration is needed. Checking it: distances to $1.5$ are $0.5,0.5,4.5,5.5$ and to $6.5$ are $5.5,4.5,0.5,0.5$, giving the same assignments. The algorithm has converged to $C_1=\{1,2\}$ and $C_2=\{6,7\}$.

3. $$\text{WCSS} = \left[(1-1.5)^2+(2-1.5)^2\right] + \left[(6-6.5)^2+(7-6.5)^2\right] = 0.5 + 0.5 = \mathbf{1.0}$$

4. Yes. With $c_1=1$ and $c_2=7$, the first assignment gives $C_1=\{1,2\}$ and $C_2=\{6,7\}$ immediately, which is the same solution reached above and is clearly the global optimum here. The starting values changed only the number of iterations required, not the destination. With more observations and higher dimension this agreement cannot be relied upon, which is why multiple starts are used.

Practice Problems

Practice Problems

Problem 1 A K-means run with $K = 3$ produces clusters of sizes $40$, $35$ and $25$, with within cluster sums of squares $120$, $98$ and $62$.
  1. Compute the total within cluster sum of squares.
  2. A second run from a different start gives $118$, $104$ and $71$. Which solution should be reported?
  3. A run with $K = 4$ gives a total of $214$. Does this show $K = 4$ is better?

1. $120+98+62 = \mathbf{280}$.

2. The second run totals $118+104+71 = 293$, which is larger. Report the first, with total $280$. The comparison is legitimate because both runs use the same $K$, so the objective is directly comparable and no judgement is required.

3. No. The objective is guaranteed to decrease as $K$ increases, reaching zero at $K = n$, so a lower total at $K=4$ is expected and carries no information. Comparing across $K$ requires a criterion that penalises complexity, such as the silhouette coefficient, or a judgement from the elbow plot. Here the fall from $280$ to $214$ would need to be assessed against the fall achieved by earlier increments.

Problem 2 An observation has mean distance $2.0$ to the other members of its cluster, and mean distances $6.0$ and $3.0$ to the two other clusters.
  1. Compute its silhouette coefficient.
  2. Interpret the value.
  3. What would the coefficient be if the mean within cluster distance were $4.0$ instead?

1. $b(i)$ is the smallest mean distance to another cluster, so $b(i) = 3.0$, not $6.0$. With $a(i) = 2.0$, $$s(i) = \frac{3.0-2.0}{\max\{2.0,\,3.0\}} = \frac{1.0}{3.0} = \mathbf{0.3333}$$

2. A value of $0.33$ is modest. The observation is closer to its own cluster than to the nearest alternative, so the assignment is defensible, but the margin is small and it lies towards the edge of its cluster rather than the interior.

3. With $a(i)=4.0$ and $b(i)=3.0$, $$s(i) = \frac{3.0-4.0}{\max\{4.0,\,3.0\}} = \frac{-1.0}{4.0} = \mathbf{-0.25}$$ A negative silhouette means the observation is on average closer to a different cluster than to its own, so it has probably been misassigned. A cluster containing many such points is not a genuine group.
