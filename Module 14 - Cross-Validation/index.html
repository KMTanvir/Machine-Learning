Module 14: Cross-Validation

Module 14

Cross-Validation

A model evaluated on its own training data is too optimistic. Cross-validation estimates generalization performance by evaluating the model on data it has not seen during training.

The fundamental problem Training error decreases as model complexity grows, it is a biased, optimistic estimate of test error. We need an honest estimate of how the model performs on new, unseen observations.

Learning Objectives

  • Distinguish training error from test error and explain why they diverge
  • Apply the validation set approach, LOOCV, and $k$-fold CV
  • Understand the bias-variance trade-off in cross-validation itself
  • Apply stratified $k$-fold CV for classification
  • Understand time-series CV for temporal data
  • Use cross-validation for model selection and hyperparameter tuning
Reference: ISLR Chapter 5; Modules 11–13 (evaluation metrics used within CV)
Motivation

Training Error vs Test Error

Optimism of training error $$\mathrm{Err}_{\mathrm{train}} = \frac{1}{n}\sum_{i=1}^n L(y_i, \hat{f}(x_i)) \leq \mathrm{Err}_{\mathrm{test}}$$ where $L$ is a loss function. Equality holds only if the model did not fit the training data (zero degrees of freedom).

As model complexity increases:

  • Training error decreases monotonically
  • Test error follows a U-shape: first decreases (bias reduction), then increases (variance increase)
  • The gap between training and test error is the optimism
Why a held-out test set is not enough If we repeatedly evaluate on the same test set and tune the model accordingly, the test set becomes "used up": it leaks into model selection decisions. Cross-validation provides a fresh estimate for each model/hyperparameter combination.
Validation Set

Validation Set Approach

Validation Set Approach Randomly split the $n$ observations into a training set (typically 70–80%) and a validation set (20–30%). Fit the model on the training set; evaluate it on the validation set.
Advantages
  • Conceptually simple
  • Computationally cheap (one model fit)
Disadvantages
  • Validation error is highly variable (depends on the random split)
  • Only a fraction of data is used for training; error estimate is pessimistically biased
  • Small datasets: both problems are severe
For regression: $\mathrm{Val\ MSE} = \dfrac{1}{|V|}\sum_{i \in V}(y_i - \hat{f}(x_i))^2$ where $V$ is the validation set index and $\hat{f}$ is fit on the training set only.
LOOCV

Leave-One-Out Cross-Validation (LOOCV)

LOOCV Algorithm For $i = 1, 2, \ldots, n$: train on all observations except $i$; predict $\hat{y}_{-i}$ for observation $i$. Estimate: $$\mathrm{CV}_{(n)} = \frac{1}{n}\sum_{i=1}^n L(y_i, \hat{y}_{-i})$$
Shortcut for OLS regression: LOOCV-MSE can be computed from a single model fit using the hat matrix $H$: $$\mathrm{CV}_{(n)} = \frac{1}{n}\sum_{i=1}^n \left(\frac{y_i - \hat{y}_i}{1 - h_{ii}}\right)^2$$ where $h_{ii}$ is the $i$-th diagonal of $H = X(X^\top X)^{-1}X^\top$. No refitting required.
Advantages
  • Low bias: trained on $n-1$ observations (almost the full data)
  • Deterministic: no random split
Disadvantages
  • High variance: $n$ training sets are nearly identical (correlated estimates)
  • Computationally expensive: $n$ model fits (except for OLS shortcut)
k-fold CV

$k$-Fold Cross-Validation

$k$-Fold CV Algorithm Randomly partition $n$ observations into $k$ approximately equal folds $F_1, F_2, \ldots, F_k$. For each $j = 1, \ldots, k$: train on all folds except $F_j$; evaluate on $F_j$. Estimate: $$\mathrm{CV}_{(k)} = \frac{1}{k}\sum_{j=1}^k \mathrm{Err}_j$$ where $\mathrm{Err}_j$ is the error on fold $F_j$.
Common choices: $k = 5$ or $k = 10$. Note that LOOCV is $k$-fold CV with $k = n$.

Bias-Variance in CV

Bias-Variance Trade-off in Cross-Validation

Cross-validation itself has bias and variance as an estimator of true test error:

Bias (pessimistic) Each training set in $k$-fold CV has only $(k-1)/k \cdot n$ observations, so the model is trained on less data than the final model will use. This induces upward bias in the error estimate (overestimates true test error). The bias decreases as $k$ increases.
Variance With large $k$ (including LOOCV), the $k$ training sets overlap heavily. Their error estimates are highly correlated, so the average has high variance. Variance decreases as $k$ decreases.
Empirical finding (Kohavi, 1995) $k = 10$ provides the best bias-variance balance in most practical settings. $k = 5$ is acceptable for large datasets. LOOCV is preferred only when $n$ is very small (e.g., $n < 50$) and computation is feasible.
Stratified CV

Stratified $k$-Fold CV

Stratified $k$-Fold CV When partitioning into folds, ensure each fold contains approximately the same proportion of each class as the full dataset. This is essential for classification with imbalanced classes.

Why stratification matters: with 90% class 0 and 10% class 1, random splitting may produce a fold with 0% positives: the model cannot be properly evaluated on it, and error estimates become unreliable.

Standard $k$-fold CV is sufficient for regression and balanced classification. Always use stratified $k$-fold for binary or multiclass classification, especially when classes are imbalanced.

Repeated $k$-fold CV

Repeat the $k$-fold CV process $r$ times with different random splits. Final estimate is the mean over all $r \times k$ folds. Reduces variance of the CV estimate at the cost of $r$ times more computation. Common choice: $r = 5$ or $r = 10$.

Time-Series CV

Time-Series Cross-Validation

Standard $k$-fold CV randomly shuffles observations. For time-series data, this causes data leakage: future data is used to predict the past. This violates causality and produces overly optimistic estimates.
Walk-Forward Validation (Expanding Window) For fold $j$: train on observations $1, \ldots, t_j$; evaluate on observations $t_j+1, \ldots, t_j+h$ (horizon $h$). Increase $t_j$ at each fold. The training set grows over time.
Sliding Window Variation Fix the training window size $w$: train on $t_j - w + 1, \ldots, t_j$; evaluate on $t_j+1, \ldots, t_j+h$. Useful when older data is less relevant.

Model Selection

Using CV for Model Selection and Tuning

CV for Model Selection Compute $\mathrm{CV}_{(k)}$ for several competing models or hyperparameter values. Select the model with the lowest CV error. Refit on the full training data.
The one-standard-error rule To avoid overfitting to CV noise, choose the simplest model whose CV error is within one standard error of the minimum CV error. This favors parsimony. $$\text{Select smallest model with } \mathrm{CV} \leq \mathrm{CV}^* + \mathrm{SE}(\mathrm{CV}^*)$$

Nested Cross-Validation

When CV is used for both hyperparameter tuning and performance estimation, use two nested loops:

  • Outer loop: $k$-fold CV for unbiased performance estimation
  • Inner loop: $k'$-fold CV on each outer training set for hyperparameter selection
Without nesting, the same data is used to select the model and estimate its performance: this produces overly optimistic results.
Example

Worked Example: 5-Fold CV

$n = 10$ observations. Randomly assign each to one of 5 folds (2 each):

FoldValidation obs.Val. MSE

$$\mathrm{CV}_{(5)} = \frac{4.2 + 5.8 + 3.9 + 6.1 + 4.4}{5} = \frac{24.4}{5} = 4.88$$

Standard error of the CV estimate:

$$\mathrm{SE}(\mathrm{CV}) = \sqrt{\frac{\sum_{j=1}^5 (\mathrm{Err}_j - \mathrm{CV})^2}{5(5-1)}} = \sqrt{\frac{(4.2-4.88)^2 + \cdots + (4.4-4.88)^2}{20}}$$ $= \sqrt{\frac{0.4624 + 0.8464 + 0.9481 + 1.4884 + 0.2304}{20}} = \sqrt{\frac{3.9757}{20}} \approx 0.446$
One-SE rule: accept any model with CV error $\leq 4.88 + 0.45 = 5.33$. This selects simpler models over complex ones with marginally lower CV error.
In-Class Exercise

In-Class Exercise

A dataset has $n = 20$ observations with one continuous response. Two competing models:

  • Model A (linear regression, $p=2$): 5-fold CV MSE $= 8.4$ with folds $(7.2, 9.0, 8.1, 9.8, 7.9)$
  • Model B (quadratic regression, $p=5$): 5-fold CV MSE $= 7.9$ with folds $(6.8, 9.5, 7.3, 9.6, 6.3)$
  1. Compute the SE of each model's CV estimate.
  2. Apply the one-SE rule to choose between Model A and Model B.
  3. How many observations are in each fold's training set? What is the approximate bias this introduces?
  4. Would LOOCV be preferable here? Justify your answer.

1. Model A: mean $= 8.4$. Deviations: $(-1.2, 0.6, -0.3, 1.4, -0.5)$. SS $= 1.44+0.36+0.09+1.96+0.25 = 4.10$. SE $= \sqrt{4.10/20} = \sqrt{0.205} \approx 0.453$.
Model B: mean $= 7.9$. Deviations: $(-1.1, 1.6, -0.6, 1.7, -1.6)$. SS $= 1.21+2.56+0.36+2.89+2.56 = 9.58$. SE $= \sqrt{9.58/20} = \sqrt{0.479} \approx 0.692$.

2. Minimum CV error is Model B at 7.9. One-SE threshold $= 7.9 + 0.692 = 8.59$. Model A CV $= 8.4 \leq 8.59$. By the one-SE rule, choose the simpler Model A.

3. 5-fold with $n=20$: each fold has 4 validation observations, training sets have 16 observations. Training on 80% of data slightly underestimates what the final model (trained on 100%) can achieve, introducing modest upward bias in the CV error estimate.

4. With $n=20$, LOOCV is computationally feasible (20 fits). It would reduce bias (train on 19 observations each time) but increase variance due to high correlation among training sets. 5-fold CV is still preferred for its lower variance. LOOCV would be better if $n$ were much smaller, e.g., $n = 10$.

Practice Problems

Practice Problems

Problem 1: Conceptual
  1. A researcher trains 10 models with different hyperparameters, evaluates each on the same held-out test set, and reports the best test error. Why is this test error not a reliable estimate of generalization performance?
  2. What does it mean for cross-validation to be "consistent"? What property of the data is required?
  3. Can cross-validation detect overfitting? Explain how.

a. Evaluating 20 models on the same held-out test set is multiple-comparisons overfitting: the best result capitalises on random variation in that set. A separate held-out test or nested CV is required for a reliable estimate.

b. CV is consistent if the CV error estimate converges to the true test error as $n\to\infty$. This requires observations to be exchangeable (iid). For time series, the iid assumption fails: future observations depend on the past.

c. Yes. Compare training error to CV error: if training error is much lower, the model is overfitting. CV simulates prediction on unseen data at each fold and reveals generalisation performance.

Problem 3: Time series

Weekly sales data, 52 weeks. You want to forecast 4 weeks ahead using a model with features from the previous 4 weeks.

  1. Why is standard 5-fold CV inappropriate here?
  2. Describe an expanding-window CV setup with 5 folds. Specify the training and validation periods for each fold (state the weeks used).
  3. What is the minimum number of observations in the first training set?

a. Standard 5-fold randomly shuffles all 52 weeks. A model could train on week 40 and validate on week 10: training on future data to predict the past, a causal violation. Error estimates would be unrealistically optimistic for forecasting.

b. First usable observation: week 5 (requires lags from weeks 1 to 4). Fold 1: train weeks 5-32, validate 33-36. Fold 2: train weeks 5-36, validate 37-40. Fold 3: train weeks 5-40, validate 41-44. Fold 4: train weeks 5-44, validate 45-48. Fold 5: train weeks 5-48, validate 49-52.

c. Minimum observations in first training set: 28 (weeks 5 to 32). The 4-week lag requirement means week 5 is the earliest usable observation.
