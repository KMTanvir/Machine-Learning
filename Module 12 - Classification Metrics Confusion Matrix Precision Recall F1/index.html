Module 12

Classification Metrics: Confusion Matrix, Precision, Recall, F1

Accuracy alone is a misleading summary of classifier performance, especially under class imbalance. This module develops a complete toolkit for evaluating classifiers.

Why accuracy fails If 99% of emails are legitimate, a classifier that always predicts "not spam" achieves 99% accuracy, but catches zero spam. We need metrics that separately track each type of error.

Learning Objectives

  • Construct and interpret a confusion matrix
  • Compute accuracy, precision, recall, specificity, and F1-score
  • Understand the precision-recall tradeoff
  • Apply macro and micro averaging for multi-class problems
  • Recognise the impact of class imbalance on metric choice
Reference: ISLR Chapter 4.4; Module 08 (LDA) covered sensitivity/specificity in context
Confusion Matrix

The Confusion Matrix

For binary classification (Positive = class 1, Negative = class 0):

Predicted PositivePredicted Negative
Actual PositiveTP (True Positive)FN (False Negative)
Actual NegativeFP (False Positive)TN (True Negative)
Error types
  • FP (Type I error): predicted positive, actually negative (false alarm)
  • FN (Type II error): predicted negative, actually positive (missed detection)
Context matters
  • Medical test: FN (missed disease) is costlier than FP
  • Spam filter: FP (blocking a real email) may be costlier than FN
  • The cost structure determines which error to minimise
Total $= \mathrm{TP} + \mathrm{TN} + \mathrm{FP} + \mathrm{FN}$
Accuracy

Accuracy and Its Limitations

Accuracy $$\mathrm{Accuracy} = \frac{\mathrm{TP} + \mathrm{TN}}{\mathrm{TP}+\mathrm{TN}+\mathrm{FP}+\mathrm{FN}}$$ Proportion of all predictions that are correct.
Accuracy is misleading under class imbalance

Disease prevalence = 2%. A model predicting "no disease" for everyone achieves 98% accuracy, but has TP = 0, sensitivity = 0%. It is clinically useless.

Error rate $$\text{Error rate} = 1 - \text{Accuracy} = \frac{\mathrm{FP}+\mathrm{FN}}{n}$$

Accuracy is appropriate only when classes are balanced and all errors have equal cost. In most real applications, at least one of these conditions fails.

Sensitivity and Specificity

Sensitivity (Recall) and Specificity

Sensitivity (Recall, TPR) $$\mathrm{Sensitivity} = \frac{\mathrm{TP}}{\mathrm{TP}+\mathrm{FN}}$$ Of all true positives, how many did we catch?
Specificity (TNR) $$\mathrm{Specificity} = \frac{\mathrm{TN}}{\mathrm{TN}+\mathrm{FP}}$$ Of all true negatives, how many did we correctly identify?
False Positive Rate (FPR) $$\mathrm{FPR} = 1 - \mathrm{Specificity} = \frac{\mathrm{FP}}{\mathrm{FP}+\mathrm{TN}}$$
Sensitivity and specificity are complementary: lowering the classification threshold increases sensitivity (catching more positives) but decreases specificity (more false alarms). The ROC curve (Module 13) traces this tradeoff.
Precision

Precision (Positive Predictive Value)

Precision $$\mathrm{Precision} = \frac{\mathrm{TP}}{\mathrm{TP}+\mathrm{FP}}$$ Of all instances predicted positive, how many are truly positive?
Precision vs Recall (Sensitivity)
  • Recall: "Did we find all positives?" (completeness)
  • Precision: "Are our positive predictions trustworthy?" (exactness)
  • Increasing one typically decreases the other
Examples
  • Cancer screening: maximise recall (missing a cancer is dangerous)
  • Recommendation systems: maximise precision (irrelevant suggestions annoy users)
  • Information retrieval: balance both
Trivial high precision: predict positive for only one observation (the most confident one). Then precision $= 1$ but recall is near 0. Precision and recall must be reported together.
F1-Score

F1-Score and $F_\beta$-Score

F1-Score (Harmonic Mean of Precision and Recall) $$F_1 = 2 \cdot \frac{\mathrm{Precision} \times \mathrm{Recall}}{\mathrm{Precision} + \mathrm{Recall}} = \frac{2\,\mathrm{TP}}{2\,\mathrm{TP}+\mathrm{FP}+\mathrm{FN}}$$
General $F_\beta$-Score $$F_\beta = (1+\beta^2)\cdot\frac{\mathrm{Precision}\times\mathrm{Recall}}{\beta^2\cdot\mathrm{Precision}+\mathrm{Recall}}$$ $\beta > 1$: recall weighted more; $\beta < 1$: precision weighted more.
Why harmonic mean? The harmonic mean is dominated by the smaller of the two values. If precision $= 1$ and recall $= 0.01$, arithmetic mean $= 0.505$ (misleadingly high), but $F_1 \approx 0.02$ (correctly low). $F_1$ forces both to be high simultaneously.

$F_1 \in [0, 1]$; $F_1 = 1$ requires both perfect precision and perfect recall.

Which to report? Always report at minimum: confusion matrix, sensitivity, specificity, and $F_1$. Add precision if positive predictions have costs. Accuracy can be included but should not be the primary metric under class imbalance.
Multi-class

Multi-Class Metrics: Macro and Micro Averaging

For $K > 2$ classes, compute per-class metrics then aggregate:

Macro-average $$\text{Macro-}F_1 = \frac{1}{K}\sum_{k=1}^K F_{1,k}$$ Treats all classes equally regardless of size.
Micro-average $$\text{Micro-}F_1 = \frac{2\sum_k TP_k}{2\sum_k TP_k + \sum_k FP_k + \sum_k FN_k}$$ Aggregates counts across classes; dominated by the most frequent class.

Class Imbalance

Class Imbalance and Strategies

Class imbalance occurs when one class is much rarer than others (e.g., fraud: 0.1%, medical events: 2%). Standard accuracy becomes uninformative.

Strategies

  • Metric choice: use $F_1$, precision, recall, or AUC (Module 13) instead of accuracy
  • Threshold adjustment: lower the positive class threshold to increase sensitivity at the cost of precision
  • Resampling:
    • Oversampling minority class (SMOTE: Synthetic Minority Over-sampling Technique)
    • Undersampling majority class (random or informed)
  • Cost-sensitive learning: assign higher misclassification cost to minority class
  • Ensemble methods: balanced random forests, boosting with class weights
The Matthews Correlation Coefficient (MCC) is a single balanced metric robust to imbalance: $$\mathrm{MCC} = \frac{TP \cdot TN - FP \cdot FN}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}} \in [-1,1]$$
Example

Worked Example: Email Spam Classifier

A classifier is tested on 1000 emails: 100 spam (positive), 900 legitimate (negative).

Predicted SpamPredicted Legit
Actual SpamTP = 80FN = 20
Actual LegitFP = 50TN = 850
$$\text{Accuracy} = \frac{80+850}{1000} = 0.930$$ $$\text{Sensitivity} = \frac{80}{80+20} = 0.800 \qquad \text{Specificity} = \frac{850}{850+50} = 0.944$$ $$\text{Precision} = \frac{80}{80+50} = 0.615 \qquad F_1 = \frac{2(0.615)(0.800)}{0.615+0.800} = 0.696$$
Despite 93% accuracy, precision is only 61.5%: nearly 4 in 10 emails flagged as spam are actually legitimate. Whether this is acceptable depends on the cost of blocking a genuine email vs missing a spam message.
In-Class Exercise

In-Class Exercise

A disease screening test on 500 patients (50 have the disease). Results:

Test PositiveTest Negative
DiseaseTP = 42FN = 8
No DiseaseFP = 30TN = 420
  1. Compute accuracy, sensitivity, specificity, precision, and $F_1$.
  2. Which error (FP or FN) is more costly in this context? What does that imply about which metric to prioritise?
  3. If the threshold is lowered so that TP increases to 48 but FP increases to 60, recompute sensitivity, specificity, and $F_1$. Did the change help?
  4. Compute the MCC for the original confusion matrix.

1. Accuracy $= (42+420)/500 = 0.924$. Sensitivity $= 42/50 = 0.840$. Specificity $= 420/450 = 0.933$. Precision $= 42/72 = 0.583$. $F_1 = 2(0.583)(0.840)/(0.583+0.840) = 0.980/1.423 = 0.689$.

2. FN (missed disease) is far more costly: failing to diagnose a sick patient risks untreated illness. Prioritise sensitivity. Precision matters less here; some false alarms are acceptable to avoid missing true cases.

3. New sensitivity $= 48/50 = 0.960$; specificity $= (450{-}60)/450 = 390/450 = 0.867$; precision $= 48/(48+60) = 0.444$; $F_1 = 2(0.444)(0.960)/(0.444+0.960) = 0.853/1.404 = 0.607$. Sensitivity improved greatly (0.84 to 0.96) but precision fell (0.583 to 0.444) and $F_1$ fell. For this application, the higher sensitivity is worth the tradeoff.

4. MCC $= (42 \times 420 - 30 \times 8)/\sqrt{72 \times 50 \times 450 \times 428} = (17640-240)/\sqrt{694{,}080{,}000} = 17400/26345 \approx 0.660$.

Practice Problems

Practice Problems

Problem 1: Computing all metrics

Credit default classifier, $n=200$: TP=18, FP=12, FN=7, TN=163.

  1. Compute accuracy, sensitivity, specificity, precision, $F_1$, and FPR.
  2. Is accuracy an appropriate primary metric? Why or why not?
  3. Compute MCC.

a. Accuracy$=(18+163)/200=90.5\%$. Sensitivity$=18/25=72.0\%$. Specificity$=163/175\approx93.1\%$. Precision$=18/30=60.0\%$. $F_1=2\times0.60\times0.72/(0.60+0.72)\approx0.655$. FPR$=12/175\approx6.9\%$.

b. Accuracy is misleading: 175 of 200 are non-defaults, so predicting all non-default gives 87.5\% baseline accuracy. A 72\% sensitivity means 28\% of actual defaults are missed. Sensitivity and precision are more informative primary metrics.

c. MCC$=(18\times163-12\times7)/\sqrt{30\times25\times175\times170}=2850/4724\approx0.603$.

Two models on the same test set (positive class prevalence = 10%):

ModelTPFPFNTN
A901010890

  1. Compute precision, recall, and $F_1$ for both.
  2. Which model would you choose for: (i) cancer screening; (ii) fraud alerts sent to customers?

Problem 3: True or False
  1. Macro-averaged $F_1$ is always greater than or equal to micro-averaged $F_1$.
  2. Under perfect class balance (50/50), accuracy equals the micro-averaged $F_1$.
  3. A classifier with sensitivity $= 1$ necessarily has specificity $= 0$.
  4. $F_1$ is always between precision and recall.

a. False. Macro and micro $F_1$ have no consistent ordering. Macro weights each class equally; micro weights by class size, so it is dominated by the majority class.

b. True. For binary classification, micro $F_1=(\text{TP}+\text{TN})/n=$ accuracy regardless of class balance.

c. False. A perfect classifier achieves sensitivity$=1$ and specificity$=1$ simultaneously. Sensitivity$=1$ (no FN) does not force specificity$=0$.

d. True. $F_1$ is the harmonic mean of precision and recall, always between $\min(P,R)$ and $\max(P,R)$.
