Module 13

ROC Curve, AUC, and Model Calibration

A single threshold gives a single confusion matrix. The ROC curve and AUC evaluate a classifier across all thresholds. Model calibration asks whether predicted probabilities are reliable.

Key distinction A classifier outputs a score (probability or decision function). A threshold converts that score to a class label. The ROC curve separates the quality of the score from the choice of threshold.

Learning Objectives

  • Construct and interpret the ROC curve
  • Compute and interpret AUC
  • Understand the Precision-Recall curve for imbalanced data
  • Define model calibration and the Brier score
  • Compare classifiers using AUC rather than a single threshold metric
Reference: ISLR Chapter 4.4; Module 08 (LDA), Module 07 (logistic regression probability output)
Threshold

Classification Threshold

Most classifiers output a probability $\hat{p}(x) = P(Y=1 \mid X=x)$. A threshold $t \in [0,1]$ converts this to a label:

$$\hat{y} = \begin{cases} 1 & \text{if } \hat{p}(x) \geq t \\ 0 & \text{if } \hat{p}(x) < t \end{cases}$$
Low threshold $t$ (e.g., 0.1)
  • More positives predicted
  • High recall (sensitivity)
  • Low precision, more FP
High threshold $t$ (e.g., 0.9)
  • Fewer positives predicted
  • High precision, fewer FP
  • Low recall, more FN
The default threshold is $t = 0.5$, but this is almost never optimal. The optimal threshold depends on the relative costs of FP and FN errors, and the class prevalence.
ROC

The ROC Curve

ROC (Receiver Operating Characteristic) Curve Plot of TPR (Sensitivity) on the $y$-axis versus FPR ($1 -$ Specificity) on the $x$-axis as the threshold $t$ varies from 1 down to 0.

How to construct the ROC curve

  1. Rank all $n$ observations by predicted score $\hat{p}(x_i)$, highest to lowest
  2. Start at $(0, 0)$ (threshold $= 1$, predict all negative)
  3. For each decreasing threshold: if the next observation is a true positive, step up; if it is a false positive, step right
  4. End at $(1, 1)$ (threshold $= 0$, predict all positive)
Perfect classifier: curve passes through $(0, 1)$. AUC $= 1$.
Random classifier: diagonal line (TPR $=$ FPR). AUC $= 0.5$.
A classifier below the diagonal (AUC $< 0.5$) performs worse than random: flip its predictions.
AUC

Area Under the ROC Curve (AUC)

AUC $$\mathrm{AUC} = \int_0^1 \mathrm{TPR}(t)\, d\mathrm{FPR}(t) \in [0, 1]$$
Probabilistic interpretation AUC $= P(\hat{p}(x^+) > \hat{p}(x^-))$ where $x^+$ is a randomly chosen positive and $x^-$ is a randomly chosen negative. It is the probability that the classifier ranks a random positive above a random negative.
AUC valueInterpretation
1.0Perfect discrimination
0.9 – 1.0Excellent
0.8 – 0.9Good
0.7 – 0.8Fair
0.6 – 0.7Poor
0.5No discrimination (random)
AUC is threshold-independent and class-imbalance robust (it does not depend on the proportion of positives). It summarises overall discriminative ability across all operating points.
Comparing Models

Using AUC to Compare Classifiers

AUC allows fair comparison of classifiers without committing to a threshold. The classifier with the higher AUC has better overall discriminative ability.

Limitation of AUC: if two ROC curves cross, one model may be better at low FPR (preferred in rare-disease screening) while the other is better at high FPR. A single AUC number can hide this. Always inspect the full curve, especially in the operating region of interest.

Partial AUC

When only a specific FPR range matters (e.g., FPR $\leq 0.1$ for high-stakes screening), compute the partial AUC over that range only. Normalise by the range width for comparability.

Practical guideline for threshold selection
  • Choose $t$ that maximises $F_1$ (balanced applications)
  • Choose $t$ that achieves a minimum required sensitivity (medical screening)
  • Choose $t$ that minimises expected cost $= c_{FP} \cdot FP + c_{FN} \cdot FN$
PR Curve

Precision-Recall Curve

PR Curve Plot of Precision on the $y$-axis versus Recall on the $x$-axis as the threshold varies. Area under the PR curve = Average Precision (AP).
When to prefer PR over ROC
  • Severe class imbalance (positive class is rare)
  • Performance on negatives is not relevant (e.g., information retrieval)
  • FPR can be misleading when TN $\gg$ TP+FP
Why ROC is optimistic under imbalance

With 99% negatives, even many FPs produce a small FPR (small relative to large TN). ROC curve looks better than PR curve in this case, but PR reflects true performance more honestly.

Average Precision (AP) $$\mathrm{AP} = \sum_{k} (R_k - R_{k-1}) P_k$$ where $P_k$ and $R_k$ are precision and recall at threshold $k$.
Calibration

Model Calibration

Calibration A model is well-calibrated if its predicted probability $\hat{p}(x)$ matches the true frequency of the positive class among observations with that predicted probability.

If $\hat{p}(x) = 0.7$ for a group of patients, about 70% of them should actually have the disease.

Discrimination (AUC) and calibration are independent: a well-discriminating model can be poorly calibrated, and vice versa.

Well-calibrated: $E[Y \mid \hat{p}(X)=p] = p$ for all $p \in [0,1]$.
Miscalibrated: overconfident (predicted 0.9, true frequency 0.6) or underconfident (predicted 0.6, true frequency 0.9).
Calibration matters when the probability itself is used (e.g., personalised risk scores, insurance pricing, medical decision support). If only the ranking matters (e.g., top-$k$ retrieval), calibration is irrelevant: discrimination suffices.
Brier Score

Reliability Diagrams and Brier Score

Brier Score $$\mathrm{BS} = \frac{1}{n}\sum_{i=1}^n (\hat{p}(x_i) - y_i)^2 \in [0, 1]$$ MSE applied to probability predictions. Lower is better; BS $= 0$ is perfect.
Reliability Diagram (Calibration Plot) Group observations into bins by predicted probability (e.g., $[0, 0.1), [0.1, 0.2), \ldots$). Plot the mean predicted probability vs the actual fraction of positives in each bin.
  • Perfect calibration: points on the diagonal $y = x$
  • Above diagonal: model is underconfident (actual rate higher than predicted)
  • Below diagonal: model is overconfident (actual rate lower than predicted)
Calibration methods: Platt scaling (logistic regression on scores), isotonic regression (non-parametric). Both are post-hoc recalibration methods applied after model training.

Worked Example: ROC Construction

Six observations, true labels $y$ and predicted scores $\hat{p}$, sorted by score descending:

RankScore $\hat{p}$Label $y$TPRFPR
10.921 (TP)1/30/3
20.800 (FP)1/31/3
30.751 (TP)2/31/3
40.601 (TP)3/31/3

Points on ROC curve: $(0,0) \to (0, 1/3) \to (1/3, 1/3) \to (1/3, 2/3) \to (1/3, 1) \to (2/3, 1) \to (1, 1)$.

AUC $= (1/3)(1/3) + (1/3)(1/3) + 0 + (1/3)(2/3)$? Using trapezoid rule: $\mathrm{AUC} \approx \frac{1}{3}(1/3) + \frac{1}{3}(2/3-1/3) + \frac{1}{3}(1-2/3+\ldots) \approx 0.722$
This model is reasonably discriminating (AUC $\approx 0.72$); most true positives are ranked higher than true negatives.
In-Class Exercise

In-Class Exercise

Four patients, true labels and scores:

PatientScoreTrue label
A0.851
B0.700
C0.551
D0.300
  1. Construct the ROC curve step by step (start at $(0,0)$).
  2. Compute AUC using the trapezoid rule.
  3. At threshold $t=0.60$, compute the confusion matrix, sensitivity, specificity, and $F_1$.
  4. Compute the Brier score for these four observations.

1. Sort: A(1), B(0), C(1), D(0). Positives: 2, Negatives: 2. Steps: start $(0,0)$. A is TP: up to $(0, 0.5)$. B is FP: right to $(0.5, 0.5)$. C is TP: up to $(0.5, 1.0)$. D is FP: right to $(1.0, 1.0)$.

2. Rectangles: from $(0,0)$ to $(0, 0.5)$: width 0, area 0. From $(0,0.5)$ to $(0.5, 0.5)$: width 0.5, height 0.5, area 0.25. From $(0.5, 0.5)$ to $(0.5, 1.0)$: width 0. From $(0.5, 1.0)$ to $(1, 1)$: width 0.5, height 1.0, area 0.5. AUC $= 0.25 + 0.5 = 0.75$.

3. At $t=0.60$: predict positive for A (0.85) and B (0.70). TP=1 (A), FP=1 (B), FN=1 (C), TN=1 (D). Sensitivity $= 1/2 = 0.5$. Specificity $= 1/2 = 0.5$. Precision $= 1/2 = 0.5$. $F_1 = 2(0.5)(0.5)/(0.5+0.5) = 0.5$.

4. Brier $= [(0.85{-}1)^2 + (0.70{-}0)^2 + (0.55{-}1)^2 + (0.30{-}0)^2]/4 = [0.0225 + 0.49 + 0.2025 + 0.09]/4 = 0.805/4 = 0.201$.

Practice Problems

Practice Problems

Problem 1: AUC and comparison

Model A: AUC $= 0.88$. Model B: AUC $= 0.79$. Both tested on the same data (5% positive prevalence).

  1. Interpret AUC $= 0.88$ in probabilistic terms.
  2. Can we conclude Model A is always better? What additional information helps?
  3. If the task is rare disease screening (minimise FN), which additional curve (ROC or PR) is more informative, and why?

a. AUC$=0.88$: if we randomly pick one positive and one negative, Model A assigns a higher score to the positive 88% of the time.

b. Not necessarily: the ROC curves may cross, making Model B better at low FPR. We need the full curves, the operating region of interest, and cost structure.

c. PR curve. With 5% prevalence, FPR is dominated by the large negative class and ROC looks optimistic. The PR curve directly shows the precision-recall trade-off for the rare positive class.

Problem 2: Brier score and calibration

Three predictions: $(\hat{p}_1, y_1) = (0.9, 1)$, $(\hat{p}_2, y_2) = (0.4, 0)$, $(\hat{p}_3, y_3) = (0.7, 0)$.

  1. Compute the Brier score.
  2. Is the model well-calibrated based on these three points?
  3. The model is recalibrated using Platt scaling: new predictions are $(0.85, 0.35, 0.55)$. Recompute the Brier score. Did calibration improve?

a. BS$=[(0.9{-}1)^2+(0.4{-}0)^2+(0.7{-}0)^2]/3=[0.01+0.16+0.49]/3=0.220$.

b. Not well-calibrated. Obs 3 predicts 0.70 for a true negative ($y=0$): substantial overconfidence. Obs 2 (0.40 for $y=0$) is acceptable; obs 1 (0.90 for $y=1$) is reasonable.

c. After Platt scaling, new predictions: $(0.85,0.35,0.55)$. New BS$=[(0.85{-}1)^2+(0.35{-}0)^2+(0.55{-}0)^2]/3=[0.0225+0.1225+0.3025]/3\approx0.149$. Calibration improved (0.220 to 0.149).

Problem 3: True or False
  1. A model with AUC $= 0.5$ is useless and should be discarded.
  2. The ROC curve is invariant to the class prevalence (proportion of positives).
  3. A perfectly calibrated model necessarily has AUC $= 1$.
  4. The Brier score can be greater than 1.

a. False: a random model gives AUC$=0.5$, meaning the scores are uninformative. It should be replaced or re-examined.

b. True: ROC uses TPR and FPR, both of which normalise by their respective class totals; changing prevalence does not affect them.

c. False: calibration and discrimination are independent. A perfectly calibrated model could have AUC$=0.5$.

d. False: for $y\in\{0,1\}$ and $\hat p\in[0,1]$, each squared term is at most 1, so BS$\in[0,1]$.
