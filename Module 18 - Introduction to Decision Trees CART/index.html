Module 18

Decision Trees: CART

Decision trees partition the feature space into rectangular regions and fit a simple model (constant) in each region. They are highly interpretable, handle mixed data types naturally, and require no feature scaling.

Learning Objectives
  • Understand recursive binary splitting and the CART algorithm
  • Apply the RSS splitting criterion for regression trees, and locate the optimal split by exhaustive search
  • Interpret a fitted tree: splitting rules, leaf predictions, and feature importance
  • Recognise overfitting in deep trees and the need for pruning (Module 19)
  • Identify the strengths and limitations of single decision trees
CART Classification and Regression Trees (Breiman et al., 1984) is the foundational algorithm. It builds binary trees using greedy recursive splitting and applies cost-complexity pruning to control depth. Bagging, random forests and boosting, covered in the supplementary material, are all ensemble methods built on CART trees.
Tree Structure

Anatomy of a Decision Tree

Terminology
  • Root node: the first split, applied to all training data
  • Internal node: a subsequent split on a subset of data
  • Leaf (terminal node): no further splitting; prediction made here
  • Depth: number of splits from root to the deepest leaf
  • Branch: a path from root to a leaf
Prediction
  • Regression: mean of training $y$ in the leaf
  • Classification: majority class in the leaf (or class probabilities $\hat{p}_{mk}$)
  • To predict for a new observation: traverse the tree from root, following splits, until a leaf is reached
Tree Building

Recursive Binary Splitting

The tree on the previous slide is not specified by hand. It is grown from the data by one procedure, applied over and over.

The algorithm
  1. Place all training observations in the root node.
  2. For every predictor $X_j$ and every candidate cutpoint $s$, consider the split $X_j < s$ versus $X_j \geq s$, and measure how well it separates the responses.
  3. Choose the single best pair $(j, s)$ and divide the node into two children.
  4. Apply steps 2 and 3 again to each child, using only the observations that reached it.
  5. Stop when a stopping rule is met (Slide 9). Each remaining node is a leaf.
Reading the name
  • Binary: every split produces exactly two children.
  • Recursive: each child is treated as a new, smaller problem and split by the same rule.
  • Splitting: each step divides the predictor space into rectangular regions.
What "best" means For a regression tree, the best split minimises the residual sum of squares (next slide). For a classification tree, it minimises an impurity measure, the Gini index or entropy, developed in Module 19.
Greedy, not global Each split is the best available at that moment. The algorithm never backtracks to reconsider an earlier split, because searching over all possible trees is intractable.
Regression Trees

The Splitting Criterion for Regression

What the tree is minimising A regression tree partitions the predictor space into $J$ non overlapping boxes $R_1, \ldots, R_J$ and predicts the mean response within each box. The goal is to choose the boxes that minimise $$\sum_{j=1}^{J}\sum_{i \in R_j}\left(y_i - \hat y_{R_j}\right)^2, \qquad \hat y_{R_j} = \frac{1}{|R_j|}\sum_{i \in R_j} y_i$$

Searching over every possible partition is computationally infeasible, so CART proceeds greedily. At each step it considers every predictor $X_k$ and every candidate cutpoint $s$, defining

$$R_1(k,s) = \{X \mid X_k < s\}, \qquad R_2(k,s) = \{X \mid X_k \geq s\}$$

and chooses the pair $(k,s)$ minimising

$$\text{RSS}(k,s) = \sum_{i \in R_1(k,s)}(y_i - \hat y_{R_1})^2 + \sum_{i \in R_2(k,s)}(y_i - \hat y_{R_2})^2$$
Why only $n-1$ cutpoints matter per predictor The RSS changes only when a cutpoint moves past an observation, so for a predictor with $n$ distinct values there are at most $n-1$ distinct splits worth testing, conventionally placed at the midpoints between consecutive sorted values.
Greedy is not optimal The split chosen first is the one that helps most immediately. It may not belong to the best tree of a given size, exactly as forward stepwise selection can miss the best subset. Trees accept this because the exhaustive search is intractable, and pruning later repairs some of the damage.
Worked Example

Worked Example: Growing a Depth 1 Regression Tree

Five observations are available: $(X,Y) = (1,2),\,(2,4),\,(3,3),\,(6,8),\,(8,7)$. Build a depth 1 regression tree, that is a single split on $X$.

Step 1: list the candidate splits The sorted distinct values of $X$ are $1, 2, 3, 6, 8$, so the candidate cutpoints are the four midpoints between consecutive values: $$s \in \{1.5,\; 2.5,\; 4.5,\; 7.0\}$$ With $n = 5$ there are at most $n-1 = 4$ splits worth testing.
Step 2: evaluate every candidate For each split, take the mean of $Y$ in each child and sum the squared deviations about those means.

Sample working for the winner, $X < 4.5$: $$\text{RSS}_L = (2-3)^2+(4-3)^2+(3-3)^2 = 1+1+0 = 2.00$$ $$\text{RSS}_R = (8-7.5)^2+(7-7.5)^2 = 0.25+0.25 = 0.50$$
Step 3: the chosen split and how much it buys The split $X < 4.5$ gives the smallest total RSS, $2.50$. The fitted tree is $$\hat f(X) = \begin{cases} 3.0 & \text{if } X < 4.5 \\ 7.5 & \text{if } X \geq 4.5 \end{cases}$$ Before any split the root predicts $\bar y = 24/5 = 4.8$, giving $$\text{TSS} = (2-4.8)^2+(4-4.8)^2+(3-4.8)^2+(8-4.8)^2+(7-4.8)^2 = 26.80$$ So one split removes $26.80 - 2.50 = 24.30$, which is $90.7\%$ of the total variation.
Reading the table The two extreme splits perform worst. $X < 1.5$ and $X < 7.0$ each isolate a single observation, leaving four points with a wide spread in the other child. The best split is the one that separates the two natural groups, $\{1,2,3\}$ and $\{6,8\}$, and this is what recursive binary splitting discovers automatically without being told the groups exist.

Worked Example: Growing to Depth 2

Continuing the same data, each child of the depth 1 tree is now split again. Recursive splitting treats each node as a fresh problem, using only the observations that reach it.

Left node: $X < 4.5$, containing $(1,2),(2,4),(3,3)$

Candidate cutpoints are $1.5$ and $2.5$.
SplitLeft $Y$RSS$_L$Right $Y$RSS$_R$Total
$X < 1.5$$\{2\}$$0.00$$\{4,3\}$$0.50$$\mathbf{0.50}$
$X < 2.5$$\{2,4\}$$2.00$$\{3\}$$0.00$$2.00$
The winner is $X < 1.5$, with RSS $= 0.50$. Working: $\bar y_R = (4+3)/2 = 3.5$, so $\text{RSS}_R = (4-3.5)^2+(3-3.5)^2 = 0.25+0.25 = 0.50$.

Right node: $X \geq 4.5$, containing $(6,8),(8,7)$

Only one cutpoint is available, $X < 7.0$. It sends one observation to each side, so each child is a single point and both residuals are zero: $$\text{RSS} = 0.00$$ The node is now perfectly fitted, which is exactly the warning sign discussed on Slide 9.

Training RSS falls every time a split is added, and will reach exactly $0$ once every leaf holds a single observation. That is why training RSS can never be used to choose the tree size.
What the second level actually bought The first split removed $24.30$ of RSS using one degree of freedom. The second level removed a further $2.00$ using two more splits. With only five observations, four leaves means an average of $1.25$ observations per leaf, so the depth 2 tree is fitting individual points rather than structure. Cross validation would almost certainly prefer the depth 1 tree here, and cost-complexity pruning in Module 19 provides the machinery to make that choice formally.
Predictors

Categorical Predictors and Missing Values

Categorical predictors

A qualitative predictor with $q$ unordered levels admits $2^{q-1}-1$ possible binary splits, which grows explosively: $q = 10$ already gives $511$ candidate splits.

The ordering shortcut For a regression tree, or a two class classification tree, the optimal split can be found without an exhaustive search. Order the levels by their mean response (or by the proportion in class 1), then treat the predictor as if it were ordered and test only the $q-1$ splits along that ordering. This provably yields the optimal partition, reducing the cost from exponential to linear.
The bias this introduces A categorical predictor with many levels has many more candidate splits than a binary one, so it is more likely to produce a good split by chance alone. Trees are therefore biased towards selecting high cardinality predictors. Grouping rare levels, or using a method that corrects for the number of candidate splits, mitigates this.

Missing values

Trees handle missing data more gracefully than most methods, through two devices.

  • Missing as a category. For a categorical predictor, treat "missing" as a level in its own right. If missingness carries information, the tree can exploit it.
  • Surrogate splits. For each split, record the alternative splits on other predictors that most closely reproduce it. When an observation reaches that node with the primary variable missing, the best available surrogate is used instead.
Contrast with linear regression Ordinary least squares discards any observation with a missing value in any predictor. With $p$ predictors each independently missing $5\%$ of the time, a complete case analysis with $p = 20$ retains only $0.95^{20} = 35.8\%$ of the data. A tree with surrogates keeps all of it.
Interpretation

Feature Importance and Tree Properties

Variable importance The importance of predictor $X_j$ is the total reduction in impurity (RSS or Gini) due to splits on $X_j$, summed over all nodes where $X_j$ is used: $$\mathrm{VI}(j) = \sum_{\text{nodes } t:\,j \text{ used}} \bigl[\mathrm{Impurity}(t) - w_L\,\mathrm{Impurity}(t_L) - w_R\,\mathrm{Impurity}(t_R)\bigr]$$ where $w_L, w_R$ are the fractions of training observations in the left and right children. Higher importance means the predictor is used more frequently and produces larger purity gains.

High variance: the core weakness A decision tree fitted on a slightly different training set can look completely different. This instability is what makes ensembles (bagging, random forests, boosting) so powerful: they average over many trees to reduce variance.
Overfitting

Stopping Criteria and Overfitting

Common stopping criteria (pre-pruning)
  • Minimum node size: stop splitting if a node has fewer than $n_{\min}$ observations (e.g.\ 5 or 10)
  • Maximum depth: limit the tree to $d$ levels
  • Minimum impurity decrease: split only if the impurity reduction exceeds a threshold $\gamma$
  • Maximum leaf count: limit the total number of leaves
Pre-pruning vs post-pruning Pre-pruning (stopping early) is simple but myopic: a split that appears unhelpful may enable a good split two levels deeper. Post-pruning (grow a full tree then prune back) is more principled and is the approach taken by CART via cost-complexity pruning, covered in Module 19.
Overfitting in deep trees A fully grown tree (one observation per leaf) has training error = 0 but extremely high test error. Each leaf memorises a single training point. The bias-variance trade-off: shallow trees have high bias (underfitting), deep trees have high variance (overfitting). Cost-complexity pruning selects the tree size by cross-validation.
Comparison

Trees Compared with Linear Models

Neither model class dominates. The right choice depends on the shape of the true relationship.

When each wins If the true relationship really is close to linear and additive, linear regression wins: it estimates $p+1$ parameters efficiently, whereas a tree needs many splits to approximate a straight line with a staircase and pays for each in variance. If the relationship is highly non linear with strong interactions, the tree wins, because it discovers that structure without being told where to look.
The instability point matters A single tree has high variance: refitting on a slightly different sample can produce a visibly different tree. This weakness is precisely what bagging and random forests exist to correct, by averaging many trees grown on resampled data.
In-Class Exercise

In-Class Exercise

Questions
  1. A node contains four observations $(X,Y) = (1,3),\,(2,5),\,(3,10),\,(4,12)$. Compute the RSS of the node before any split.
  2. Evaluate the three candidate splits $X < 1.5$, $X < 2.5$ and $X < 3.5$. Which does recursive binary splitting choose, and how much RSS does it remove?
  3. Using the chosen split, what does the tree predict for a new observation with $X = 3.2$?
  4. A regression tree is fitted to $n=200$ observations with $p=10$ predictors. At each split, the algorithm considers all $10 \times (n-1)$ possible split points. In what way does recursive binary splitting approximate the optimal solution?
  1. $\bar y = (3+5+10+12)/4 = 7.5$, so $\text{RSS} = (-4.5)^2+(-2.5)^2+2.5^2+4.5^2 = 20.25+6.25+6.25+20.25 = 53.00$.
  2. $X < 1.5$: left $\{3\}$, right $\{5,10,12\}$ with mean $9$, total RSS $= 0 + (16+1+9) = 26.00$. $X < 2.5$: left $\{3,5\}$ with mean $4$ (RSS $2$), right $\{10,12\}$ with mean $11$ (RSS $2$), total $= \mathbf{4.00}$. $X < 3.5$: left $\{3,5,10\}$ with mean $6$ (RSS $26$), right $\{12\}$, total $= 26.00$. The split $X < 2.5$ is chosen, removing $53 - 4 = 49$ of RSS, which is $92.5\%$.
  3. $X = 3.2 \geq 2.5$, so the observation falls in the right leaf, whose prediction is the mean of $\{10, 12\}$, namely $11$.
  4. With $n=200$ and $p=10$ the algorithm evaluates $10 \times 199 = 1990$ candidate splits at the root. Recursive binary splitting is greedy: each split is chosen to minimise the current RSS, without considering future splits. A globally optimal tree (over all possible hierarchical partitions) requires exponential search. The greedy algorithm is the tractable approximation; it performs well in practice despite the global suboptimality.
Practice Problems

Practice Problems

Problem 1: Conceptual
  1. Explain why a decision tree does not require feature standardisation, while logistic regression and ridge regression do.
  2. True or False: A fully grown decision tree (one leaf per training observation) always has lower test MSE than a depth-2 tree on the same data.
  3. A tree is grown on a dataset with a continuous predictor $X$ taking values $\{1.2, 3.4, 5.1, 7.8, 9.0\}$. How many distinct split points does CART consider for $X$?
  1. Decision tree splits are of the form $X_j < s$: the scale of $X_j$ does not affect which split is chosen, only the threshold $s$. In contrast, ridge regression penalises $\sum\beta_j^2$ and logistic regression uses $\mathbf{x}^\top\boldsymbol\beta$: both treat coefficients differently depending on predictor scale, so standardisation is needed for fair penalisation or comparison.
  2. False. A fully grown tree has zero training error (each leaf contains one observation) but very high variance. Its test MSE will be much higher than that of a pruned tree. Lower training error does not imply lower test MSE.
  3. Candidate split points are midpoints between consecutive sorted values: $(1.2+3.4)/2=2.3$, $(3.4+5.1)/2=4.25$, $(5.1+7.8)/2=6.45$, $(7.8+9.0)/2=8.4$. CART considers 4 candidate split points.
Problem 2: Calculation A regression tree node contains six observations $(X,Y)$: $(1,4),\,(2,6),\,(3,5),\,(4,12),\,(5,14),\,(6,13)$.
  1. Compute the RSS of the node before splitting.
  2. Compute the total RSS after the split $X < 3.5$, and state the prediction in each child.
  3. Compute the RSS reduction. Is this split worthwhile?
  1. $\bar y = 54/6 = 9$, so $\text{RSS} = 25+9+16+9+25+16 = 100.00$.
  2. Left $\{4,6,5\}$ has mean $5$ and $\text{RSS}_L = 1+1+0 = 2$. Right $\{12,14,13\}$ has mean $13$ and $\text{RSS}_R = 1+1+0 = 2$. Total $= 4.00$. The tree predicts $5$ for $X < 3.5$ and $13$ for $X \geq 3.5$.
  3. Reduction $= 100 - 4 = 96$, which is $96\%$ of the total variation. This is a very worthwhile split: the data fall into two tight, well separated groups, and one split captures almost all the structure.
Problem 3: Conceptual
  1. A decision tree assigns a variable importance score to each predictor. What does it mean if predictor $X_3$ has the highest importance in a regression tree?
  2. You compare a single deep decision tree and a linear regression model on the same dataset. The linear model has lower test MSE. What does this suggest about the true relationship?
  1. $X_3$ produces the largest total reduction in RSS (or Gini) across all nodes where it is used as a splitting variable. It is the most useful predictor for partitioning the data into homogeneous regions. Note: importance is based on training data and may not reflect the true population importance, especially if predictors are correlated.
  2. The true relationship is likely approximately linear (or at least smoother than what the tree captures). Linear regression imposes a global parametric structure that fits well when the signal is linear; a deep tree uses its flexibility to fit noise, resulting in high variance. When linear regression beats a decision tree, it suggests the nonlinear patterns are weak and the tree's high variance outweighs its lower bias.
