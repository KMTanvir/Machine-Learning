Module 09: QDA and Naive Bayes

Module 09

QDA and Naive Bayes

Module 08 introduced LDA with a shared covariance matrix, giving linear boundaries. This module covers two extensions: QDA (class-specific covariances, quadratic boundaries) and Naive Bayes (independent features within each class).

QDA: Relaxes LDA's shared covariance assumption. Each class has its own $\boldsymbol\Sigma_k$. Decision boundaries become quadratic.
Naive Bayes: Assumes features are conditionally independent within each class. Works for any feature distribution. Extremely fast and scalable.

Learning Objectives

  • Derive QDA discriminant scores and decision boundaries
  • Compare LDA and QDA: bias-variance tradeoff
  • State and apply the Naive Bayes assumption
  • Identify when each classifier is appropriate
QDA

Quadratic Discriminant Analysis

QDA assumption: $\mathbf{X} \mid Y = k \sim \mathcal{N}(\boldsymbol\mu_k, \boldsymbol\Sigma_k)$ with a class-specific covariance $\boldsymbol\Sigma_k$.
QDA discriminant score: $$\delta_k(\mathbf{x}) = -\frac{1}{2}(\mathbf{x}-\boldsymbol\mu_k)^\top\boldsymbol\Sigma_k^{-1}(\mathbf{x}-\boldsymbol\mu_k) - \frac{1}{2}\log|\boldsymbol\Sigma_k| + \log\pi_k$$ Assign $\mathbf{x}$ to class $k^* = \arg\max_k \delta_k(\mathbf{x})$.
Why quadratic? Unlike LDA, the $\mathbf{x}^\top\boldsymbol\Sigma_k^{-1}\mathbf{x}$ term now differs across classes (because $\boldsymbol\Sigma_k$ varies), so it does not cancel. The boundary is a quadratic function of $\mathbf{x}$.
QDA requires estimating a separate $\boldsymbol\Sigma_k$ for each class. With $p$ features, each $\boldsymbol\Sigma_k$ has $p(p+1)/2$ parameters. More flexible but higher variance: needs larger training sets.

LDA vs QDA: Bias-Variance Tradeoff

PropertyLDAQDA
CovarianceShared $\boldsymbol\Sigma$Class-specific $\boldsymbol\Sigma_k$

ParametersFewer (lower variance)More (higher variance)
BiasHigher (if covariances differ)Lower

Decision rule:
  • If the true decision boundary is approximately linear: use LDA
  • If the true boundary is non-linear and training set is large: use QDA
  • With small $n$, LDA's lower variance usually outperforms QDA despite potential bias
Naive Bayes

The Naive Bayes Classifier

Naive Bayes assumption (conditional independence): $$f_k(\mathbf{x}) = P(\mathbf{X} = \mathbf{x} \mid Y = k) = \prod_{j=1}^p f_{kj}(x_j)$$ Within each class $k$, all features $X_1, \ldots, X_p$ are assumed independent.
Naive Bayes posterior: $$P(Y = k \mid \mathbf{X} = \mathbf{x}) \propto \pi_k \prod_{j=1}^p f_{kj}(x_j)$$ Taking logs: classify to the class $k$ maximising $$\log\pi_k + \sum_{j=1}^p \log f_{kj}(x_j)$$
The assumption of conditional independence within classes is "naive" because it is usually violated in practice. Yet Naive Bayes often performs surprisingly well despite this, especially for text classification and spam filtering.
Naive Bayes

Estimating Naive Bayes

Each marginal density $f_{kj}(x_j)$ is estimated separately, making Naive Bayes very flexible:

Quantitative $X_j$: Assume $X_j \mid Y=k \sim \mathcal{N}(\mu_{kj}, \sigma_{kj}^2)$. Estimate $\hat\mu_{kj}$ and $\hat\sigma_{kj}^2$ from class $k$ training observations. This gives Gaussian Naive Bayes.
Categorical $X_j$: Estimate $P(X_j = c \mid Y = k)$ by the fraction of class $k$ observations with $X_j = c$. This is the classic Naive Bayes for text (bag-of-words).
Key insight: Naive Bayes only needs to estimate $p$ univariate densities per class rather than one $p$-dimensional joint density. This dramatically reduces the number of parameters: from $O(p^2)$ (QDA) to $O(p)$ per class.
Naive Bayes

Why Naive Bayes Works Despite the Naive Assumption

The independence assumption is almost always wrong. In real data, features are correlated. For example, in email spam detection, words like "free" and "offer" tend to co-occur.

Despite this, Naive Bayes often gives good classification results because:

  • We only need the ranking of posterior probabilities to classify correctly, not their exact values
  • The bias from the wrong assumption can be outweighed by the variance reduction from estimating far fewer parameters
  • When $p$ is large relative to $n$, this variance reduction is crucial
Relationship to LDA: Gaussian Naive Bayes is a special case of LDA where $\boldsymbol\Sigma$ is forced to be diagonal (off-diagonal covariances set to zero).

Example

Naive Bayes Example: Spam Filter

Binary classification: spam (1) vs ham (0). Two features: $X_1$ = contains "free" (1/0), $X_2$ = contains "meeting" (1/0).

Training data: 100 spam, 400 ham emails.

Feature$P(X_j=1 \mid \text{spam})$$P(X_j=1 \mid \text{ham})$
Contains "free"0.700.05
Contains "meeting"0.100.60

New email: contains "free" but not "meeting" ($x_1=1, x_2=0$). Priors: $\pi_1=0.2$, $\pi_0=0.8$.

$P(\text{spam}\mid\mathbf{x}) \propto 0.2 \times 0.70 \times 0.90 = 0.126$ $P(\text{ham}\mid\mathbf{x}) \propto 0.8 \times 0.05 \times 0.40 = 0.016$ Normalised: $P(\text{spam}\mid\mathbf{x}) = 0.126/(0.126+0.016) \approx 0.887$. Classify as spam.
In-Class Exercise

In-Class Exercise: QDA vs LDA

Two classes, one predictor. Class 1: $\hat\mu_1 = 0$, $\hat\sigma_1^2 = 1$. Class 2: $\hat\mu_2 = 3$, $\hat\sigma_2^2 = 4$. Equal priors.

  1. Write the QDA discriminant scores $\delta_1(x)$ and $\delta_2(x)$.
  2. Is the decision boundary a single point or can there be two boundary points? Why?
  3. What would the LDA boundary be (using pooled variance)?
  4. At $x = 1.5$, which class does QDA assign? Which does LDA assign?

1. $\delta_k(x) = -\frac{(x-\mu_k)^2}{2\sigma_k^2} - \frac{1}{2}\log\sigma_k^2 + \log\pi_k$

$\delta_1(x) = -(x-0)^2/2 - \frac{1}{2}\log 1 + 0 = -x^2/2$

$\delta_2(x) = -(x-3)^2/8 - \frac{1}{2}\log 4 + 0 = -(x-3)^2/8 - \log 2$

2. Setting $\delta_1 = \delta_2$: $-x^2/2 = -(x-3)^2/8 - \log 2$. This is a quadratic equation in $x$ and can have up to two solutions (two boundary points), unlike LDA which always has exactly one.

Solving: $-4x^2 = -(x-3)^2 - 8\log 2 \Rightarrow -4x^2 = -x^2+6x-9-5.545 \Rightarrow 3x^2+6x-14.545=0$. Discriminant positive: two roots $\approx -3.55$ and $\approx 1.55$.

3. LDA pooled variance: $\hat\sigma^2 = (n_1\sigma_1^2 + n_2\sigma_2^2)/(n_1+n_2-2)$. With equal class sizes: $\approx (1+4)/2 = 2.5$. Boundary: $(\mu_1+\mu_2)/2 = 1.5$.

4. At $x=1.5$: $\delta_1(1.5) = -1.125$; $\delta_2(1.5) = -(1.5-3)^2/8 - \log 2 = -0.281 - 0.693 = -0.974$. QDA: $\delta_2 > \delta_1$, assign to class 2. LDA: $x=1.5$ is exactly at the boundary, tie broken as class 2 (or class 1, depending on convention).

Practice Problems

Problem 1: QDA Parameters

Three classes, $p = 2$ predictors. How many parameters does QDA need to estimate in total (means, covariances, priors)?

  1. Count the parameters for QDA.
  2. Count for LDA (shared covariance).
  3. Count for Naive Bayes (Gaussian, class-specific variances).

a. QDA: $Kp=6$ means $+$ $K\cdot p(p+1)/2=9$ covariances $+$ $(K-1)=2$ priors $=17$ parameters.

b. LDA (shared covariance): $Kp=6$ means $+$ $p(p+1)/2=3$ pooled covariances $+$ 2 priors $=11$ parameters.

c. Gaussian NB (class-specific variances, no covariances): $Kp=6$ means $+$ $Kp=6$ variances $+$ 2 priors $=14$ parameters.

Problem 2: Naive Bayes Calculation

Medical diagnosis. Disease (+) prevalence = 5%. Two test results: $P(T_1=+\mid +) = 0.90$, $P(T_1=+\mid -) = 0.10$; $P(T_2=+\mid +) = 0.80$, $P(T_2=+\mid -) = 0.20$. A patient has both tests positive.

  1. Using Naive Bayes, compute $P(\text{disease} \mid T_1=+, T_2=+)$.
  2. If only $T_1$ is positive, what is $P(\text{disease} \mid T_1=+)$ (standard Bayes)?

a. $P(+,+\mid D)=0.72$, $P(+,+\mid\bar D)=0.02$. $P(D\mid+,+)=0.72\times0.05/(0.72\times0.05+0.02\times0.95)=0.036/0.055\approx0.655$.

b. $P(D\mid T_1{=}+)=0.045/(0.045+0.095)\approx0.321$.

Problem 3: Choosing a Classifier

For each dataset, recommend LDA, QDA, or Naive Bayes and justify.

  1. $n = 50$, $p = 2$, $K = 2$, features approximately Gaussian, similar within-class spread.
  2. $n = 10{,}000$, $p = 500$ binary features (word presence in documents), $K = 3$.
  3. $n = 500$, $p = 3$, $K = 4$, clear evidence that class covariances differ substantially.

a. LDA: small $n$, Gaussian, equal covariance likely. b. Naive Bayes: $p=500$ binary features, QDA/LDA covariance estimation infeasible. c. QDA: class covariances clearly differ.

Problem 4: True or False
  1. QDA always outperforms LDA because it is more flexible.
  2. Naive Bayes requires the features to be normally distributed.
  3. LDA is a special case of QDA where $\boldsymbol\Sigma_1 = \boldsymbol\Sigma_2 = \cdots = \boldsymbol\Sigma_K$.
  4. Naive Bayes can fail to produce valid probabilities if a feature value never occurs in a class in the training data (zero-frequency problem).

a. False: QDA has higher variance; LDA can win when true covariances are similar. b. False: NB assumes feature independence, not normality. c. True. d. True: zero training frequency collapses the posterior; Laplace smoothing is needed.

Summary

Module 09 Summary

QDA Key Points
  • Class-specific $\boldsymbol\Sigma_k$: quadratic boundaries
  • $\delta_k(\mathbf{x}) = -\frac{1}{2}(\mathbf{x}-\boldsymbol\mu_k)^\top\boldsymbol\Sigma_k^{-1}(\mathbf{x}-\boldsymbol\mu_k) - \frac{1}{2}\log|\boldsymbol\Sigma_k| + \log\pi_k$
  • More flexible than LDA, needs more data
  • Up to 2 boundary points per pair of classes (in 1D)
Naive Bayes Key Points
  • Conditional independence: $f_k(\mathbf{x}) = \prod_j f_{kj}(x_j)$
  • Works for any feature type (Gaussian, binary, count)
  • Only $O(Kp)$ parameters: very efficient
  • Often surprisingly good despite wrong assumption
  • Needs Laplace smoothing for zero-frequency problem
