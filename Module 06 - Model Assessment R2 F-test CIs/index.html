Module 06: Model Assessment: R², F-test, CIs

Module 06

Model Assessment: R², F-test, CIs

After fitting a regression model, we need to answer: how good is it? This module consolidates the key tools for assessing and comparing linear regression models.

Three core questions in model assessment:
  1. Is the model useful? (F-test, individual t-tests)
  2. How well does it fit the data? (RSE, R², adjusted R²)
  3. How precise are predictions? (CIs, prediction intervals)

Learning Objectives

  • Interpret RSE, $R^2$, and adjusted $R^2$ correctly
  • Conduct and interpret $F$-tests for nested models
  • Distinguish confidence intervals from prediction intervals
  • Use AIC and BIC for model comparison
Fit

Residual Standard Error

$$\mathrm{RSE} = \sqrt{\frac{\mathrm{RSS}}{n - p - 1}}$$ where $p$ is the number of predictors (not counting the intercept).

Interpretation

  • RSE estimates $\sigma$, the standard deviation of the error $\varepsilon$
  • It is in the same units as $Y$
  • It represents the average amount that the response deviates from the true regression plane
  • A model is a good fit if RSE is small relative to the mean of $Y$
Relative RSE: $\mathrm{RSE}/\bar y \times 100\%$ gives a percentage measure of fit. For the Advertising data, $\mathrm{RSE} = 1.69$ and $\bar y = 14.02$, so typical error is about 12%.
RSE depends on $n$ and $p$ via the degrees of freedom $n-p-1$. Adding useless predictors reduces $n-p-1$ but barely reduces RSS, so RSE can increase.
Fit

R² and Its Limits

$$R^2 = 1 - \frac{\mathrm{RSS}}{\mathrm{TSS}} = \frac{\mathrm{ESS}}{\mathrm{TSS}}$$ Always between 0 and 1. Proportion of variance in $Y$ explained by the model.
Problem: $R^2$ always increases when predictors are added, even if the new predictor is completely irrelevant (noise). It can never decrease.
Adjusted R² penalises for the number of predictors: $$\bar R^2 = 1 - \frac{\mathrm{RSS}/(n-p-1)}{\mathrm{TSS}/(n-1)}$$ $\bar R^2$ can decrease when a useless predictor is added. Use $\bar R^2$ (not $R^2$) when comparing models with different numbers of predictors.

F-test

F-test for Nested Models

Compare a full model (with $p$ predictors) against a reduced model (with $q < p$ predictors, where the reduced model is obtained by setting some coefficients to zero).

Hypotheses: $H_0:$ the reduced model is adequate vs $H_a:$ the full model is needed. Equivalently: $H_0: \beta_{q+1} = \cdots = \beta_p = 0$
$$F = \frac{(\mathrm{RSS}_{\text{red}} - \mathrm{RSS}_{\text{full}})/(p - q)}{\mathrm{RSS}_{\text{full}}/(n - p - 1)}$$ Under $H_0$: $F \sim F_{p-q,\; n-p-1}$
Special case: When $q = 0$ (comparing against intercept-only model), this becomes the overall $F$-test from Module 05.
The reduced model must be nested inside the full model: all predictors in the reduced model must also appear in the full model.
F-test

F-test Example: Is Newspaper Useful?

Full model: Sales $\sim$ TV + Radio + Newspaper ($p=3$, $\mathrm{RSS}_{\text{full}} = 556.8$)

Reduced model: Sales $\sim$ TV + Radio ($q=2$, $\mathrm{RSS}_{\text{red}} = 556.9$)

$n = 200$

$$F = \frac{(556.9 - 556.8)/(3-2)}{556.8/(200-3-1)} = \frac{0.1/1}{556.8/196} = \frac{0.1}{2.841} \approx 0.035$$

$p$-value $\approx 0.85$: no evidence that Newspaper adds value beyond TV and Radio.

Conclusion: The reduced model (TV + Radio only) is adequate. Newspaper can be dropped. This matches the individual $t$-test result for Newspaper in Module 05.
In this case, the individual $t$-test and the partial $F$-test give the same result. In general, when testing a single coefficient, $F = t^2$.
Prediction

Confidence Intervals for Predictions

At a new point $\mathbf{x}^* = (1, x_1^*, \ldots, x_p^*)^\top$, the predicted value is $\hat y^* = (\mathbf{x}^*)^\top \hat{\boldsymbol\beta}$.

Confidence interval for $E[Y|\mathbf{x}^*]$ (mean response): $$\hat y^* \pm t_{n-p-1,\alpha/2} \cdot \mathrm{SE}(\hat\mu^*)$$ where $\mathrm{SE}(\hat\mu^*)^2 = \hat\sigma^2\,(\mathbf{x}^*)^\top(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{x}^*$
Prediction interval for a new observation: $$\hat y^* \pm t_{n-p-1,\alpha/2} \cdot \mathrm{SE}(\hat y^*)$$ where $\mathrm{SE}(\hat y^*)^2 = \hat\sigma^2\!\left[1 + (\mathbf{x}^*)^\top(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{x}^*\right]$
The PI is always wider than the CI by $\hat\sigma^2$ inside the square root. Both intervals widen as $\mathbf{x}^*$ moves away from the centre of the training data.
Prediction

Extrapolation: A Warning

Extrapolation: Predicting at values of $\mathbf{x}^*$ far outside the range of the training data. The model may be seriously wrong there, since linearity is only assumed (and verified) in the observed range.

Leverage and Influence

  • Leverage $h_{ii} = (\mathbf{X}(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top)_{ii}$: measures how far $\mathbf{x}_i$ is from the centre of the design. High-leverage points can have disproportionate influence on $\hat{\boldsymbol\beta}$.
  • Cook's distance: measures how much $\hat{\boldsymbol\beta}$ changes if observation $i$ is removed. Combines leverage and residual size.
$$D_i = \frac{(\hat{\boldsymbol\beta} - \hat{\boldsymbol\beta}_{(-i)})^\top \mathbf{X}^\top\mathbf{X}\,(\hat{\boldsymbol\beta} - \hat{\boldsymbol\beta}_{(-i)})}{(p+1)\hat\sigma^2}$$ Rule of thumb: $D_i > 1$ may indicate influential observation.
Model Comparison

AIC and BIC for Model Comparison

For comparing non-nested models (or as an alternative to $F$-tests for nested models):

$$\mathrm{AIC} = n\log\!\left(\frac{\mathrm{RSS}}{n}\right) + 2(p+1)$$ $$\mathrm{BIC} = n\log\!\left(\frac{\mathrm{RSS}}{n}\right) + (p+1)\log n$$
CriterionPenalty per parameterFavours
AIC$2$Prediction accuracy (larger models)
BIC$\log n$Parsimony (smaller models for $n > 7$)
Adj. $R^2$$\frac{n-1}{n-p-1} - 1$Goodness of fit (adjusted)
BIC is consistent: as $n \to \infty$, it selects the true model (if it is among the candidates). AIC is not consistent but often gives better predictive models in finite samples.
Best practice: Use cross-validation to estimate test MSE directly. AIC/BIC are approximations; CV is model-agnostic and more principled.

In-Class Exercise

In-Class Exercise: Model Comparison

Three models are fitted to the same dataset ($n = 100$):

ModelPredictors ($p$)RSS$R^2$
M1112000.700
M239000.775
M378600.785

TSS $= 4000$.

  1. Compute adjusted $R^2$ for each model. Which is best by this criterion?
  2. Compute AIC for each model. Which model wins?
  3. Test whether M2 is a significant improvement over M1 using a partial $F$-test.
  4. Test whether M3 is a significant improvement over M2.

1. Adjusted R²:

M1: $\bar R^2 = 1 - \frac{1200/98}{4000/99} = 1 - \frac{12.24}{40.40} = 0.697$

M2: $\bar R^2 = 1 - \frac{900/96}{4000/99} = 1 - \frac{9.375}{40.40} = 0.768$

M3: $\bar R^2 = 1 - \frac{860/92}{4000/99} = 1 - \frac{9.348}{40.40} = 0.769$

M3 slightly edges M2, but the improvement is tiny.

2. AIC: $\mathrm{AIC} = 100\log(\mathrm{RSS}/100) + 2(p+1)$

M1: $100\log(12) + 4 = 248.5 + 4 = 252.5$

M2: $100\log(9) + 8 = 219.7 + 8 = 227.7$

M3: $100\log(8.6) + 16 = 215.2 + 16 = 231.2$

M2 has the lowest AIC: best balance of fit and complexity.

3. Partial F, M1 vs M2: $F = \frac{(1200-900)/(3-1)}{900/96} = \frac{150}{9.375} = 16.0$, $df=(2,96)$, $p \ll 0.001$. M2 is a significant improvement.

4. Partial F, M2 vs M3: $F = \frac{(900-860)/(7-3)}{860/92} = \frac{10}{9.348} = 1.07$, $df=(4,92)$, $p \approx 0.38$. M3 is NOT a significant improvement over M2.

Practice Problems

Practice Problems

Problem 1: RSE and R²

A model with $p=2$ predictors fitted to $n=50$ observations gives $\mathrm{RSS}=480$ and $\mathrm{TSS}=2000$.

  1. Compute $R^2$, adjusted $R^2$, and RSE.
  2. A third predictor is added, giving $\mathrm{RSS}=470$. Compute the new adjusted $R^2$. Should the new predictor be retained?

a. $R^2=1-480/2000=0.76$. $\bar R^2=1-(480/47)/(2000/49)=0.750$. RSE$=\sqrt{480/47}\approx3.196$.

b. With third predictor: $\bar R^2=1-(470/46)/(2000/49)\approx0.750$. Adjusted $R^2$ is essentially unchanged; the predictor provides negligible improvement and need not be retained.

Problem 2: Nested F-test

Full model ($p=5$, $n=80$): $\mathrm{RSS}=320$. Reduced model ($q=2$): $\mathrm{RSS}=410$.

  1. Compute the partial $F$-statistic for testing whether the 3 additional predictors are jointly useful.
  2. The critical value $F_{3,74,0.05} \approx 2.73$. State your conclusion.

a. Partial $F=\frac{(410-320)/3}{320/74}=\frac{30}{4.324}\approx6.94$.

b. Since $6.94>2.73$, reject $H_0$: the three additional predictors jointly improve the model; the full model is preferred.

Problem 3: CI vs PI

At $\mathbf{x}^* $: $\hat y^* = 45$, $\hat\sigma = 6$, $(\mathbf{x}^*)^\top(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{x}^* = 0.04$, $n-p-1 = 60$ (use $z = 1.96$).

  1. Compute the 95% CI for the mean response.
  2. Compute the 95% PI for a new observation.
  3. The new point is far from the training data centre. How does this affect the intervals?

a. SE$(\hat\mu)=6\sqrt{0.04}=1.2$. 95\% CI: $45\pm1.96\times1.2=(42.6,\ 47.4)$.

b. SE(new)$=\sqrt{36+1.44}=\sqrt{37.44}\approx6.12$. 95\% PI: $45\pm1.96\times6.12=(33.0,\ 57.0)$.

c. A point far from the training data centre has a larger leverage term $(\mathbf{x}^*)^\top(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{x}^*$, which widens both the CI and PI. The farther the point, the greater the extrapolation uncertainty.

Problem 4: AIC and BIC

Two models with $n=200$: Model A has $p=3$, $\mathrm{RSS}=800$. Model B has $p=6$, $\mathrm{RSS}=740$.

  1. Compute AIC for both. Which is preferred?
  2. Compute BIC for both. Do you reach the same conclusion?

a. $\hat\sigma^2_A=800/196\approx4.08$. AIC$_A\approx200\ln(4.08)+8\approx292$. $\hat\sigma^2_B=740/193\approx3.83$. AIC$_B\approx200\ln(3.83)+14\approx280$. AIC prefers Model B ($280<292$).

b. BIC$_A\approx200\ln(4.08)+4\ln(200)\approx305$. BIC$_B\approx200\ln(3.83)+7\ln(200)\approx303$. BIC also prefers Model B ($303<305$) but the margin is narrow.

Summary

Module 06 Summary

Key Formulas
  • $\mathrm{RSE} = \sqrt{\mathrm{RSS}/(n-p-1)}$
  • $R^2 = 1 - \mathrm{RSS}/\mathrm{TSS}$
  • $\bar R^2 = 1 - \frac{\mathrm{RSS}/(n-p-1)}{\mathrm{TSS}/(n-1)}$
  • Partial $F = \frac{(\mathrm{RSS}_r-\mathrm{RSS}_f)/(p-q)}{\mathrm{RSS}_f/(n-p-1)}$
  • $\mathrm{AIC} = n\log(\mathrm{RSS}/n) + 2(p+1)$
Key Rules
  • $R^2$ always increases: use $\bar R^2$ to compare models
  • Partial $F$-test for nested model comparison
  • PI always wider than CI
  • Both intervals widen with extrapolation
  • BIC penalises more than AIC for large $n$
