Module 08

Linear Discriminant Analysis (LDA)

We begin Part C: Classification Methods. LDA is an alternative to logistic regression that classifies observations using Bayes' theorem with Gaussian class-conditional distributions.

Classification Problem Given $\mathbf{X}$, assign an observation to one of $K$ classes. LDA models $P(Y = k \mid \mathbf{X})$ indirectly via Bayes' theorem, modelling $P(\mathbf{X} \mid Y = k)$ instead.

Learning Objectives

  • Apply Bayes' theorem for classification
  • Derive the LDA decision rule for $K = 2$ and $K > 2$ classes
  • Interpret the linear decision boundary
  • Compare LDA with logistic regression
  • Evaluate classifiers using error rates and confusion matrices
Reference: ISLR Chapter 4 (Sections 4.4–4.5)
Bayes Classifier

Bayes' Theorem for Classification

The ideal classifier assigns observation $\mathbf{x}$ to the class with the highest posterior probability.

Bayes' theorem: $$P(Y = k \mid \mathbf{X} = \mathbf{x}) = \frac{\pi_k \cdot f_k(\mathbf{x})}{\sum_{l=1}^K \pi_l \cdot f_l(\mathbf{x})}$$ where $\pi_k = P(Y = k)$ is the prior probability of class $k$, and $f_k(\mathbf{x}) = P(\mathbf{X} = \mathbf{x} \mid Y = k)$ is the class-conditional density.
Bayes classifier: Assign $\mathbf{x}$ to class $k^* = \arg\max_k P(Y = k \mid \mathbf{X} = \mathbf{x})$. This minimises the overall misclassification rate (Bayes error rate).
The Bayes classifier is the gold standard but requires knowing $\pi_k$ and $f_k(\mathbf{x})$. LDA estimates these from training data under specific assumptions about $f_k$.
LDA Setup

LDA Assumptions

LDA assumptions:
  1. Each class-conditional density is Gaussian: $\mathbf{X} \mid Y = k \sim \mathcal{N}(\boldsymbol\mu_k, \boldsymbol\Sigma)$
  2. All classes share the same covariance matrix $\boldsymbol\Sigma$ (homoscedasticity across classes)
Univariate ($p = 1$): $$f_k(x) = \frac{1}{\sqrt{2\pi}\sigma}\exp\!\left(-\frac{(x-\mu_k)^2}{2\sigma^2}\right)$$ with common variance $\sigma^2$.
Multivariate ($p > 1$): $$f_k(\mathbf{x}) = \frac{1}{(2\pi)^{p/2}|\boldsymbol\Sigma|^{1/2}}\exp\!\left(-\frac{1}{2}(\mathbf{x}-\boldsymbol\mu_k)^\top\boldsymbol\Sigma^{-1}(\mathbf{x}-\boldsymbol\mu_k)\right)$$
The shared covariance assumption is what makes the decision boundaries linear. Relaxing this gives Quadratic Discriminant Analysis (QDA), covered in Module 09.
Decision Rule

LDA Decision Rule: One Predictor

For $p = 1$ and $K = 2$ classes, plugging Gaussian $f_k(x)$ into Bayes' theorem and taking logs, assign $x$ to class $k$ with the largest discriminant score:

Linear discriminant score: $$\delta_k(x) = x \cdot \frac{\mu_k}{\sigma^2} - \frac{\mu_k^2}{2\sigma^2} + \log\pi_k$$ Classify $x$ to class $k^* = \arg\max_k \delta_k(x)$.

Decision Boundary for $K = 2$

The boundary where $\delta_1(x) = \delta_2(x)$:

$$x^* = \frac{\mu_1^2 - \mu_2^2}{2(\mu_1 - \mu_2)} - \frac{\sigma^2 \log(\pi_1/\pi_2)}{\mu_1 - \mu_2} = \frac{\mu_1 + \mu_2}{2} - \frac{\sigma^2\log(\pi_1/\pi_2)}{\mu_1-\mu_2}$$ With equal priors ($\pi_1 = \pi_2$): boundary is the midpoint $x^* = (\mu_1 + \mu_2)/2$.
Decision Rule

LDA for Multiple Predictors

For $p$ predictors and $K$ classes, the multivariate discriminant score is:

$$\delta_k(\mathbf{x}) = \mathbf{x}^\top\boldsymbol\Sigma^{-1}\boldsymbol\mu_k - \frac{1}{2}\boldsymbol\mu_k^\top\boldsymbol\Sigma^{-1}\boldsymbol\mu_k + \log\pi_k$$ Classify $\mathbf{x}$ to class $k^* = \arg\max_k \delta_k(\mathbf{x})$.
Why "Linear"? The decision boundaries between any two classes $k$ and $l$ are where $\delta_k(\mathbf{x}) = \delta_l(\mathbf{x})$. This simplifies to a linear function of $\mathbf{x}$ because the quadratic $\mathbf{x}^\top\boldsymbol\Sigma^{-1}\mathbf{x}$ term is the same for all classes and cancels.
The decision boundaries are hyperplanes in $\mathbb{R}^p$: lines in 2D, planes in 3D, etc. This is the defining characteristic of LDA.
Estimation

Estimating LDA Parameters

In practice, $\mu_k$, $\Sigma$, and $\pi_k$ are estimated from training data:

Prior: $\hat\pi_k = n_k / n$ (fraction of observations in class $k$) Class mean: $\hat{\boldsymbol\mu}_k = \frac{1}{n_k}\sum_{i:\, y_i=k} \mathbf{x}_i$ Pooled covariance: $$\hat{\boldsymbol\Sigma} = \frac{1}{n - K}\sum_{k=1}^K \sum_{i:\,y_i=k}(\mathbf{x}_i - \hat{\boldsymbol\mu}_k)(\mathbf{x}_i - \hat{\boldsymbol\mu}_k)^\top$$
The pooled covariance averages the within-class scatter matrices, weighted by class size. This enforces the shared covariance assumption.
Evaluation

Evaluating a Classifier

Confusion matrix (for $K = 2$ classes, Positive = class 1):

Actual NegativeTNFP

Key metrics:
  • Sensitivity (recall, TPR): $\mathrm{TP}/(\mathrm{TP}+\mathrm{FN})$
  • Specificity (TNR): $\mathrm{TN}/(\mathrm{TN}+\mathrm{FP})$
  • Precision (PPV): $\mathrm{TP}/(\mathrm{TP}+\mathrm{FP})$
  • Error rate: $(\mathrm{FP}+\mathrm{FN})/n$
ROC curve: Plots TPR vs FPR as the classification threshold varies from 0 to 1. AUC (area under ROC): 0.5 = random, 1 = perfect. AUC is threshold-independent.

Threshold

Adjusting the Classification Threshold

LDA (like logistic regression) uses threshold $c = 0.5$ by default. Adjusting $c$ trades off sensitivity and specificity.

Default threshold is not always best. For rare diseases, a lower threshold increases sensitivity (catches more true positives) at the cost of more false positives. The optimal threshold depends on the relative costs of FP and FN.
Optimal Bayes threshold (minimises expected cost): $$c^* = \frac{C_{10}}{C_{10} + C_{01}}$$ where $C_{10}$ = cost of FN (miss a positive) and $C_{01}$ = cost of FP. With equal costs: $c^* = 0.5$.
The ROC curve shows the full sensitivity-specificity tradeoff. Choose the threshold appropriate for the application, not just the default.

In-Class Exercise

In-Class Exercise: LDA Decision Rule

Two classes, one predictor ($p = 1$). Training data gives: $\hat\mu_1 = 2$, $\hat\mu_2 = 6$, $\hat\sigma^2 = 4$, $\hat\pi_1 = 0.6$, $\hat\pi_2 = 0.4$.

  1. Compute the discriminant scores $\delta_1(x)$ and $\delta_2(x)$.
  2. Find the decision boundary $x^*$. Which class would $x = 3.5$ be assigned to?
  3. If priors were equal ($\pi_1 = \pi_2 = 0.5$), what would the boundary be?
  4. Explain why unequal priors shift the boundary toward the less common class.

1. $\delta_k(x) = x\mu_k/\sigma^2 - \mu_k^2/(2\sigma^2) + \log\pi_k$

$\delta_1(x) = x(2)/4 - 4/8 + \log(0.6) = 0.5x - 0.5 - 0.511 = 0.5x - 1.011$

$\delta_2(x) = x(6)/4 - 36/8 + \log(0.4) = 1.5x - 4.5 - 0.916 = 1.5x - 5.416$

2. Set $\delta_1 = \delta_2$: $0.5x - 1.011 = 1.5x - 5.416 \Rightarrow -x = -4.405 \Rightarrow x^* = 4.405$.

For $x = 3.5 < 4.405$: $\delta_1(3.5) = 0.75$, $\delta_2(3.5) = -0.166$. Assign to class 1.

3. Equal priors: $x^* = (\mu_1 + \mu_2)/2 = (2+6)/2 = 4$.

4. The prior term $\log\pi_k$ rewards the more common class. With $\pi_1 > \pi_2$, class 1 gets a bonus, so the boundary shifts toward class 2 (higher $x$), making it harder to be classified as class 2.

Practice Problems

Practice Problems

Problem 1: Discriminant Scores

LDA with $K=2$, $p=1$: $\hat\mu_1 = -1$, $\hat\mu_2 = 3$, $\hat\sigma^2 = 2$, equal priors.

  1. Compute $\delta_1(x)$ and $\delta_2(x)$.
  2. Find the decision boundary. Classify $x = 0.5$ and $x = 2$.
  3. How does increasing $\sigma^2$ affect the boundary?

a. $\delta_k(x)=x\mu_k/\sigma^2-\mu_k^2/(2\sigma^2)+\log\pi_k$. With equal priors: $\delta_1(x)=-x/2-1/4$, $\delta_2(x)=3x/2-9/4$.

b. Set $\delta_1(x)=\delta_2(x)$: boundary at $x=1$. $x=0.5\Rightarrow\delta_1>\delta_2\Rightarrow$ class 1. $x=2\Rightarrow\delta_2>\delta_1\Rightarrow$ class 2.

c. With equal priors the boundary is always the midpoint $(\mu_1+\mu_2)/2=1$, independent of $\sigma^2$. Larger $\sigma^2$ only widens the overlap region but does not shift the boundary.

Problem 2: Confusion Matrix and Metrics

A classifier tested on $n = 200$ observations: TP = 45, FP = 15, FN = 10, TN = 130.

  1. Compute overall error rate, sensitivity, specificity, and precision.
  2. If the cost of FN is 4 times that of FP, what threshold adjustment is needed?
  3. Would you say this classifier has good performance? Justify.

a. Error$=25/200=12.5\%$. Sensitivity$=45/55=81.8\%$. Specificity$=130/145=89.7\%$. Precision$=45/60=75\%$.

b. Since FN costs $4\times$ FP, lower the classification threshold so the model predicts positive more readily, reducing FN at the cost of more FP.

c. Generally yes: 12.5\% error rate with 81.8\% sensitivity and 89.7\% specificity is solid. However, "good" depends on context. If FN is costly (e.g., disease screening), 18.2\% missed positives may still be unacceptable. Precision of 75\% means 1 in 4 positive predictions is wrong.

Problem 3: LDA vs Logistic Regression

For each scenario, state which method (LDA or logistic regression) is likely preferable and why.

  1. Features are approximately Gaussian within each class, $n = 80$, $K = 3$ classes.
  2. Features include binary indicators and skewed counts, $n = 5{,}000$, $K = 2$ classes.
  3. Classes are perfectly linearly separable in the training data.

a. LDA: small $n$, Gaussian, $K=3$. b. Logistic regression: large $n$, binary/skewed features. c. Logistic regression: perfect separation causes LDA scores to diverge; regularised logistic is more stable.

Problem 4: True or False
  1. LDA assumes each class has its own covariance matrix.
  2. The Bayes classifier minimises the overall misclassification error rate.
  3. LDA decision boundaries are always straight lines (or hyperplanes).
  4. A classifier with 99% accuracy on a dataset where 99% of observations belong to one class is necessarily a good classifier.

a. False: LDA assumes a shared $\Sigma$; QDA does not. b. True. c. True: linear discriminant scores give hyperplane boundaries. d. False: 99% accuracy on a 99/1 split can be achieved by always predicting the majority class; sensitivity is 0%.

Summary

Module 08 Summary

Key Formulas
  • $P(Y=k\mid\mathbf{x}) \propto \pi_k f_k(\mathbf{x})$
  • $\delta_k(\mathbf{x}) = \mathbf{x}^\top\boldsymbol\Sigma^{-1}\boldsymbol\mu_k - \frac{1}{2}\boldsymbol\mu_k^\top\boldsymbol\Sigma^{-1}\boldsymbol\mu_k + \log\pi_k$
  • Boundary: $x^* = \frac{\mu_1+\mu_2}{2}$ (equal priors, $p=1$)
  • Sensitivity: TP/(TP+FN)
  • Specificity: TN/(TN+FP)
Key Ideas
  • LDA uses Bayes' theorem with Gaussian $f_k$
  • Shared $\boldsymbol\Sigma$ gives linear boundaries
  • Estimated from training data (plug-in)
  • Compare via confusion matrix and ROC/AUC
  • Adjust threshold based on costs
