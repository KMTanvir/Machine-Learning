The Bootstrap

The bootstrap is a powerful resampling technique for quantifying uncertainty about an estimate. By repeatedly sampling with replacement from the observed data, it simulates the sampling distribution of any statistic without requiring distributional assumptions.

Core idea We treat the observed data as a proxy for the population. Each bootstrap sample mimics drawing a new dataset from that population. The variability across bootstrap samples approximates the variability of the statistic across repeated real samples.

Learning Objectives

  • Understand the bootstrap principle: sampling with replacement from observed data
  • Compute bootstrap standard errors for any statistic
  • Construct bootstrap confidence intervals: percentile, basic, and BCa
  • Apply the bootstrap in regression, model selection, and risk estimation
  • Recognise when bootstrap assumptions may fail
Reference: ISLR Chapter 5.2; Efron & Hastie, Computer Age Statistical Inference (2016), Ch. 10
The Bootstrap Idea

Motivation: Quantifying Uncertainty

Suppose we estimate a parameter $\theta$ using a statistic $\hat\theta = s(\mathbf{X})$. We want $\mathrm{SE}(\hat\theta)$, but we only have one dataset. How do we simulate repeated sampling?

Classical approach Derive $\mathrm{Var}(\hat\theta)$ analytically. This requires distributional assumptions and closed-form expressions. Not always possible for complex statistics (e.g., ratios, quantiles, prediction errors).
Bootstrap approach Draw $B$ samples of size $n$ with replacement from the original data. Compute $\hat\theta^{*b}$ on each. Estimate $\mathrm{SE}(\hat\theta)$ from the spread of $\hat\theta^{*1}, \ldots, \hat\theta^{*B}$.
Bootstrap standard error $$\widehat{\mathrm{SE}}_B(\hat\theta) = \sqrt{\frac{1}{B-1}\sum_{b=1}^B \bigl(\hat\theta^{*b} - \bar{\theta}^*\bigr)^2}, \qquad \bar\theta^* = \frac{1}{B}\sum_{b=1}^B \hat\theta^{*b}$$
Bootstrap Algorithm

The Bootstrap Algorithm

Nonparametric Bootstrap Given observed data $\mathbf{x} = (x_1, \ldots, x_n)$ and statistic $\hat\theta = s(\mathbf{x})$:
  1. For $b = 1$ to $B$: draw a bootstrap sample $\mathbf{x}^{*b} = (x^*_1, \ldots, x^*_n)$ by sampling $n$ observations with replacement from $\mathbf{x}$.
  2. Compute $\hat\theta^{*b} = s(\mathbf{x}^{*b})$.
  3. Estimate $\mathrm{SE}(\hat\theta)$, bias, or a confidence interval from $\{\hat\theta^{*b}\}_{b=1}^B$.
Properties of a bootstrap sample Each $\mathbf{x}^{*b}$ has $n$ observations drawn with replacement: on average, $1 - (1 - 1/n)^n \approx 1 - e^{-1} \approx 63.2\%$ of original observations appear at least once. The remaining $\approx 36.8\%$ are not included (these are the "out-of-bag" observations).
Example ($n=5$) Data: $\{2, 5, 8, 1, 6\}$. One bootstrap sample: $\{5, 2, 2, 8, 5\}$ (2 and 5 repeated, 1 and 6 absent). Another: $\{1, 8, 6, 6, 2\}$. Each is a valid size-$n$ resample.
Bootstrap Bias

Bias Estimation and Correction

Bootstrap bias estimate $$\widehat{\mathrm{Bias}}_B = \bar\theta^* - \hat\theta$$ where $\bar\theta^* = \frac{1}{B}\sum_b \hat\theta^{*b}$ and $\hat\theta$ is the estimate on the original data. The bootstrap bias-corrected estimator is: $$\hat\theta_{\mathrm{bc}} = \hat\theta - \widehat{\mathrm{Bias}}_B = 2\hat\theta - \bar\theta^*$$

Bias correction matters when the statistic is biased in small samples (e.g., maximum likelihood estimators for variance, correlation in small $n$).

When is bootstrap bias reliable? The bootstrap bias estimate is itself variable. Correcting for small estimated biases may increase variance more than it reduces bias. Rule of thumb: correct only when $|\widehat{\mathrm{Bias}}| > \tfrac{1}{4}\widehat{\mathrm{SE}}$.
Confidence Intervals

Bootstrap Confidence Intervals

Percentile Interval

Percentile CI Let $\hat\theta^{*(\alpha/2)}$ and $\hat\theta^{*(1-\alpha/2)}$ denote the $\alpha/2$ and $(1-\alpha/2)$ quantiles of the bootstrap distribution. The $(1-\alpha)$ percentile CI is: $$\bigl[\hat\theta^{*(\alpha/2)},\; \hat\theta^{*(1-\alpha/2)}\bigr]$$

Basic (Reflected) Interval

$$\bigl[2\hat\theta - \hat\theta^{*(1-\alpha/2)},\; 2\hat\theta - \hat\theta^{*(\alpha/2)}\bigr]$$ Reflects the bootstrap distribution around $\hat\theta$. More robust when the distribution is skewed.

Normal Approximation

$$\hat\theta \;\pm\; z_{\alpha/2}\,\widehat{\mathrm{SE}}_B(\hat\theta)$$ Appropriate only when the bootstrap distribution of $\hat\theta$ is approximately symmetric and normal.
BCa Interval

Bias-Corrected and Accelerated (BCa) Interval

The BCa interval is the gold-standard bootstrap CI: it corrects for both bias and skewness of the bootstrap distribution.

BCa interval Let $\Phi$ denote the standard normal CDF. Define: $$\hat{z}_0 = \Phi^{-1}\!\left(\frac{\#\{\hat\theta^{*b} < \hat\theta\}}{B}\right), \qquad \hat{a} = \frac{\sum_i (\bar\theta_{\cdot} - \hat\theta_{-i})^3}{6\bigl[\sum_i(\bar\theta_{\cdot} - \hat\theta_{-i})^2\bigr]^{3/2}}$$ where $\hat\theta_{-i}$ is the jackknife estimate leaving out observation $i$. The adjusted quantiles are: $$\alpha_1 = \Phi\!\left(\hat{z}_0 + \frac{\hat{z}_0 + z_{\alpha/2}}{1 - \hat{a}(\hat{z}_0 + z_{\alpha/2})}\right), \quad \alpha_2 = \Phi\!\left(\hat{z}_0 + \frac{\hat{z}_0 + z_{1-\alpha/2}}{1 - \hat{a}(\hat{z}_0 + z_{1-\alpha/2})}\right)$$ The BCa interval is $[\hat\theta^{*(\alpha_1)}, \hat\theta^{*(\alpha_2)}]$.
In practice $\hat{z}_0 = 0$ and $\hat{a} = 0$ recover the percentile interval. BCa is the default choice in most software (R's boot package, Python's scipy.stats.bootstrap).
Bootstrap in Regression

Bootstrapping Regression Coefficients

Case resampling (pairs bootstrap) Resample entire observation pairs $(x_i, y_i)$ with replacement. Refit the model on each bootstrap sample. Yields bootstrap distributions for $\hat\beta_j$. Valid under heteroscedasticity; no model assumptions beyond what is needed for estimation.
Residual resampling Fix $X$; resample residuals $\hat{e}_i$ with replacement; form $y_i^* = \hat{y}_i + e^*_i$; refit. Assumes homoscedastic errors and a correctly specified mean function. More powerful under correct model but fragile to misspecification.
Comparison with OLS standard errors OLS $\mathrm{SE}(\hat\beta_j) = \hat\sigma\sqrt{(X^\top X)^{-1}_{jj}}$ assumes homoscedastic normal errors. Bootstrap SEs make no such assumptions and are more reliable when errors are non-normal, heteroscedastic, or correlated.
Time-series data i.i.d. resampling breaks temporal dependence. Use block bootstrap (resample contiguous blocks) or stationary bootstrap instead.
Out-of-Bag Error

Out-of-Bag (OOB) Error Estimation

Out-of-Bag observations In bootstrap sample $b$, approximately 36.8% of original observations are not selected. These are the out-of-bag observations for sample $b$. We can use them to evaluate predictions without additional held-out data.
OOB error For each observation $i$, let $B_i = \{b : i \notin \mathbf{x}^{*b}\}$ be the set of bootstrap samples not containing $i$. The OOB prediction for $i$ is the average prediction from all models trained without $i$: $$\hat{y}_i^{\mathrm{OOB}} = \frac{1}{|B_i|}\sum_{b \in B_i} \hat{y}_i^{*b}$$ The OOB error is computed from $\{(y_i, \hat{y}_i^{\mathrm{OOB}})\}_{i=1}^n$.
OOB error is used directly in random forests as a built-in cross-validation estimate, providing an unbiased estimate of test error without any explicit held-out set. We will revisit this in Part G (Tree-Based Methods).
Parametric Bootstrap

Parametric Bootstrap

Parametric Bootstrap Instead of resampling from the observed data, sample from a fitted parametric model $\hat{F}_\theta$:
  1. Fit a parametric model to obtain $\hat\theta$ (e.g., fit a normal distribution, estimate $\hat\mu, \hat\sigma$).
  2. For $b = 1$ to $B$: generate $\mathbf{x}^{*b} \sim \hat{F}_\theta$ (simulate from the fitted model).
  3. Re-estimate $\hat\theta^{*b}$ on each simulated sample.
Advantage More efficient when the model is correctly specified: less variance in the bootstrap distribution.
Disadvantage If the parametric model is misspecified, the bootstrap distribution may be badly wrong. The nonparametric bootstrap is more robust.
When to use parametric bootstrap Useful for models where the likelihood is known (GLMs, survival models, time series). For general prediction problems, prefer the nonparametric bootstrap.
Worked Example

Worked Example: Bootstrap SE of a Correlation

Data: $(x, y)$ pairs with sample correlation $\hat\rho = 0.68$, $n = 20$. We run $B = 2000$ bootstrap samples and obtain bootstrap correlations $\hat\rho^{*b}$. Suppose $\bar\rho^* = 0.661$ and $\widehat{\mathrm{SE}}_B = 0.112$.

Bootstrap bias estimate: $$\widehat{\mathrm{Bias}} = \bar\rho^* - \hat\rho = 0.661 - 0.680 = -0.019$$ Since $|-0.019| < \tfrac{1}{4}(0.112) = 0.028$, bias correction is marginal; omit.
95% Normal CI: $$0.68 \pm 1.96 \times 0.112 = (0.461, 0.899)$$ 95% Percentile CI (from 2.5th and 97.5th percentiles of bootstrap distribution): Suppose $\hat\rho^{*(0.025)} = 0.438$, $\hat\rho^{*(0.975)} = 0.880$. CI: $(0.438, 0.880)$.
The two intervals differ because the bootstrap distribution of $\hat\rho$ is left-skewed (bounded above by 1): the percentile interval is more reliable.
In-Class Exercise

In-Class Exercise

A dataset has $n = 8$ observations of a single variable: $\{4, 7, 2, 9, 3, 6, 5, 8\}$. We are interested in the population median.

  1. Compute the sample median $\hat\theta$.
  2. Generate two bootstrap samples by hand (use the sequence of draws: sample 1: indices 3,1,7,2,5,3,8,4; sample 2: indices 6,6,2,1,4,7,3,5). Compute $\hat\theta^{*1}$ and $\hat\theta^{*2}$.
  3. If $B = 1000$ bootstrap medians have $\bar\theta^* = 5.72$ and $\widehat{\mathrm{SE}}_B = 0.94$, compute a 95% normal-approximation CI.
  4. Explain why the bootstrap SE for the median is larger than the bootstrap SE for the mean on the same data.

1. Sorted data: 2, 3, 4, 5, 6, 7, 8, 9. With $n=8$ (even), median $= (5+6)/2 = 5.5$.

2. Sample 1 draws (1-indexed into sorted order... but the data is given in original order $\{4,7,2,9,3,6,5,8\}$): indices 3,1,7,2,5,3,8,4 give values $\{2,4,5,7,3,2,8,9\}$. Sorted: 2,2,3,4,5,7,8,9. Median $= (4+5)/2 = 4.5$. Sample 2: indices 6,6,2,1,4,7,3,5 give $\{6,6,7,4,9,5,2,3\}$. Sorted: 2,3,4,5,6,6,7,9. Median $= (5+6)/2 = 5.5$.

3. 95% CI: $5.72 \pm 1.96 \times 0.94 = 5.72 \pm 1.84 = (3.88, 7.56)$.

4. The median depends only on the central order statistics and is insensitive to most of the data. Small changes in resampling can shift which value sits in the middle, producing larger variation. The mean uses all values linearly; its bootstrap distribution is more stable by the central limit theorem.

Practice Problems

Practice Problems

Problem 1: Conceptual
  1. Why does the nonparametric bootstrap treat the empirical distribution function as the population distribution? What assumption does this require?
  2. A researcher uses bootstrap with $B = 50$ and reports narrow confidence intervals. What is the risk, and what value of $B$ is more appropriate?
  3. True or False: The bootstrap can be applied to any statistic, including non-smooth statistics such as sample quantiles, without additional corrections.

a. The bootstrap uses the empirical CDF $\hat F_n$ as a proxy for the unknown population CDF $F$. This requires that the data are i.i.d. (or exchangeable) so that $\hat F_n$ is a consistent estimator of $F$. Without i.i.d., e.g. time series, the empirical distribution ignores dependence structure and the bootstrap is invalid.

b. With $B=50$ the Monte Carlo error in the SE estimate is large: $\mathrm{SE}(\widehat{\mathrm{SE}}) \approx \widehat{\mathrm{SE}}/\sqrt{2(B-1)} \approx \widehat{\mathrm{SE}}/10$, giving about 10% relative error. More importantly, quantile estimates for CI construction are unreliable with so few samples. Use $B \geq 1000$ for SEs, $B \geq 2000$ for 95% CIs, $B \geq 10000$ for 99% CIs.

c. False. The bootstrap is not automatically valid for non-smooth statistics such as the sample maximum or extreme quantiles. For the median, convergence is slower and the percentile interval may undercover at small $n$. BCa or studentized intervals are preferred.

Problem 2: Calculation

A study of $n = 6$ patients measures the ratio $\hat\theta = \bar{X}/\bar{Y}$ of two biomarkers. From $B = 5$ bootstrap samples (for illustration), the bootstrap estimates are: $\hat\theta^{*1} = 1.45$, $\hat\theta^{*2} = 1.21$, $\hat\theta^{*3} = 1.38$, $\hat\theta^{*4} = 1.52$, $\hat\theta^{*5} = 1.29$. The original estimate is $\hat\theta = 1.35$.

  1. Compute $\widehat{\mathrm{SE}}_B(\hat\theta)$.
  2. Compute $\widehat{\mathrm{Bias}}_B$. Should bias correction be applied? Use the rule $|\widehat{\mathrm{Bias}}| > \frac{1}{4}\widehat{\mathrm{SE}}$.

a. $\bar\theta^* = (1.45+1.21+1.38+1.52+1.29)/5 = 6.85/5 = 1.370$. Deviations: $(0.08, -0.16, 0.01, 0.15, -0.08)$. Squared: $(0.0064, 0.0256, 0.0001, 0.0225, 0.0064)$. Sum $= 0.0610$. $\widehat{\mathrm{SE}}_B = \sqrt{0.0610/4} = \sqrt{0.01525} \approx 0.1235$.

b. $\widehat{\mathrm{Bias}} = 1.370 - 1.350 = 0.020$. Threshold: $\frac{1}{4}(0.1235) = 0.031$. Since $0.020 < 0.031$, bias is small relative to SE: do not apply bias correction. (With $B=5$ the bias estimate itself has high uncertainty.)

Problem 3: Bootstrap in regression

A simple linear regression $Y = \beta_0 + \beta_1 X + \varepsilon$ is fit to $n = 30$ observations. OLS gives $\hat\beta_1 = 2.4$ with $\mathrm{SE}_{\mathrm{OLS}} = 0.35$. From 2000 case-resampling bootstrap samples, the bootstrap distribution of $\hat\beta_1^*$ has $\widehat{\mathrm{SE}}_B = 0.51$ and is right-skewed, with 2.5th and 97.5th percentiles at 1.51 and 3.55.

  1. Why is $\widehat{\mathrm{SE}}_B = 0.51$ larger than $\mathrm{SE}_{\mathrm{OLS}} = 0.35$? What does this suggest about the data?
  2. Construct a 95% percentile CI and a 95% normal CI for $\beta_1$. Which is more appropriate and why?

a. OLS SE assumes homoscedastic, normally distributed errors. The bootstrap SE is larger, suggesting the errors are likely heteroscedastic (variance depends on $X$) or the error distribution has heavier tails than normal. The bootstrap captures this variability that OLS ignores.

b. Percentile CI: $(1.51, 3.55)$. Normal CI: $2.4 \pm 1.96 \times 0.51 = 2.4 \pm 1.00 = (1.40, 3.40)$. The percentile CI is more appropriate here because the bootstrap distribution is right-skewed, violating the symmetry assumption needed for the normal CI. The normal CI would be misleadingly symmetric around $\hat\beta_1$.
