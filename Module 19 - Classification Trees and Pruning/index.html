Module 19

Classification Trees and Pruning

This module completes the treatment of single trees. First we adapt recursive binary splitting to a categorical response, using node impurity in place of residual sum of squares. Then we address the fact that a fully grown tree overfits, and derive cost-complexity pruning as a principled way to trade training error against tree size.

Learning Objectives
  • Predict a class and estimate class probabilities from a terminal node
  • Compute the Gini index, cross entropy and misclassification error, and choose between them
  • Explain why fully grown trees overfit and why pre-pruning is myopic
  • Derive the cost-complexity (weakest link) pruning criterion
  • Apply the pruning algorithm step by step
  • Select the optimal tree size using cross-validation
  • Interpret the complexity parameter $\alpha$ as a regularisation penalty
Pruning as regularisation Cost-complexity pruning is the tree analogue of ridge/lasso regularisation. The penalty parameter $\alpha$ controls the bias-variance trade-off, with $\alpha = 0$ giving the full tree and $\alpha \to \infty$ collapsing to the root (intercept-only model).
Classification Trees

Classification Trees: Prediction and Node Purity

A classification tree grows in exactly the same way as a regression tree, by recursive binary splitting. Only two things change: how a node makes a prediction, and how the quality of a split is measured.

Prediction rule Let $\hat p_{mk}$ be the proportion of training observations in node $m$ that belong to class $k$: $$\hat p_{mk} = \frac{1}{n_m}\sum_{i \in R_m} 1\{y_i = k\}$$ The node predicts the majority class, $\arg\max_k \hat p_{mk}$. The vector $(\hat p_{m1},\ldots,\hat p_{mK})$ itself serves as the estimated class probabilities, which is what allows a tree to produce a ROC curve.

Why RSS is replaced

Residual sum of squares is meaningless for an unordered categorical response, so a measure of node impurity takes its place. A node is pure when all its observations share one class, and maximally impure when the classes are evenly balanced.

The three standard measures $$\text{Misclassification error: } E_m = 1 - \max_k \hat p_{mk}$$ $$\text{Gini index: } G_m = \sum_{k=1}^{K}\hat p_{mk}(1-\hat p_{mk}) = 1 - \sum_{k=1}^{K}\hat p_{mk}^2$$ $$\text{Cross entropy: } D_m = -\sum_{k=1}^{K}\hat p_{mk}\log \hat p_{mk}$$ All three equal zero when the node is pure. For $K = 2$ they are maximised at $\hat p = 0.5$, taking the values $0.5$, $0.5$ and $\log 2 = 0.693$ respectively.
Combining child nodes A split is scored by the weighted impurity of the two children, weighted by the number of observations each receives: $$\text{score} = \frac{n_L}{n}Q_L + \frac{n_R}{n}Q_R$$ Weighting matters: a split producing one perfectly pure node containing a single observation is worth far less than one that cleanly separates two large groups.
Impurity

Impurity Measures: Comparison

Misclassification error (blue), Gini index (orange), and entropy/2 (green) as a function of class proportion $\hat{p}$ in a 2-class problem. Gini and entropy are more sensitive to impurity changes, making them better split criteria.

Misclassification error is a poor split criterion Misclassification error $= 1 - \max_k \hat{p}_{mk}$ is not sensitive to the distribution of class probabilities within a node. Two nodes with very different impurity can have the same misclassification error. Use Gini or entropy for splitting; use misclassification error only for pruning evaluation.
Two nodes, same error, different impurity With three classes, consider two nodes of $100$ observations each:

Worked Example: Choosing a Classification Split

A node contains $80$ observations, $40$ of class A and $40$ of class B, so it is maximally impure. Two candidate splits are available.

SplitLeft childRight child
Split 1$30$ A, $10$ B  ($n_L = 40$)$10$ A, $30$ B  ($n_R = 40$)
Split 2$40$ A, $20$ B  ($n_L = 60$)$0$ A, $20$ B  ($n_R = 20$)

Parent impurity. With $\hat p_A = \hat p_B = 0.5$:

$$G_{\text{parent}} = 1 - (0.5^2 + 0.5^2) = 0.5, \qquad E_{\text{parent}} = 1 - 0.5 = 0.5$$

Split 1

$$G_L = 1 - \left[(0.75)^2 + (0.25)^2\right] = 1 - 0.625 = 0.375, \qquad G_R = 0.375 \text{ (by symmetry)}$$ $$G_{\text{split 1}} = \tfrac{40}{80}(0.375) + \tfrac{40}{80}(0.375) = \mathbf{0.375}$$ $$E_L = 1 - 0.75 = 0.25, \quad E_R = 0.25, \qquad E_{\text{split 1}} = \mathbf{0.25}$$

Split 2

$$G_L = 1 - \left[\left(\tfrac{40}{60}\right)^2 + \left(\tfrac{20}{60}\right)^2\right] = 1 - (0.4444 + 0.1111) = 0.4444, \qquad G_R = 1 - (0 + 1) = 0$$ $$G_{\text{split 2}} = \tfrac{60}{80}(0.4444) + \tfrac{20}{80}(0) = \mathbf{0.3333}$$ $$E_L = 1 - \tfrac{40}{60} = 0.3333, \quad E_R = 0, \qquad E_{\text{split 2}} = \tfrac{60}{80}(0.3333) + \tfrac{20}{80}(0) = \mathbf{0.25}$$
The two criteria disagree
CriterionSplit 1Split 2Preferred
Gini$0.3750$$\mathbf{0.3333}$Split 2
Misclassification error$0.2500$$0.2500$Tie
Misclassification error cannot separate the two splits, because both leave $20$ of the $80$ observations misclassified. Gini prefers Split 2, and rightly so: Split 2 produces a completely pure node of $20$ observations, which is a terminal answer requiring no further work, whereas Split 1 leaves both children still mixed.
The lesson Grow the tree with Gini or cross entropy, since they reward purity gains that misclassification error is blind to. Use misclassification error when pruning, where the objective is predictive accuracy of the final classifier rather than the quality of a further split.
Cost-Complexity Pruning

Cost-Complexity (Weakest Link) Pruning

Cost-complexity criterion For a subtree $T$ with $|T|$ leaves, define: $$C_\alpha(T) = \sum_{m=1}^{|T|} \sum_{i:\,x_i \in R_m}(y_i - \hat{y}_{R_m})^2 + \alpha|T|$$ The first term is training RSS; the second penalises the number of leaves. $\alpha \geq 0$ is the complexity parameter. For any $\alpha$, the optimal subtree $T(\alpha)$ minimises $C_\alpha(T)$ over all subtrees of the full tree $T_{\max}$.
Weakest link pruning algorithm
  1. Grow the full tree $T_{\max}$ (stopping only at minimum node size).
  2. For each internal node $t$, compute the effective $\alpha$ at which collapsing the subtree rooted at $t$ becomes beneficial: $$g(t) = \frac{\mathrm{RSS}(t) - \mathrm{RSS}(T_t)}{|T_t| - 1}$$ where $T_t$ is the subtree rooted at $t$ and $\mathrm{RSS}(t)$ is the RSS of the single node $t$.
  3. Collapse the node with smallest $g(t)$ (the weakest link). Record the resulting subtree.
  4. Repeat until the tree collapses to a single node. This yields a sequence $T_0 \supset T_1 \supset \cdots \supset T_k = \{$root$\}$ with corresponding thresholds $0 \leq \alpha_0 < \alpha_1 < \cdots < \alpha_k$.
  5. Use cross-validation to select $\alpha^*$ from this sequence. Report $T(\alpha^*)$.
Pruning Path

The Pruning Sequence and Cross-Validation

Training error (blue) decreases monotonically with tree size. CV error (orange) is U-shaped: the optimal number of leaves balances bias and variance.

Cross-validation procedure
  1. Split data into $K$ folds.
  2. For each fold, grow a full tree on the training portion and apply weakest-link pruning for the same $\alpha$ sequence.
  3. Record the test error for each $\alpha$ across all folds.
  4. Average the test errors. Select $\alpha^*$ minimising mean CV error (or apply the one-SE rule).
  5. Refit on the full training data and prune to $T(\alpha^*)$.
One-SE rule Select the smallest tree (fewest leaves) whose CV error is within one standard error of the minimum CV error. This applies Occam's razor: prefer simplicity when the evidence for a more complex model is weak.
Worked Example

Worked Example: Pruning Sequence

Full tree $T_{\max}$ has 5 leaves, training RSS = 12. Internal nodes and their $g(t)$ values:

NodeRSS at nodeRSS of subtreeLeaves in subtree$g(t)$
$t_1$8.03.53$(8.0-3.5)/(3-1)=2.25$
$t_2$6.04.52$(6.0-4.5)/(2-1)=1.50$
$t_3$9.57.02$(9.5-7.0)/(2-1)=2.50$
Pruning steps
  1. Smallest $g(t)$: $t_2$ with $g=1.50$. Collapse $t_2$: tree now has 4 leaves, threshold $\alpha_1 = 1.50$.
  2. Recompute $g$ for remaining nodes. Next smallest: $t_1$ with $g=2.25$. Collapse: 2 leaves, $\alpha_2=2.25$.
  3. Collapse $t_3$: 1 leaf (root), $\alpha_3=2.50$.
Cross-validation selects, say, $\alpha^*=2.0$: this corresponds to the 4-leaf subtree from step 1.
Key insight $g(t)$ is the per-leaf improvement in training RSS from keeping the subtree rooted at $t$ instead of collapsing it to a single node. A small $g(t)$ means the subtree is doing little useful work: a good candidate for removal.

The ties are the thresholds A tie occurs at exactly $\alpha = 1.50$, $2.25$ and $2.50$, which are precisely the three $g(t)$ values computed on the previous slide. This is not a coincidence: $g(t)$ is defined as the value of $\alpha$ at which keeping the subtree and collapsing it cost the same. The optimal subtree is therefore constant on each interval:

Why this matters in practice Although $\alpha$ is continuous, only finitely many subtrees can ever be optimal, here just four. Cross validation therefore does not need to search a continuum: it evaluates one representative $\alpha$ from each interval, which is why the whole pruning path can be computed cheaply. The value $\alpha^{*} = 2.0$ selected on the previous slide falls in $[1.50,\,2.25)$ and so returns $T_1$, the four leaf tree, agreeing with the sequence method.
Interpretation

Interpreting $\alpha$ and Tree Size

$\alpha$ as regularisation The complexity parameter $\alpha$ plays the same role as $\lambda$ in ridge/lasso. Increasing $\alpha$ penalises additional leaves more heavily, producing smaller trees. Cross-validation selects the optimal trade-off between fit and complexity.
$\alpha$Tree sizeBiasVariance
0Full tree $T_{\max}$LowHigh (overfits)
SmallLarge (many leaves)LowModerate
$\alpha^*$ (CV-selected)OptimalBalancedBalanced
LargeSmall (few leaves)HighLow
$\to\infty$Root onlyMaximum0
Classification trees For classification trees, replace RSS with the node misclassification error in the pruning criterion. Gini or entropy is used for splitting, but misclassification error is acceptable for pruning evaluation because it directly measures predictive accuracy.
Single trees vs ensembles Even with optimal pruning, a single decision tree has high variance. Bagging, random forests, and boosting (Modules 23 and 24) dramatically reduce variance by averaging over many trees. Pruning is most important for interpretability; for prediction accuracy, ensembles are preferred.
In-Class Exercise

In-Class Exercise

Questions
  1. A full tree has training RSS 10 with 6 leaves. After collapsing one internal node, the tree has 4 leaves and training RSS 13. What is the increase in $C_\alpha$ from this collapse, and for what values of $\alpha$ is the collapse worthwhile?
  2. Why is cross-validation needed to select $\alpha$? Why can we not just pick the tree minimising training RSS?
  3. In weakest-link pruning, why do we remove the node with the smallest $g(t)$ first, rather than the node that causes the smallest increase in training RSS?
  4. Compare cost-complexity pruning in trees with $L_1$ regularisation in lasso. Identify one conceptual similarity and one difference.
  1. $\Delta C_\alpha = (13-10) - \alpha(4-6) = 3 + 2\alpha$. Wait, the number of leaves decreases from 6 to 4, so $\Delta|T| = -2$. $\Delta C_\alpha = 3 - \alpha\cdot 2 = 3-2\alpha$. The collapse is worthwhile when $\Delta C_\alpha < 0$, i.e.\ $3-2\alpha < 0 \Rightarrow \alpha > 1.5$. So for $\alpha > 1.5$, collapsing is beneficial.
  2. Training RSS monotonically decreases with tree size: the full tree always wins. Using training RSS for selection would always select $T_{\max}$, which overfits. Cross-validation estimates test performance by evaluating on held-out data not used in tree construction.
  3. $g(t)$ is the normalised gain per leaf removed, not the raw RSS increase. Removing a node with many leaves but small $g(t)$ removes a lot of complexity for little accuracy loss; removing a node with large $g(t)$ removes a node that contributes substantially. The weakest link is defined by its normalised contribution, making the sequence consistent with the cost-complexity criterion.
  4. Similarity: both introduce a penalty on model complexity ($\alpha|T|$ vs $\lambda\|\boldsymbol\beta\|_1$) that trades off fit against size. Larger penalty gives simpler models. Both are selected by cross-validation. Difference: lasso produces exact zeros in coefficients (continuous shrinkage to zero), while pruning removes entire subtrees (discrete structural change). Lasso can gradually shrink any coefficient; pruning cannot partially collapse a node.
Practice Problems

Practice Problems

Problem 1: Conceptual
  1. A decision tree is grown with minimum node size = 1 (fully grown). What is its training misclassification rate? What does this imply about using training accuracy to evaluate trees?
  2. True or False: Cost-complexity pruning always selects the subtree with the fewest leaves.
  3. Explain why collapsing the weakest-link node first guarantees a nested sequence of subtrees.
  1. With one observation per leaf, the tree perfectly memorises the training labels: training misclassification rate = 0. This means training accuracy is completely uninformative about generalisation: a model with 0% training error is almost certainly overfitting.
  2. False. Cost-complexity pruning selects the subtree minimising $C_\alpha(T) = \text{RSS} + \alpha|T|$ for the cross-validated $\alpha^*$. The selected tree balances fit and complexity. For small $\alpha^*$, the selected tree may have many leaves; for large $\alpha^*$, few leaves. The one-SE rule may select a smaller tree, but the optimal $\alpha^*$ from CV may prefer a larger one.
  3. Weakest-link pruning collapses one subtree at a time. Each collapse produces a subtree that is a strict subset of the previous. By always choosing the subtree that causes the smallest normalised increase in RSS, the algorithm produces a sequence $T_0 \supset T_1 \supset \cdots$ where each tree is obtained from the previous by a single collapse. Nestedness is guaranteed because each step only removes nodes (never adds them).
