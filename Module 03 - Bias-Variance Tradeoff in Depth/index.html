Deriving the Decomposition: Setup

Fix a test point \(x_0\). The true model is \(Y = f(x_0) + \varepsilon\) where \(E[\varepsilon]=0\) and \(\operatorname{Var}(\varepsilon)=\sigma^2\). We train \(\hat{f}\) on a random training set \(\mathcal{T}\) and predict \(\hat{f}(x_0)\). We want to find \(E_{\mathcal{T}}\left[(y_0 - \hat{f}(x_0))^2\right]\), averaging over all possible training sets and over the noise in \(y_0\).

1
Let \(\bar{f}(x_0) = E_{\mathcal{T}}[\hat{f}(x_0)]\) be the average prediction across all possible training sets. This is a fixed number for a given \(x_0\) and method.
2
Add and subtract \(\bar{f}(x_0)\) and \(f(x_0)\) inside the squared error. Use the identity \((a+b)^2 = a^2 + 2ab + b^2\) with the cross terms vanishing under expectation.
3
The three resulting terms are Bias\(^2\), Variance, and Irreducible error. Each term is non-negative, so they sum to give a lower bound on test MSE.
Key assumption

\(\varepsilon\) is independent of \(\hat{f}(x_0)\): the noise in a new test observation is independent of how we fitted the model on training data.

Slide 3 of 15
The Full Derivation

Starting from the expected squared error at \(x_0\), where expectation is over both the training set \(\mathcal{T}\) and the test noise \(\varepsilon_0\):

Step 1: expand
\[E\!\left[(y_0 - \hat{f}(x_0))^2\right] = E\!\left[(f(x_0)+\varepsilon_0 - \hat{f}(x_0))^2\right]\]
Step 2: add and subtract the mean prediction \(\bar{f}(x_0)\)
\[= E\!\left[(\underbrace{f(x_0)-\bar{f}(x_0)}_{\text{const w.r.t. }\mathcal{T}} + \underbrace{\bar{f}(x_0)-\hat{f}(x_0)}_{\text{mean zero}} + \varepsilon_0)^2\right]\]
Step 3: cross terms vanish, leaving three squares
\[\boxed{E\!\left[(y_0-\hat{f}(x_0))^2\right] = \underbrace{\left[f(x_0)-\bar{f}(x_0)\right]^2}_{\text{Bias}^2} + \underbrace{E\!\left[(\hat{f}(x_0)-\bar{f}(x_0))^2\right]}_{\text{Variance}} + \underbrace{\sigma^2}_{\text{Irreducible}}}\]
Why do cross terms vanish?
  • \(E[\varepsilon_0]=0\) kills any term involving \(\varepsilon_0\) alone or multiplied by a quantity that does not depend on \(\varepsilon_0\).
  • \(E[\hat{f}(x_0) - \bar{f}(x_0)] = 0\) by definition of \(\bar{f}\), killing the cross term between the bias term and the variance term.
Slide 4 of 15
Understanding Bias
Definition of Bias
\[\operatorname{Bias}(\hat{f}(x_0)) = E_{\mathcal{T}}[\hat{f}(x_0)] - f(x_0) = \bar{f}(x_0) - f(x_0)\]
Intuition

Bias measures how far the average prediction (over all possible training sets of size \(n\)) is from the true value. It is the systematic error caused by wrong model assumptions, not by randomness in the data.

High Bias

  • Model is too simple
  • Misses the true shape of \(f\)
  • More data does NOT fix it
  • Example: fitting a line to curved data
  • Symptom: high training AND test error

Low Bias

  • Model is flexible enough
  • Can approximate the true \(f\)
  • Average prediction close to truth
  • Example: high-degree polynomial, deep net
  • Risk: may have high variance instead
Key point

Bias is a property of the learning method, not any single fitted model. Even with infinite data, a linear model fitting a cubic truth will always have nonzero bias.

Slide 5 of 15
Understanding Variance
Definition of Variance
\[\operatorname{Var}(\hat{f}(x_0)) = E_{\mathcal{T}}\!\left[(\hat{f}(x_0) - \bar{f}(x_0))^2\right]\]
Intuition

Variance measures how much the prediction at \(x_0\) changes when we train on different samples of size \(n\). A high-variance method produces very different \(\hat{f}\) for each new training set, even if on average it is unbiased.

High Variance

  • Model is too flexible
  • Fits noise in training data
  • Small data change, big model change
  • Example: KNN with \(K=1\), degree-15 poly
  • Symptom: low training error, high test error

Low Variance

  • Model is stable across training sets
  • Predictions change little with new data
  • Example: linear regression, large \(K\) KNN
  • Risk: may have high bias instead
  • More data shrinks variance
Analogy

Bias is like a rifle with incorrect sighting: every shot lands in the same wrong spot. Variance is like a rifle with a shaky grip: shots scatter around the target. A good model has both correct sighting (low bias) and a steady grip (low variance).

Slide 6 of 15
Why the Tradeoff is Unavoidable
The fundamental tension

Reducing bias requires a more flexible model that can adapt to the training data. But greater flexibility means the model is more sensitive to which training points it happened to see, increasing variance. You cannot simultaneously drive both to zero.

Formally: let the model complexity be controlled by parameter \(\lambda\) (e.g., polynomial degree, or \(1/K\) in KNN). Then:

As complexity increases
\[\text{Bias}^2 \downarrow \quad \text{Var} \uparrow\]
As complexity decreases
\[\text{Bias}^2 \uparrow \quad \text{Var} \downarrow\]
The optimal point

Minimise \(\text{Test MSE} = \text{Bias}^2 + \text{Var} + \sigma^2\) by choosing flexibility where \(-\frac{d}{d\lambda}\text{Bias}^2 = \frac{d}{d\lambda}\text{Var}\): the marginal bias reduction equals the marginal variance increase.

Practical consequence

We cannot observe \(\text{Bias}^2\) and \(\text{Var}\) separately from data. We can only observe total test MSE (via cross-validation), which is why CV is our main tool for finding the optimal complexity.

Slide 7 of 15
Effect of Training Sample Size n

As \(n\) increases, what happens to bias and variance separately?

Variance

  • Variance always decreases as \(n \to \infty\)
  • More data: each training set looks more like the true population
  • For OLS: \(\operatorname{Var}(\hat{\beta}) = \sigma^2(\mathbf{X}^\top\mathbf{X})^{-1} \to 0\)
  • For KNN: variance \(\approx \sigma^2 / K\), independent of \(n\)
  • Large \(n\) is the most reliable way to reduce variance

Bias

  • Bias depends on the model class, not \(n\)
  • If the model is wrong (e.g., linear fit to cubic truth), more data does NOT reduce bias
  • Bias is fixed by what the method can represent
  • Exception: nonparametric methods whose complexity grows with \(n\) (e.g., KNN with \(K = \sqrt{n}\))
Learning Curves

Plot training error and validation error vs \(n\). Both converge to \(\sigma^2 + \text{Bias}^2\) as \(n \to \infty\). If the gap between training and validation error is large at large \(n\), variance is high. If both errors are large regardless of \(n\), bias is the problem.

KNN: How K Controls the Tradeoff

KNN predicts \(\hat{f}(x_0) = \frac{1}{K}\sum_{i \in \mathcal{N}_K(x_0)} y_i\) where \(\mathcal{N}_K(x_0)\) is the set of \(K\) nearest training points to \(x_0\).

KNN Bias (approx, for smooth f)
\[\text{Bias}^2 \approx \left[f(x_0) - \frac{1}{K}\sum_{i \in \mathcal{N}_K} f(x_i)\right]^2 \uparrow \text{ as } K \uparrow\]
KNN Variance (exact)
\[\operatorname{Var}(\hat{f}(x_0)) = \frac{\sigma^2}{K} \downarrow \text{ as } K \uparrow\]
\(K\)Bias\(^2\)VarianceBehaviour
1~0 (fits each point exactly)\(\sigma^2\) (very high)Extreme overfitting
5Low\(\sigma^2/5\)Usually good
10Moderate\(\sigma^2/10\)Often near optimal
\(n\)High (predicts global mean)\(\sigma^2/n \approx 0\)Extreme underfitting
Rule of thumb

Select \(K\) by cross-validation. Larger \(K\) gives smoother decision boundaries (lower variance, higher bias). The optimal \(K\) balances the two components of test MSE.

Worked Example 1: KNN on Simulated Data
Setup

True model: \(f(x) = \sin(2\pi x)\), \(n=50\), \(\sigma^2=0.25\). We fit KNN for \(K = 1, 3, 7, 15, 25\) and estimate Bias\(^2\), Var, and MSE at \(x_0=0.5\) by simulation (1000 training sets).

30.040.090.38Better balance
70.080.040.37Near optimal
150.190.020.46Bias rising fast
250.380.010.64Underfit: bias dominates
Observations
  • As \(K\) increases, Bias\(^2\) rises and Variance falls monotonically. Both move in opposite directions.
  • Test MSE is minimised at \(K=7\), not at the extremes.
  • Irreducible error \(\sigma^2 = 0.25\) sets the floor. Even at \(K=7\): MSE = 0.08 + 0.04 + 0.25 = 0.37. Confirmed.

Setup

True model: \(f(x) = 2x - x^2 + 0.5x^3\) (cubic), \(n=30\), \(\sigma^2=1\). We fit polynomial regression of degrees \(d = 1, 2, 3, 5, 10\) and estimate components by 500 simulations.

Regularisation as Bias-Variance Management

Regularisation deliberately introduces bias to reduce variance, aiming for a lower total test MSE. The two main linear regularisation methods are ridge and lasso.

Ridge Regression (L2)
\[\hat{\beta}^{\text{ridge}} = \arg\min_\beta \left\{\sum_{i=1}^n (y_i - \mathbf{x}_i^\top\beta)^2 + \lambda\sum_{j=1}^p \beta_j^2\right\}\]
Lasso Regression (L1)
\[\hat{\beta}^{\text{lasso}} = \arg\min_\beta \left\{\sum_{i=1}^n (y_i - \mathbf{x}_i^\top\beta)^2 + \lambda\sum_{j=1}^p |\beta_j|\right\}\]
\(\lambda\)Effect on coefficientsBiasVarianceBest when
0OLS: unregularisedLowHighLarge \(n\), few predictors
SmallSlight shrinkageSlightly higherLowerModerate \(p\)
LargeStrong shrinkage to 0HighVery lowSmall \(n\), large \(p\)
\(\infty\)All \(\hat{\beta}_j = 0\) (predict mean)Very high~0Never optimal
Choosing \(\lambda\)

Always select \(\lambda\) by cross-validation on the training set only. The optimal \(\lambda\) balances the bias introduced by shrinkage against the variance it removes.

In-Class Exercise
Scenario 1
A linear regression model is fitted to data generated by \(f(x) = x^3\). As you increase the training sample size \(n\) from 50 to 5000, what happens to (a) bias, (b) variance, (c) test MSE? Explain each.
(a) Bias stays the same. Bias depends on the model class (linear), not on \(n\). A linear model can never capture the cubic shape, regardless of how much data we have. Bias\(^2\) is fixed at a positive value determined by how different the best linear approximation is from \(x^3\).

(b) Variance decreases. With more data, the OLS estimates become more stable. \(\operatorname{Var}(\hat{\beta}) = \sigma^2(\mathbf{X}^\top\mathbf{X})^{-1} \to 0\) as \(n \to \infty\).

(c) Test MSE decreases and plateaus. As \(n \to \infty\), Variance \(\to 0\) so Test MSE \(\to\) Bias\(^2\) + \(\sigma^2\). More data cannot drive test MSE below this floor. If the bias is large, gathering more data has diminishing returns.
Scenario 2
You are comparing KNN with \(K=1\) and KNN with \(K=50\) on a dataset with \(n=100\) and \(\sigma^2=4\). (a) Which has higher variance? Compute the approximate variance for each at \(x_0\). (b) A colleague says "I will just use \(K=1\) and get more data to fix it." Is this correct?
(a) \(K=1\) has higher variance. Approximate variance: \(K=1\): \(\sigma^2/K = 4/1 = 4\). \(K=50\): \(\sigma^2/K = 4/50 = 0.08\). The difference is enormous.

(b) Partly correct, but incomplete. Getting more data does reduce variance for KNN with \(K=1\), since the nearest neighbour becomes a better local average as density increases. However, \(K=1\) remains a very noisy estimator for fixed \(K\). A better approach is to increase \(K\) (or let \(K\) grow with \(n\)) rather than relying solely on more data. Simply getting more data with \(K=1\) fixed leaves variance at \(\sigma^2/1 = 4\) since the formula \(\operatorname{Var} = \sigma^2/K\) does not depend on \(n\).
Scenario 3
Ridge regression with large \(\lambda\) gives low test MSE on a dataset with \(n=20, p=18\). When you collect \(n=2000\) more observations, the optimal \(\lambda\) from cross-validation drops close to 0. Why?
With \(n=20\) and \(p=18\), the OLS estimator has very high variance (near-singular \(\mathbf{X}^\top\mathbf{X}\)). Ridge shrinkage introduces bias but dramatically reduces variance, giving a better bias-variance balance and lower test MSE.

With \(n=2000\), the OLS variance is already very small (many more observations per parameter). The benefit of shrinkage (variance reduction) is negligible, while the cost (bias) remains. So the optimal tradeoff shifts towards \(\lambda \approx 0\) (near-OLS). In the limit of infinite data, regularisation becomes unnecessary for fixed \(p\).

Practice Problems
Problem 1
Suppose \(\text{Bias}^2 = 12 - 2\lambda\) and \(\text{Var} = 3\lambda\) for a model parameterised by flexibility \(\lambda \geq 0\), with irreducible error \(\sigma^2 = 3\).
  1. Write the test MSE as a function of \(\lambda\).
  2. Find the optimal \(\lambda^*\) that minimises test MSE. Show your working.
  3. Compute the minimum test MSE.
  4. At \(\lambda^*\), what fraction of the reducible error comes from bias?
  1. \(\text{Test MSE}(\lambda) = (12-2\lambda) + 3\lambda + 3 = 15 + \lambda\).
  2. This is linear and increasing in \(\lambda\)! So the minimum is at \(\lambda^* = 0\). Wait, but that gives Bias\(^2 = 12\) and Var = 0, which seems extreme. This illustrates that when Var increases faster than Bias\(^2\) decreases, the optimal is at the boundary. Checking: \(d(\text{MSE})/d\lambda = -2 + 3 = 1 > 0\), so MSE increases with \(\lambda\). Optimal: \(\lambda^* = 0\).
  3. Minimum Test MSE = \(12 + 0 + 3 = 15\).
  4. At \(\lambda^*=0\): reducible error = Bias\(^2\) + Var = 12 + 0 = 12. Fraction from bias = 12/12 = 100%.
Problem 2
Now suppose \(\text{Bias}^2 = 8e^{-\lambda}\) and \(\text{Var} = 2\lambda\) with \(\sigma^2 = 1\).
  1. Find the optimal \(\lambda^*\) by setting \(d(\text{MSE})/d\lambda = 0\). (Hint: solve \(8e^{-\lambda} = 2\).)
  2. Compute Bias\(^2\), Var, and Test MSE at \(\lambda^*\).
  3. Is the optimal model more biased or more variable? Justify.
  1. \(\text{MSE}(\lambda) = 8e^{-\lambda} + 2\lambda + 1\). Taking derivative: \(d\text{MSE}/d\lambda = -8e^{-\lambda} + 2 = 0 \Rightarrow e^{-\lambda} = 1/4 \Rightarrow \lambda^* = \ln 4 \approx 1.386\).
  2. Bias\(^2 = 8e^{-\ln 4} = 8 \times \frac{1}{4} = 2\). Var \(= 2\ln 4 \approx 2.77\). Test MSE \(= 2 + 2.77 + 1 = 5.77\).
  3. At \(\lambda^*\), Var \(\approx 2.77 >\) Bias\(^2 = 2\), so the model is slightly more variable than biased. This is typical near the optimum: since increasing \(\lambda\) reduces bias exponentially but increases variance only linearly, the balance point leaves slightly more variance than bias.
Problem 3
A student fits a very flexible model (degree-20 polynomial) and then a rigid model (linear) to a dataset with \(n=25\) and \(\sigma^2=2\). The training MSEs are 0.3 and 8.1. The test MSEs are 15.2 and 9.4.
  1. For each model, is test MSE closer to Bias\(^2\) or to Variance? Explain.
  2. What does the large gap (0.3 vs 15.2) for the flexible model tell you about its bias and variance?
  3. Propose one change that would likely reduce the test MSE of the flexible model without changing the model class.
  1. Flexible model: test MSE = 15.2, training MSE = 0.3. The test MSE is driven by high Variance (large gap between training and test). Linear model: test MSE = 9.4, training MSE = 8.1. Both are large and close, suggesting the test MSE is driven primarily by Bias\(^2\) (both stay high, little gap).
  2. The gap of 14.9 is almost entirely Variance. The model memorised the 25 training points (near-zero bias on training) but does not generalise. Bias\(^2\) is likely close to 0 (degree-20 can match almost any smooth function), while Variance \(\approx 15.2 - 2 - 0 = 13.2\).
  3. Add regularisation (ridge or lasso with cross-validated \(\lambda\)). This shrinks the polynomial coefficients, reducing variance at the cost of a small bias increase, and will almost certainly lower test MSE from 15.2.
Problem 4
True or false? Justify each.
  1. "If two models have the same training MSE, they have the same bias."
  2. "Adding more training data always reduces test MSE."
  3. "The irreducible error \(\sigma^2\) can be estimated from training data."
  4. "A model with zero bias is always the best choice."
  1. False. Training MSE is a function of the fitted model on one dataset. Bias is defined as the average over all training sets. Two models can have the same training MSE on one dataset but very different biases.
  2. False. More data reduces Variance, but if the model has high Bias, test MSE converges to Bias\(^2\) + \(\sigma^2\) which may still be large. More data does not help a misspecified model.
  3. True, approximately. In linear regression, \(\hat{\sigma}^2 = \text{RSS}/(n-p-1)\) is an unbiased estimator of \(\sigma^2\). For nonparametric methods, it is harder but still possible with large enough \(n\).
  4. False. Zero-bias models tend to have very high variance, which can make test MSE worse than a biased but low-variance model. The goal is to minimise total test MSE, not any single component.

Diagnostic guide
  • Both training and test error are high: high bias. Use a more flexible model.
  • Training error is low but test error is high: high variance. Regularise, reduce complexity, or get more data.
  • Both errors are low: you are in a good region. Apply the 1-SE rule to pick the simplest model near this point.

Key Takeaways
The DecompositionTest MSE = Bias\(^2\) + Variance + \(\sigma^2\). All three terms are non-negative. Only Bias\(^2\) and Variance are controllable.
BiasSystematic error from wrong model assumptions. Fixed by the model class, not by more data. High in simple, inflexible models.
VarianceSensitivity to which training set you happened to observe. Reduced by more data or less flexibility. High in complex models on small datasets.
The TradeoffYou cannot reduce both simultaneously. Optimal complexity is where marginal bias reduction equals marginal variance increase.
KNNVariance = \(\sigma^2/K\). Bias increases with \(K\). Use CV to find the optimal \(K\).
RegularisationRidge and lasso add bias deliberately to reduce variance. Tune \(\lambda\) by CV. Essential when \(p\) is large relative to \(n\).
DiagnosticsHigh training and test error: bias problem. Low training, high test error: variance problem. Both low: good model.
